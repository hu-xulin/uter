# Bảng xếp hạng

Bảng xếp hạng hiển thị mức dùng trực tiếp và chuyển giữa Hôm nay / Tuần này / Tháng này / Năm nay.

<img className="block w-full rounded-lg border border-border dark:hidden" alt="Bảng xếp hạng" src="/user-guide/en/pricing-and-ranking/light/02-leaderboard.webp" />
<img className="block w-full rounded-lg border border-border hidden dark:block" alt="Bảng xếp hạng" src="/user-guide/en/pricing-and-ranking/dark/02-leaderboard.webp" />

- **Mô hình phổ biến**: xu hướng token theo tuần.
- **Xếp hạng LLM**: mô hình phổ biến nhất và thay đổi so với tuần trước.
- **Thị phần**: tỷ lệ token theo nhà cung cấp.
- **Theo nhà cung cấp**: mức dùng tổng hợp và tỷ lệ.
- **Tăng/giảm**: mô hình thay đổi thứ hạng rõ rệt.

<Callout type="info">
  Bảng xếp hạng tổng hợp mức dùng thực tế và cập nhật theo thời gian; mô hình ít dùng có thể không xuất hiện.
</Callout>
