# Nhật ký sử dụng

Nhật ký sử dụng mở `/usage-logs/common` và ghi lại mọi lần gọi mô hình.

- **Bộ lọc**: thời gian, tên mô hình, nhóm, loại, cùng khóa, người dùng…
- **Thanh thống kê**: tổng mức dùng theo bộ lọc, RPM, TPM, đọc/ghi bộ nhớ đệm và chênh lệch từng bước.
- **Bảng**: thời gian, khóa, mô hình, streaming, token, chi phí, độ trễ và chi tiết.
- **Thao tác**: đặt lại, tìm kiếm, xuất, số dòng mỗi trang, phân trang, chi tiết.
