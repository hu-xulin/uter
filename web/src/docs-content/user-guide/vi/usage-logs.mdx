# Usage Logs

Usage logs record every model request with its token usage and cost. Use them to reconcile billing and diagnose failed calls.

## Request list

Each row shows **Time**, **Token**, **Model**, **Stream**, **Tokens**, **Cost**, **Timing** and a **Details** action. The page is paginated and reflects the selected date range.

<img className="block w-full rounded-lg border border-border hidden dark:block" alt="Common logs list" src="/user-guide/en/usage-logs/dark/01-logs.webp" />

## Filter logs

Use the date-range picker and the **All Types** dropdown to narrow by time and request type, then press **Search**. **Reset** clears all filters.

<img className="block w-full rounded-lg border border-border dark:hidden" alt="Log filters" src="/user-guide/en/usage-logs/light/02-filters.webp" />
<img className="block w-full rounded-lg border border-border hidden dark:block" alt="Log filters" src="/user-guide/en/usage-logs/dark/02-filters.webp" />

## Request details

Click **View** on a row to open the detail dialog. It shows the request and response, token breakdown, the exact charge, and timing — this is the authoritative source for a disputed charge.

<img className="block w-full rounded-lg border border-border dark:hidden" alt="Log details dialog" src="/user-guide/en/usage-logs/light/03-details.webp" />
<img className="block w-full rounded-lg border border-border hidden dark:block" alt="Log details dialog" src="/user-guide/en/usage-logs/dark/03-details.webp" />
