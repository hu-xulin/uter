# Khóa API

Khóa API dùng để gọi các endpoint mô hình của Uter. Mở `/keys` ở thanh trái. Menu địa chỉ API phía trên chuyển và sao chép ba endpoint:

- `https://api.uter.ai`: CN2 GIA, toàn cầu (mặc định).
- `https://api.uter.cc`: tối ưu cho Trung Quốc đại lục.
- `https://api.uter.pro`: tối ưu cho nước ngoài.

Danh sách hiển thị tên, trạng thái, khóa đã ẩn, hạn ngạch, nhóm, giới hạn mô hình, giới hạn IP, thời gian tạo/dùng cuối và hết hạn. Lọc theo tên, khóa và trạng thái.

## Tạo khóa API

1. Nhấn "Tạo khóa API".
2. Nhập tên và chọn nhóm.
3. Đặt thời hạn: không hết hạn, 1 tháng, 1 ngày, 1 giờ hoặc tùy chỉnh.
4. Chọn số lượng; nếu >1, tên có thêm hậu tố ngẫu nhiên.
5. Bật "Hạn ngạch không giới hạn" hoặc đặt số lượng.
6. Mở "Cài đặt nâng cao" để đặt giới hạn mô hình, IP…
7. Nhấn "Lưu thay đổi".

## Xem, sao chép và quản lý

- **Xem/sao chép**: nhấn vào khóa hoặc nút sao chép. Xem khóa đầy đủ là thao tác nhạy cảm, cần xác minh bảo mật; nếu chưa có phương thức, trang sẽ nhắc thiết lập.
- **Menu dòng**: sao chép khóa, sao chép thông tin kết nối, mở tích hợp ứng dụng hoặc xóa.
- **Bật/tắt**: khóa bị tắt không gọi được API nhưng vẫn giữ bản ghi.
- **Sửa**: tên, nhóm, hạn ngạch, thời hạn và giới hạn truy cập.

## Dùng khóa

Đưa khóa vào header:

```bash
curl https://api.uter.ai/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-khoa-cua-ban" \
  -d '{"model":"MiniMax-M2.5","messages":[{"role":"user","content":"xin chào"}]}'
```

<Callout type="info">
  Khóa là thông tin xác thực: không đưa vào mã frontend, kho công khai hay trò chuyện. Nếu lộ, hãy tắt và xóa rồi tạo khóa mới. Trước khi xóa, xác nhận không còn dịch vụ production dùng khóa.
</Callout>
