# Bảng điều khiển

Chọn Bảng điều khiển ở thanh trái để mở `/dashboard/models`. Một trang có nhiều chế độ xem:

## Phân tích mô hình

Lọc theo thời gian, mô hình và nhóm để xem số yêu cầu, token, đọc/ghi bộ nhớ đệm, RPM/TPM trung bình, phân bố và xu hướng. Chuyển biểu đồ cột/vùng, chỉnh tùy chọn và bộ lọc.
