# Data Dashboard

The data dashboard turns your request history into charts, helping you see which models you use, how costs trend, and where traffic flows.

## Model call analytics

**Model Call Analytics** aggregates requests by model. Use the tabs to switch views and the **Filter** control to narrow by model, token or time range.

## Trends and charts

The **Call Trend**, **Call Count Distribution** and **Call Count Ranking** cards visualise volume over time. Toggle between **Bar Chart** and **Area Chart**, and open **Preferences** to customise the metrics shown.

<img className="block w-full rounded-lg border border-border dark:hidden" alt="Call trend and charts" src="/user-guide/en/dashboard/light/02-charts.webp" />

## Flow view

The **Flow** tab presents traffic as a funnel from request to completion. It is useful for spotting where requests are dropped or retried.
