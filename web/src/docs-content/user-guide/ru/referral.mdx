# Referral Program

The Referral Program rewards you when new users join through your link. Accumulated rewards can be moved into your spendable balance.

## Your referral link

Copy the **referral link** and share it. When a new user signs up through it and meets the site’s qualifying rules, a reward is credited to your referral earnings.

## Transfer rewards

Use **Transfer to Balance** to move accumulated referral earnings into your main balance so they can be spent on API calls. The dialog confirms the amount before it is moved.
