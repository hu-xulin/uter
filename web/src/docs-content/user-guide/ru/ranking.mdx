# Рейтинг

«Рейтинг» показывает текущий расход платформы с переключением «Сегодня / Неделя / Месяц / Год».

<img className="block w-full rounded-lg border border-border dark:hidden" alt="Рейтинг" src="/user-guide/en/pricing-and-ranking/light/02-leaderboard.webp" />
<img className="block w-full rounded-lg border border-border hidden dark:block" alt="Рейтинг" src="/user-guide/en/pricing-and-ranking/dark/02-leaderboard.webp" />

- **Популярные модели**: недельная динамика токенов.
- **Рейтинг LLM**: самые популярные модели и изменение за неделю.
- **Доля рынка**: доля токенов по поставщикам.
- **По поставщикам**: агрегированный расход и доля.
- **Рост/падение**: заметные изменения позиций.

<Callout type="info">
  Рейтинг агрегирует реальный расход и обновляется; малопопулярные модели могут отсутствовать.
</Callout>
