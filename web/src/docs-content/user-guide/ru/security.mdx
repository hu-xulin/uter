## Вход и аутентификация

- **Смена пароля**: введите текущий и новый; новый должен соответствовать требованиям.
- **Привязки**: привяжите или отвяжите e-mail, GitHub и Discord. Перед отвязкой убедитесь, что остался рабочий способ входа.

## Сеансы входа

Список сеансов по браузерам и устройствам: IP, способ входа, последняя активность и срок. Можно отозвать один сеанс, выйти из остальных или из текущего.

## Токены доступа

Токены вызывают API консоли из скриптов и автоматизации и не связаны с ключами API моделей. При создании выбираются:

- **Срок**: 30/90/180 дней, 1 год, свой или бессрочно.
- **Права**: личные права чтения/записи для профиля, ключей API, расхода, кошелька и безопасности (минимально необходимые).

Токен показывается полностью один раз — сохраните его сразу и удалите, когда он больше не нужен.

## Операции с аккаунтом и конфиденциальность

- **Удаление аккаунта**: безвозвратно удаляет аккаунт и данные.
- **Запись IP**: сохранять ли IP запросов в журналах использования и ошибок.
