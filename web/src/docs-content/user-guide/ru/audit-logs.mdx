# Журнал аудита

«Журнал аудита» открывает `/usage-logs/audit` и фиксирует события входа, безопасности и доступа.

- Фильтры по периоду, результату (все/успех/ошибка) и категории.
- Таблица: время, пользователь, событие, IP, клиент, метод и маршрут.
- «Просмотр» или развёртывание строки показывает детали — полезно для разбора необычных входов, показа ключей и действий с безопасностью.
