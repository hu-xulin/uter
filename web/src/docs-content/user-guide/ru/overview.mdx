### Начало работы

Вверху три шага:

1. **Создать ключ API** в разделе «Ключи API».
2. **Пополнить квоту** в «Кошельке» или кодом.
3. **Отправить запрос** в Песочнице или своём клиенте.

Справа показаны выбранная модель, состояние авторизации и готовый `curl`. «Скрыть руководство» сворачивает блок.

### Расход и информация об API

Показаны расход за 24 часа, общий расход, число запросов, остаток и оценка срока. Информация об API содержит три адреса:

- `https://api.uter.ai` — оптимизация CN2 GIA, глобально.
- `https://api.uter.cc` — для материкового Китая.
- `https://api.uter.pro` — для зарубежья.

У каждого адреса есть проверка задержки и копирование.

### Объявления, FAQ и аптайм

- **Объявления**: последние уведомления или пустое состояние.
- **FAQ**: адреса, модели, биллинг, пополнение, ошибки, хранение данных, баланс, поддержка.
- **Аптайм**: группы мониторинга при настроенном Uptime Kuma, иначе подсказка.
