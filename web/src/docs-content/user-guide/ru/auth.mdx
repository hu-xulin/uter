# Вход

Uter предлагает три способа входа: код на e-mail, GitHub и Discord. После входа открывается консоль; при первом входе по коду автоматически создаётся обычная учётная запись.

## Вход по коду на e-mail

1. Откройте страницу входа и укажите e-mail.
2. Нажмите «Отправить код» и используйте 6-значный код из письма.
3. Введите код и примите пользовательское соглашение и политику конфиденциальности.
4. Нажмите «Войти».

## Вход через GitHub

1. Примите соглашение и политику конфиденциальности.
2. Нажмите «Продолжить с GitHub».
3. Подтвердите на GitHub — вы вернётесь в консоль Uter.

## Вход через Discord

1. Примите соглашение и политику конфиденциальности.
2. Нажмите «Продолжить с Discord».
3. Подтвердите в Discord — вы вернётесь в консоль Uter.

<Callout type="info">
  GitHub и Discord используют собственные учётные записи; Uter хранит только базовые данные, необходимые для входа. Если кнопка отсутствует, способ отключён.
</Callout>

## После входа

Открывается «Обзор». В «Профиле» видны данные учётной записи, в «Безопасность и доступ» — сеансы, привязки, токены доступа и настройки безопасности.
