# Login

Uter supports three ways to sign in: email verification code, GitHub and Discord. A successful sign-in opens the console; the first email-code sign-in automatically creates a regular account.

## Sign in with an email code

Click **Sign in with email code** to switch to the code flow. Enter your email and request a code; a 6-digit code arrives by email and is valid for 10 minutes.

A new, unregistered email is turned into a regular account after verification, so there is no separate registration form. Five wrong attempts invalidate the code and you must request a new one.

## Sign in with GitHub

Tick the agreement checkbox, then select the **Continue with GitHub** button (shown selected below). Uter hands you to GitHub for authorization and returns you to the console automatically once you approve.

Only the basic profile needed to sign you in is stored. If the button is missing, that provider has been disabled by the administrator.

## Sign in with Discord

With the agreement accepted, select **Continue with Discord** (shown selected below) and approve the authorization on Discord. You are redirected back to the console on success.

OAuth sign-in uses your GitHub or Discord identity — you can bind or unbind these providers later under Security & Access.
