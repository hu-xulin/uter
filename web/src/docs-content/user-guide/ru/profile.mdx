# Профиль

## Профиль

«Профиль» открывает `/profile`. Вверху аватар, отображаемое имя, логин, ID, группа, баланс, общий расход и число запросов.

### Уведомления и поведение

- **Способ уведомлений**: e-mail, Webhook, Bark, Gotify.
- **E-mail для уведомлений**: пусто — адрес аккаунта.
- **Низкий баланс**: одно уведомление при падении ниже порога (USD).
- **Принимать модели без цены**: разрешить неоценённые модели; выключено — они отклоняются.

После изменений нажмите «Сохранить».

### Персонализация боковой панели

Настройки боковой панели скрывают или показывают пункты по областям: чат (Песочница, Чат), администрирование (Панель, Ключи API, журналы) и личное (Кошелек, Профиль, Безопасность). Сохраните или сбросьте.

### Ежедневная отметка

Одна отметка в день даёт случайную квоту на баланс. Панель показывает всего, за месяц и суммарно, а также календарь.
