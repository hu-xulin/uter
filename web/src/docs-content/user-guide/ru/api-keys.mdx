# Ключи API

Ключи API вызывают модельные эндпоинты Uter. Откройте `/keys` в левом меню. Меню адреса API сверху переключает и копирует три эндпоинта:

- `https://api.uter.ai` — CN2 GIA, глобально (по умолчанию).
- `https://api.uter.cc` — для материкового Китая.
- `https://api.uter.pro` — для зарубежья.

Список показывает имя, состояние, маскированный ключ, квоту, группу, ограничения моделей и IP, время создания/использования и срок. Есть фильтры по имени, ключу и состоянию.

## Создание ключа API

1. Нажмите «Создать ключ API».
2. Укажите имя и группу.
3. Задайте срок: бессрочно, 1 месяц, 1 день, 1 час или вручную.
4. Выберите количество; при >1 к имени добавляется случайный суффикс.
5. Включите «Безлимитная квота» или задайте сумму.
6. Разверните «Дополнительно» для ограничений моделей и IP.
7. Нажмите «Сохранить изменения».

## Просмотр, копирование и управление

- **Просмотр/копирование**: нажмите ключ или кнопку копирования. Показ полного ключа — чувствительная операция с проверкой безопасности; при её отсутствии страница предложит настроить способ.
- **Меню строки**: копировать ключ, копировать данные подключения, открыть интеграцию, удалить.
- **Включить/отключить**: отключённый ключ не вызывает API, записи сохраняются.
- **Изменить**: имя, группа, квота, срок и ограничения.

## Использование ключа

Передайте ключ в заголовке:

```bash
curl https://api.uter.ai/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-ваш-ключ" \
  -d '{"model":"MiniMax-M2.5","messages":[{"role":"user","content":"привет"}]}'
```

<Callout type="info">
  Ключ — это учётные данные: не помещайте его во фронтенд, публичный репозиторий или чат. При утечке отключите и удалите ключ, создайте новый. Перед удалением убедитесь, что им не пользуются в продакшене.
</Callout>
