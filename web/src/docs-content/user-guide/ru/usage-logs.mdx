# Журнал использования

«Журнал использования» открывает `/usage-logs/common` и фиксирует каждый вызов модели.

- **Фильтры**: период, модель, группа, тип, а также ключ, пользователь и др.
- **Сводка**: общий расход по фильтру, RPM, TPM, чтение/запись кэша и изменения по шагам.
- **Таблица**: время, ключ, модель, потоковость, токены, стоимость, задержка, детали.
- **Действия**: сброс, поиск, экспорт, размер страницы, пагинация, детали.
