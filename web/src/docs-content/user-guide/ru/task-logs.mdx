# Журнал задач

«Журнал задач» открывает `/usage-logs/task`; сверху переключаются «Журнал изображений» и «Журнал задач».

## Журнал изображений

Записывает задачи изображений. Фильтр по периоду; видны время отправки, ID задачи, статус, прогресс и результат; можно открыть детали и артефакты.

## Журнал задач

Записывает асинхронные видео- и аудиозадачи. Фильтр по периоду и ID; видны время, длительность, статус, прогресс, артефакты и детали.

<img className="block w-full rounded-lg border border-border dark:hidden" alt="Журнал задач" src="/user-guide/en/logs-and-tasks/light/03-task-logs.webp" />
<img className="block w-full rounded-lg border border-border hidden dark:block" alt="Журнал задач" src="/user-guide/en/logs-and-tasks/dark/03-task-logs.webp" />

<Callout type="info">
  Статус и прогресс берутся с сервера. Ошибки и тайм-ауты могут компенсироваться по правилам канала. По ID задачи можно найти запись биллинга в журнале использования.
</Callout>

## Связь журналов

- **Использование**: биллинг и производительность каждого вызова.
- **Аудит**: входы, безопасность и доступ к аккаунту.
- **Изображения/задачи**: жизненный цикл асинхронных задач.

При разборе: аудит → использование → задачи.
