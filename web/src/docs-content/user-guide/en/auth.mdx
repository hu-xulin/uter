# Login

Uter offers three sign-in methods: email verification code, GitHub, and Discord. A successful sign-in opens the console; the first email-code sign-in automatically creates a regular user account.

## Sign in with an email code

1. Open the sign-in page and enter your email address.
2. Click "Send code" and use the 6-digit code from the email.
3. Enter the code and accept the User Agreement and Privacy Policy.
4. Click "Sign in".

<Callout type="info">
  The code is valid for 10 minutes and can be used once; five wrong attempts invalidate it and a new code is required. An unregistered email becomes a new account after verification — no separate registration step.
</Callout>

## Sign in with GitHub

1. Accept the User Agreement and Privacy Policy on the sign-in page.
2. Click "Continue with GitHub".
3. Confirm on GitHub; you return to the Uter console automatically.

## Sign in with Discord

1. Accept the User Agreement and Privacy Policy on the sign-in page.
2. Click "Continue with Discord".
3. Confirm on Discord; you return to the Uter console automatically.

<Callout type="info">
  GitHub and Discord use their own accounts for authorization; Uter stores only the basic profile needed to sign you in. A missing button means that method is disabled.
</Callout>

## After sign-in

You land on Overview. Profile shows your account information, and Security & Access manages login sessions, account bindings, access tokens and security settings.
