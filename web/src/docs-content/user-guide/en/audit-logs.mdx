# Audit Logs

Audit Logs opens `/usage-logs/audit` and records sign-in, security and access events.

- Filter by time range, result (all/success/failure) and category.
- The table shows time, username, event, IP, client, method and route.
- Use "View" or expand a row for details — useful for investigating unusual sign-ins, key reveals and account-security actions.
