# Usage Logs

Usage Logs in the left navigation opens `/usage-logs/common` and records every model call.

- **Filters**: time range, model name, group and type, plus key, user and other conditions.
- **Summary bar**: total usage for the current filter, RPM, TPM, cache reads/writes and each step's delta.
- **Table**: time, key, model, streaming or not, tokens, cost, latency and details.
- **Actions**: reset, search, export, page size, pagination and details.
