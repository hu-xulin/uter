# Profile

## Profile

Profile in the left navigation opens `/profile`. The top shows avatar, display name, username, user ID, group, balance, total usage and request count.

### Notifications and behaviour

- **Notification method**: email, Webhook, Bark or Gotify.
- **Notification email**: leave empty to use the account email.
- **Low balance alert**: warn once below a threshold (USD, configurable).
- **Accept unpriced models**: allow models without configured prices; when off they are rejected.

Click "Save settings" after changes.

### Sidebar personalisation

Left Sidebar Settings hides or shows menu items by area: chat (Playground, Chat), admin (Dashboard, API Keys, Usage Logs, Audit Logs, Drawing Logs, Task Logs) and personal (Wallet, Profile, Security & Access). Save when done, or reset to defaults.

### Daily check-in

Check in once per day for random quota added directly to your balance. The panel shows total check-ins, this month and all-time rewards, plus a calendar.
