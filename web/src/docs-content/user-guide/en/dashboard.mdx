# Dashboard

Choose Dashboard in the left navigation to open `/dashboard/models`. One page hosts several views:

## Model analytics

Filter by time range, model and group to inspect requests, tokens, cache reads/writes, average RPM/TPM, consumption distribution and trends. Switch between bar and area charts, adjust preferences and filters.
