# Overview

After sign-in, choose Overview in the left navigation to open `/dashboard/overview`. It summarizes balance, the last 24 hours of usage, request count, API endpoints, announcements, FAQ and uptime.

### Get started

The top of the page guides you through three steps:

1. **Create an API key** on the API Keys page.
2. **Add quota** in Wallet, or redeem a code.
3. **Send a request** in the Playground or your own client.

The right side shows the selected model, auth status and a copyable `curl` example. "Hide setup guide" collapses this area.

### Usage and API information

The page shows the last 24 hours, lifetime usage, request count and remaining balance, with an estimate of how long it will last. API information lists three endpoints:

- `https://api.uter.ai`: CN2 GIA optimized, globally available.
- `https://api.uter.cc`: optimized for mainland China.
- `https://api.uter.pro`: optimized for overseas networks.

Each endpoint offers a latency check and a copy button.

### Announcements, FAQ and uptime

- **Announcements**: the latest platform notices, or an empty state.
- **FAQ**: endpoints, models, billing, top-up, errors, data retention, balance and support.
- **Uptime**: grouped monitoring when Uptime Kuma is configured; otherwise a hint is shown.
