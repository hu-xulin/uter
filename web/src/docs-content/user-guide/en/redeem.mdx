# Redemption Code

Redemption codes add quota to your account. They are commonly distributed as promotions, referrals or compensation.

## Redeem a code

Enter the code in the **Redemption Code** field and press **Redeem**. On success the code’s quota is credited to your balance immediately and the code is consumed.

## Quota semantics

The credited amount is shown in the account balance card. Codes are single-use; an already-redeemed or expired code returns an error and does not change your balance.
