# Task Logs

Task logs track asynchronous jobs such as image generation, music creation and other model-driven tasks that complete after submission.

## Task list

The table shows **Submit Time**, **Task ID**, **Duration**, **Status**, **Progress**, **Artifacts** and **Details**. Statuses include queued, processing, succeeded and failed.

## Task details

Click **View details** to inspect the task payload, progress history and generated artifacts, including retry information when a task fails.
