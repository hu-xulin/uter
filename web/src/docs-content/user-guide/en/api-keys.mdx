# API Keys

API keys call Uter's model endpoints. Open `/keys` from the left navigation. The API address menu at the top switches and copies three endpoints:

- `https://api.uter.ai`: CN2 GIA optimized, globally available (default).
- `https://api.uter.cc`: optimized for mainland China.
- `https://api.uter.pro`: optimized for overseas networks.

The list shows name, status, masked key, quota, group, model limits, IP limits, creation/last-used time and expiry. Filter by name or key, and view by status.

## Create an API key

1. Click "Create API Key" in the top right.
2. Enter a name and choose a group.
3. Set expiry: never, 1 month, 1 day, 1 hour, or a custom time.
4. Choose how many keys to create; names get a random suffix when more than one.
5. Enable "Unlimited quota", or set a specific amount.
6. Expand "Advanced settings" for model limits, IP limits and other constraints.
7. Click "Save changes".

The console reports how many keys were created and the keys appear in the list.

## View, copy and manage

- **View/copy**: click the key text or the copy button. Revealing the full key is sensitive and requires a security verification step; the page prompts you to add one when none is available.
- **Row menu**: copy the key, copy connection info, open app integration, or delete.
- **Enable/disable**: a disabled key cannot call the API; its records remain.
- **Edit**: change name, group, quota, expiry and access constraints.

## Use the key

Put the key in the request header:

```bash
curl https://api.uter.ai/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-your-key" \
  -d '{"model":"MiniMax-M2.5","messages":[{"role":"user","content":"hello"}]}'
```

<Callout type="info">
  A key is an account credential: never put it in frontend code, public repositories or chat logs. If leaked, disable and delete it, then create a new one. Confirm no production service still uses a key before deleting it.
</Callout>
