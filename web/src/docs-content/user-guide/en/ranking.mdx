# Leaderboard

The Leaderboard shows live platform usage and switches between Today, This week, This month and This year.

<img className="block w-full rounded-lg border border-border dark:hidden" alt="Leaderboard" src="/user-guide/en/pricing-and-ranking/light/02-leaderboard.webp" />
<img className="block w-full rounded-lg border border-border hidden dark:block" alt="Leaderboard" src="/user-guide/en/pricing-and-ranking/dark/02-leaderboard.webp" />

- **Popular models**: weekly token trends per model.
- **LLM ranking**: most popular models and week-over-week change.
- **Market share**: token share per vendor.
- **By vendor**: aggregated usage and share.
- **Risers/fallers**: models with notable rank changes.

<Callout type="info">
  The leaderboard aggregates real platform usage and updates over time; low-volume models may not appear.
</Callout>
