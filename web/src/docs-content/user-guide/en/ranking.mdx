# Leaderboard

Rankings show which models are popular across the platform, along with market share and momentum. Use the period tabs to change the time window.

## Top models

The **LLM Leaderboard** ranks models by usage in the selected period. Use **Today / Week / Month / Year** to switch the window and see how preferences shift.
