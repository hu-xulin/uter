# 資料看板

點選左側導覽「資料看板」進入 `/dashboard/models`。看板在同一頁面內提供多個檢視：

## 模型呼叫分析

依時間範圍、模型與分組查看請求數、Token 數、快取讀寫、平均 RPM/TPM、消耗分布與呼叫趨勢。支援長條圖/面積圖切換、偏好設定與篩選。
