# 数据看板

数据看板把请求历史可视化，帮助你了解使用了哪些模型、成本趋势如何以及流量去向。

## 模型调用分析

**模型调用分析**按模型聚合请求。通过标签页切换视图，使用**筛选**控件按模型、令牌或时间范围收窄数据。

## 趋势与图表

**调用趋势**、**调用次数分布**与**调用次数排行**卡片展示随时间变化的调用量。可在**柱状图**与**面积图**间切换，并打开**偏好设置**自定义指标。

**流量**标签页以漏斗形式呈现从请求到完成的流转，便于发现请求在哪个环节被丢弃或重试。
