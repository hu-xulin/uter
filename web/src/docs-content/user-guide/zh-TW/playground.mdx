# 游乐场

游乐场让你直接在浏览器中试用任意可用模型，无需 API 密钥或代码。这是集成前对比回答效果、调试参数最快的方式。

## 发起对话

主对话区以会话记录形式展示消息。输入内容后点击**发送**即可调用所选模型，回复按 token 流式返回。**清空对话记录**可重置会话。

**附件**按钮可为支持的文件输入模型的场景添加文件；**搜索**在支持的模型上开启联网查询。

## 选择模型

底部的模型选择器可在你有权使用的模型间切换。每项显示模型 ID 与渠道标签，确保你测试的模型与 API 调用实际命中的模型一致。

## 调整参数

打开**参数**面板可调节 temperature、top-p 等采样参数。数值越低回答越稳定，越高则越发散。修改仅对下一条消息生效。
