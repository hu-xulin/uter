# 使用日志

使用日志记录每次模型请求及其 token 用量与费用，用于核对账单和排查失败调用。

## 请求列表

每行展示**时间**、**令牌**、**模型**、**流式**、**Token 数**、**费用**、**耗时**及**详情**操作。列表分页展示，并遵循所选时间范围。

<img className="block w-full rounded-lg border border-border hidden dark:block" alt="调用日志列表" src="/user-guide/zh/usage-logs/dark/01-logs.webp" />

## 筛选日志

使用日期范围选择与**所有类型**下拉框按时间和请求类型收窄，然后点击**搜索**。**重置**清空所有筛选条件。

<img className="block w-full rounded-lg border border-border dark:hidden" alt="日志筛选" src="/user-guide/zh/usage-logs/light/02-filters.webp" />
<img className="block w-full rounded-lg border border-border hidden dark:block" alt="日志筛选" src="/user-guide/zh/usage-logs/dark/02-filters.webp" />

## 请求详情

点击某行的**查看**打开详情对话框，展示请求与响应、token 明细、实际扣费与耗时——这是核对争议扣费的权威依据。

<img className="block w-full rounded-lg border border-border dark:hidden" alt="日志详情对话框" src="/user-guide/zh/usage-logs/light/03-details.webp" />
<img className="block w-full rounded-lg border border-border hidden dark:block" alt="日志详情对话框" src="/user-guide/zh/usage-logs/dark/03-details.webp" />

**导出**将筛选结果下载为文件，便于离线分析或对账。
