# 安全与访问

「安全与访问」集中管理密码、双因素认证、登录会话与 API 访问令牌。建议定期检查以保障账号安全。

## 密码与绑定

**修改密码**可轮换登录密码。**账号绑定**显示邮箱、GitHub 与 Discord 的绑定状态，未连接的渠道可通过**绑定**添加。

## 安全验证

开启**两步验证**可启用基于 TOTP 的双因素认证，请妥善保存备用码。还可在隐私设置中切换**记录 IP 地址**并**保存设置**，**访问记录**展示近期安全事件。

<img className="block w-full rounded-lg border border-border dark:hidden" alt="双因素认证" src="/user-guide/zh/security/light/02-mfa.webp" />
<img className="block w-full rounded-lg border border-border hidden dark:block" alt="双因素认证" src="/user-guide/zh/security/dark/02-mfa.webp" />

## 会话与访问令牌

**登录会话**列出活跃设备，可用**退出其他会话**将其吊销。**访问令牌**用于脚本调用控制台 API，通过**创建访问令牌**生成，不用时及时**撤销**。
