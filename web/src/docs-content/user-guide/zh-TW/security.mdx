## 登入與驗證

- **變更密碼**：輸入目前密碼與新密碼完成修改；新密碼需符合頁面提示的強度要求。
- **帳號綁定**：綁定或解除綁定電子郵件、GitHub、Discord。綁定後可使用對應方式登入，解除綁定前需確保帳號仍有其他可用登入方式。

## 登入工作階段

「登入工作階段」列出目前帳號在不同瀏覽器與裝置上的工作階段，包括 IP、登入方式、最後活躍時間與到期時間。可以撤銷單一工作階段、登出其他工作階段，或登出目前工作階段。

## 存取權杖

存取權杖用於在腳本或自動化工具中呼叫主控台 API，與用於模型呼叫的 API 金鑰相互獨立。建立時可選擇：

- **到期時間**：30 天、90 天、180 天、1 年、自訂或永不過期。
- **權限範圍**：依「個人」維度授予個人資料、API 金鑰、用量、錢包、帳號安全等檢視/編輯權限，遵循最小權限原則。

權杖只在建立時完整顯示一次，請立即保存；不再使用時請及時刪除。

## 帳號操作與隱私

- **刪除帳號**：永久刪除帳號及資料，操作不可復原。
- **記錄 IP 位址**：控制是否在使用日誌與錯誤日誌中記錄請求 IP；依需開啟後儲存設定。
