# API 金鑰

API 金鑰用於呼叫 Uter 的模型介面。左側導覽「API 金鑰」進入 `/keys`，頁面頂部提供「API 位址」下拉選單，可在下列三個位址之間切換並複製：

- `https://api.uter.ai`：CN2 GIA 優化線路，全球通用（預設）。
- `https://api.uter.cc`：國內專用優化線路。
- `https://api.uter.pro`：海外專用優化線路。

## 建立 API 金鑰

1. 點選右上角「建立 API 金鑰」。
2. 填寫名稱，選擇分組。
3. 設定到期時間：永不過期、1 個月、1 天、1 小時，或自訂時間。
4. 設定建立數量；數量大於 1 時名稱會自動附加隨機後綴。
5. 選擇「無限配額」，或關閉後設定具體額度。
6. 展開「進階設定」可設定模型限制、IP 限制等存取約束。
7. 點選「儲存變更」。

## 查看、複製與操作

- **查看/複製**：點選金鑰文字或複製按鈕。查看完整金鑰屬於敏感操作，需先完成安全驗證；若帳號沒有可用的驗證方式，頁面會提示先綁定驗證方式。
- **操作選單**：可複製金鑰、複製連線資訊、開啟應用整合，或刪除金鑰。
- **啟用/停用**：停用後該金鑰不能繼續呼叫介面，但記錄保留。
- **編輯**：修改名稱、分組、額度、到期時間與存取限制。

## 使用金鑰

在請求標頭中攜帶金鑰：

```bash
curl https://api.uter.ai/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-你的金鑰" \
  -d '{"model":"MiniMax-M2.5","messages":[{"role":"user","content":"你好"}]}'
```

<Callout type="info">
  金鑰等同帳號憑證，請勿寫入前端程式碼、公開倉庫或聊天記錄。發現洩漏時立即停用並刪除，再建立新金鑰。刪除金鑰前請確認沒有線上服務仍在使用。
</Callout>
