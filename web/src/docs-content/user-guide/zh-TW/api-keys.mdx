# API 密钥

API 密钥是应用调用 Uter 的凭据。建议为每个应用单独创建密钥，便于分别管控与吊销。

## 密钥列表

表格列出每个密钥的**名称**、**状态**、掩码后的值、**额度（$）**、**分组**、可用**模型**、**IP 限制**、创建时间与过期时间。密钥创建后会掩码，首次看到时请复制保存。

<img className="block w-full rounded-lg border border-border hidden dark:block" alt="API 密钥列表" src="/user-guide/zh/api-keys/dark/01-keys.webp" />

## 创建密钥

点击**创建 API 密钥**打开对话框，填写名称、设置额度上限、选择分组，可按需限制模型或来源 IP，然后保存。完整密钥只显示一次。

<img className="block w-full rounded-lg border border-border dark:hidden" alt="创建 API 密钥对话框" src="/user-guide/zh/api-keys/light/02-create.webp" />
<img className="block w-full rounded-lg border border-border hidden dark:block" alt="创建 API 密钥对话框" src="/user-guide/zh/api-keys/dark/02-create.webp" />

## 接口地址

**接口地址**打开各支持协议的端点 URL 列表，复制与你的客户端匹配的地址（OpenAI 兼容、Responses、Anthropic 等）。
