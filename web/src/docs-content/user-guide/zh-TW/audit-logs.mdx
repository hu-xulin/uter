# 審計日誌

「審計日誌」進入 `/usage-logs/audit`，記錄登入、安全與存取相關事件。

- 支援時間範圍、結果（全部/成功/失敗）與分類篩選。
- 表格展示時間、使用者名稱、事件、IP、用戶端、請求方法與路由。
- 點選「查看」或展開可查看事件詳情，用於排查異常登入、金鑰查看、帳號安全操作等。
