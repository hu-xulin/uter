# 登入

Uter 目前提供三種登入方式：電子郵件驗證碼、GitHub 與 Discord。登入成功即進入主控台；首次使用電子郵件驗證碼登入時，系統會自動建立一般使用者帳號。

## 電子郵件驗證碼登入

1. 開啟登入頁，輸入電子郵件地址。
2. 點選「傳送驗證碼」，查收郵件中的 6 位數字驗證碼。
3. 輸入驗證碼，勾選同意使用者條款與隱私政策。
4. 點選「登入」。

  驗證碼 10 分鐘內有效、僅可使用一次；連續輸入錯誤 5 次後失效，需要重新傳送。未註冊的電子郵件通過驗證後會直接建立帳號，無需另行註冊。
</Callout>

## 使用 GitHub 登入

1. 在登入頁先勾選同意使用者條款與隱私政策。
2. 點選「使用 GitHub 登入」。
3. 在 GitHub 授權頁確認授權，完成後自動返回 Uter 主控台。

## 使用 Discord 登入

1. 在登入頁先勾選同意使用者條款與隱私政策。
2. 點選「使用 Discord 登入」。
3. 在 Discord 授權頁確認授權，完成後自動返回 Uter 主控台。

</Callout>

## 登入後

登入成功後會進入「概覽」。可在「個人資料」查看帳號資訊，在「安全與存取」管理登入工作階段、帳號綁定、存取權杖與安全設定。
