# 登录

Uter 支持三种登录方式：邮箱验证码、GitHub 和 Discord。登录成功后进入控制台；首次使用邮箱验证码登录会自动创建普通账号。

## 邮箱验证码登录

点击**使用邮箱验证码登录**切换到验证码流程，输入邮箱并获取验证码。6 位数字验证码通过邮件发送，有效期 10 分钟。

未注册的新邮箱在验证后会自动成为普通账号，无需单独注册。连续 5 次输错会使验证码失效，需要重新获取。

## GitHub 登录

勾选协议后，选中**使用 GitHub 登录**按钮（下图为选中状态）。Uter 会跳转到 GitHub 完成授权，通过后自动返回控制台。

平台只保存登录所需的基础资料。如果看不到该按钮，说明管理员已停用此登录方式。

## Discord 登录

勾选协议后选中**使用 Discord 登录**按钮（下图为选中状态），在 Discord 端确认授权，成功后自动跳回控制台。

OAuth 登录使用你的 GitHub 或 Discord 身份，之后可在「安全与访问」中绑定或解绑。
