# 任务日志

任务日志跟踪异步作业，例如图片生成、音乐创作等在提交后异步完成的模型任务。

## 任务列表

表格展示**提交时间**、**任务 ID**、**耗时**、**状态**、**进度**、**产物**与**详情**。状态含排队中、处理中、成功与失败。

## 任务详情

点击**查看详情**查看任务负载、进度历史与生成的产物，失败任务还会显示重试信息。
