# 任務日誌

左側導覽「任務日誌」進入 `/usage-logs/task`，頁面頂部可切換「繪圖日誌」與「任務日誌」。

## 繪圖日誌

記錄繪圖類任務。可依時間範圍篩選，查看提交時間、任務 ID、狀態、進度與結果；點選任務可查看詳情或製品。

## 任務日誌

記錄影片、音訊等非同步任務。可依時間範圍與任務 ID 篩選，查看提交時間、耗時、狀態、進度、製品與詳情。

<img className="block w-full rounded-lg border border-border dark:hidden" alt="任務日誌" src="/user-guide/zh/logs-and-tasks/light/03-task-logs.webp" />
<img className="block w-full rounded-lg border border-border hidden dark:block" alt="任務日誌" src="/user-guide/zh/logs-and-tasks/dark/03-task-logs.webp" />

<Callout type="info">
  非同步任務的狀態與進度以伺服器端記錄為準；任務失敗或逾時後可依管道規則自動退款。任務 ID 可用於在「使用日誌」中定位對應的計費記錄。
</Callout>

## 日誌關係

- **使用日誌**：每次模型呼叫的計費與效能明細。
- **審計日誌**：登入、安全與帳號存取事件。
- **繪圖/任務日誌**：非同步任務的生命週期與製品。

排查問題時，建議先用審計日誌確認帳號與存取，再用使用日誌核對計費，最後用任務日誌查看非同步執行結果。
