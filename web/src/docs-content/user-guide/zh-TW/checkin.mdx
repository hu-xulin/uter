# 每日签到

每日签到每天可获得一次随机额度奖励，是日常使用时额外赚取少量额度的简单方式。

## 签到

点击**立即签到**领取当日奖励，每次签到给予随机额度。页面展示累计签到次数与累计奖励。

月历标出已签到的日期，可用**上个月**与**下个月**查看往期记录——每天只能签到一次。
