# 钱包

钱包保存你的额度余额，是充值与订阅的入口。每次请求都会从中扣费；余额用尽时调用会快速失败并提示余额不足。

## 充值

**充值**卡片提供多个预设金额及对应支付价格，并支持在最低限额之上自定义金额。选择**支付方式**——列表由服务端配置决定，可能包含支付宝、微信、Stripe 等。**应付金额**按实时汇率将额度换算为支付币种。

## 订单历史

**订单历史**列出每次充值尝试（含已过期），展示状态（成功／待支付／已过期）与可搜索的交易号。任何客服请求都请附上交易号。

## 订阅计划

**订阅计划**卡片展示各方案的额度、有效期、额度重置周期与购买限制，*推荐*标签标记管理员推荐项。**立即订阅**启动支付流程，已订阅方案在适用时显示升级选项。
