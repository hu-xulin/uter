## 線上儲值

1. 在「新增資金」中選擇預設金額（$10 至 $50,000），或輸入自訂金額。
2. 核對右側的待支付金額（人民幣）。
3. 選擇可用的付款方式（例如支付寶）。
4. 依支付頁面提示完成付款，餘額到帳後可在頂部與「訂單歷史」中核對。

金額與人民幣的換算以頁面即時顯示為準。

## 訂單歷史

點選「訂單歷史」查看儲值交易記錄與付款歷史，支援依訂單號搜尋與切換每頁筆數。

## 兌換碼

在錢包頁「有兌換碼嗎？」區域輸入兌換碼並點選「兌換額度」，額度會加入帳戶餘額。兌換碼通常由管理員或活動發放，輸入前請確認來源可信。

## 推薦計畫

錢包頁底部展示推薦計畫：透過你的推薦連結註冊的使用者會計入邀請人數。面板展示待確認獎勵、總收入與邀請數，可複製推薦連結分享。
