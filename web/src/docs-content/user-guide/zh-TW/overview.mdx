# 概览

概览是登录后的首页，汇总你的余额与用量、展示 API 接入信息，并回答常见的上手问题。

## 用量概览

顶部卡片展示当前余额、今日请求数与近期消耗。这些数字与计费共用同一套额度账本，因此反映真实扣费。

## API 信息

**API 信息**卡片列出接口地址（Base URL）并提供**复制地址**按钮。将兼容 OpenAI 的客户端指向该地址，再用「API 密钥」中的密钥鉴权即可。
