# 设置

设置控制控制台如何通知你以及如何呈现界面。这些偏好按用户保存，不影响其他成员。

## 通知方式

在**通知方式**下启用你需要的渠道——**邮件**、**Webhook**、**Bark** 或 **Gotify**——并配置对应地址，点击**保存设置**生效。

## 通知事项

**接收的通知**可选择哪些事件触发消息，例如余额不足、登录失败或任务完成，让你只关注真正重要的内容。

## 界面语言

在**偏好设置**中设置**界面语言**。用户指南各语言共用同一章节 URL，因此切换语言后仍停留在当前页面。

## 侧边栏个性化

**侧边栏个性化设置**控制**对话区**、**控制台区**与**个人中心区**显示哪些条目。可隐藏不用的板块，或用**恢复默认**还原标准布局。
