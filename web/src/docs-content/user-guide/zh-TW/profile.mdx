# 個人資料

## 個人資料

點選左側導覽「個人資料」進入 `/profile`。頁面頂部顯示頭像、顯示名稱、使用者名稱、使用者 ID、分組、餘額、總用量與請求數。

### 通知與行為偏好

- **通知方式**：電子郵件、Webhook、Bark、Gotify，可依需切換。
- **通知電子郵件**：留空時使用帳號電子郵件。
- **餘額不足提醒**：餘額低於閾值時提醒一次，可自訂提醒閾值（USD）。
- **接受未定價模型**：允許呼叫尚未設定價格的模型；關閉後此類模型會被拒絕。

修改後點選「儲存設定」。

### 語言偏好

「介面語言」決定主控台、文件與 API 錯誤訊息使用的語言。語言偏好會同步到所有已登入裝置。

### 側邊欄個人化

「左側邊欄個人設定」可以依區域隱藏或顯示選單項目：聊天區域（遊樂場、聊天）、管理區域（資料看板、API 金鑰、使用日誌、審計日誌、繪圖日誌、任務日誌）與個人中心區域（錢包、個人資料、安全與存取）。調整後點選「儲存變更」，需要時可用「重設為預設」。

### 每日簽到

每日可簽到一次，獎勵為隨機額度，直接加入帳戶餘額。面板展示累計簽到次數、本月獲得與累計獲得，並提供簽到日曆。
