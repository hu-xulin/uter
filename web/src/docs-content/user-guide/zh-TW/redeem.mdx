# 兑换码

兑换码可为账号增加额度，通常作为推广、推荐奖励或补偿发放。

## 兑换

在**兑换码**输入框填入代码并点击**兑换**。成功后额度立即计入余额，该码随即失效。

## 额度说明

到账额度显示在账户余额卡片中。兑换码为一次性使用；已兑换或已过期的码会报错且不会改变余额。
