# 数据看板

点击左侧导航「数据看板」进入 `/dashboard/models`。看板在同一页面内提供多个视图：

## 模型调用分析

按时间范围、模型和分组查看请求数、Token 数、缓存读写、平均 RPM/TPM、消耗分布和调用趋势。支持柱状图/面积图切换、偏好设置和筛选。
