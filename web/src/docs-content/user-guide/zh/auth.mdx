# 登录

Uter 当前开启三种登录方式：邮箱验证码、GitHub 和 Discord。登录成功即进入控制台；首次使用邮箱验证码登录时，系统会自动创建普通用户账号。

## 邮箱验证码登录

1. 打开登录页，输入邮箱地址。
2. 点击「发送验证码」，查收邮件中的 6 位数字验证码。
3. 输入验证码，勾选同意用户协议和隐私政策。
4. 点击「登录」。

</Callout>

## 使用 GitHub 登录

1. 在登录页先勾选同意用户协议和隐私政策。
2. 点击「使用 GitHub 登录」。
3. 在 GitHub 授权页确认授权，完成后自动返回 Uter 控制台。

## 使用 Discord 登录

1. 在登录页先勾选同意用户协议和隐私政策。
2. 点击「使用 Discord 登录」。
3. 在 Discord 授权页确认授权，完成后自动返回 Uter 控制台。

## 登录后

登录成功后会进入「概览」。可以在「个人资料」查看账号信息，在「安全与访问」管理登录会话、账户绑定、访问令牌和安全设置。
