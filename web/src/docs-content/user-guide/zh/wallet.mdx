## 在线充值

1. 在「添加资金」中选择预设金额（$10 至 $50,000），或输入自定义金额。
2. 核对右侧的待支付金额（人民币）。
3. 选择可用的付款方式（如支付宝）。
4. 按支付页面提示完成付款，余额到账后可在顶部与「订单历史」中核对。

金额与人民币的换算以页面实时显示为准。

## 订单历史

点击「订单历史」查看充值交易记录和付款历史，支持按订单号搜索和切换每页条数。

## 兑换码

在钱包页「有兑换码吗？」区域输入兑换码并点击「兑换额度」，额度会加入账户余额。兑换码通常由管理员或活动发放，输入前请确认来源可信。

## 推荐计划

钱包页底部展示推荐计划：通过你的推荐链接注册的用户会计入邀请人数。面板展示待确认奖励、总收入和邀请数，可复制推荐链接分享。

<img className="block w-full rounded-lg border border-border hidden dark:block" alt="推荐计划" src="/user-guide/zh/wallet-and-subscription/dark/04-referral.webp" />

<Callout type="info">
  推荐链接和奖励规则由平台配置；奖励到账前处于「待确认」状态。不要把推荐链接与 API 密钥混淆，前者只用于邀请注册。
