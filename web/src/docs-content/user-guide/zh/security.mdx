## 登录与认证

- **更改密码**：输入当前密码和新密码完成修改；新密码需满足页面提示的强度要求。
- **账户绑定**：绑定或解绑邮箱、GitHub、Discord。绑定后可使用对应方式登录，解绑前需确保账号仍有其他可用登录方式。

## 登录会话

「登录会话」列出当前账号在不同浏览器和设备上的会话，包括 IP、登录方式、最后活跃时间和到期时间。可以撤销单个会话、退出其他会话，或登出当前会话。

## 访问令牌

访问令牌用于在脚本或自动化工具中调用控制台 API，与用于模型调用的 API 密钥相互独立。创建时可选择：

- **到期时间**：30 天、90 天、180 天、1 年、自定义或永不过期。
- **权限范围**：按「个人」维度授予个人资料、API 密钥、用量、钱包、账户安全等查看/编辑权限，遵循最小权限原则。

令牌只在创建时完整显示一次，请立即保存；不再使用时请及时删除。

## 账户操作与隐私

- **删除账户**：永久删除账号及数据，操作不可恢复。
- **记录 IP 地址**：控制是否在使用日志和错误日志中记录请求 IP；按需开启后保存设置。
