# 推荐计划

推荐计划在新用户通过你的链接加入时给予奖励，累计奖励可转入可消费余额。

## 推荐链接

复制**推荐链接**并分享。新用户通过该链接注册并满足站点规则后，奖励会计入你的推荐收益。

## 转入余额

使用**转入余额**将累计推荐收益转入主余额，用于 API 调用消费。对话框会在转入前确认金额。
