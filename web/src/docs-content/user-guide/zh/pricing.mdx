# 定价

定价页是模型及其价格的实时目录，是发送请求前了解调用成本的权威来源。

## 浏览与筛选

每张卡片展示模型名称、渠道与价格档位。使用**筛选**按渠道或能力收窄，并在**卡片视图**与**表格视图**间切换。**标准**标签标明计费模式。

## 计价口径

价格按每百万 token（**/1M**）或每千（**/1K**）显示，输入与输出分别计价。切换单位可在同一口径下比较不同模型。

## 模型详情

点击模型的**详情**查看完整价目表、支持的能力与上下文限制。使用**复制模型名称**将准确的 ID 粘贴到你的应用中。
