# 审计日志

审计日志记录登录、设置变更与管理操作等安全相关事件，为只读记录，与使用日志相互独立。

## 事件列表

列包括**时间**、**用户名**、**事件**、**IP**、**客户端**、**方法**、**路由**、**HTTP** 状态、**结果**与**详情**。每次登录和配置变更都会留下记录。

## 筛选事件

使用**日期范围**、**结果**与**分类**筛选，再点击**搜索**。这是排查可疑登录最快的方式。

## 事件详情

点击某行的**详情**查看完整内容：操作者、动作、路由、状态以及当时记录的请求上下文。
