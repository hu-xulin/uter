# 审计日志

「审计日志」进入 `/usage-logs/audit`，记录登录、安全与访问相关事件。

- 支持时间范围、结果（全部/成功/失败）和分类筛选。
- 表格展示时间、用户名、事件、IP、客户端、请求方法和路由。
- 点击「查看」或展开可查看事件详情，用于排查异常登录、密钥查看、账户安全操作等。
