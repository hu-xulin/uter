# 个人资料

## 个人资料

点击左侧导航「个人资料」进入 `/profile`。页面顶部显示头像、显示名称、用户名、用户 ID、分组、余额、总用量和请求数。

### 通知与行为偏好

- **通知方式**：邮箱、Webhook、Bark、Gotify，可按需切换。
- **通知邮箱**：留空时使用账户邮箱。
- **余额不足提醒**：余额低于阈值时提醒一次，可自定义提醒阈值（USD）。
- **接受未定价模型**：允许调用尚未配置价格的模型；关闭后此类模型会被拒绝。

修改后点击「保存设置」。

### 语言偏好

「界面语言」决定控制台、文档和 API 错误消息使用的语言。语言偏好会同步到所有已登录设备。

### 侧边栏个性化

「左侧边栏个人设置」可以按区域隐藏或显示菜单项：聊天区域（游乐场、聊天）、管理区域（数据看板、API 密钥、使用日志、审计日志、绘图日志、任务日志）和个人中心区域（钱包、个人资料、安全与访问）。调整后点击「保存更改」，需要时可用「重置为默认」。

### 每日签到

每日可签到一次，奖励为随机额度，直接加入账户余额。面板展示累计签到次数、本月获得和累计获得，并提供签到日历。
