# 排行

「排行」页展示平台实时用量数据，可切换「今天」「本周」「本月」「今年」。

<img className="block w-full rounded-lg border border-border dark:hidden" alt="排行榜" src="/user-guide/zh/pricing-and-ranking/light/02-leaderboard.webp" />
<img className="block w-full rounded-lg border border-border hidden dark:block" alt="排行榜" src="/user-guide/zh/pricing-and-ranking/dark/02-leaderboard.webp" />

- **热门模型**：各模型每周 Token 用量趋势。
- **LLM 排行**：最受欢迎模型及周环比变化。
- **市场份额**：各厂商 Token 占比。
- **按模型厂商**：厂商聚合用量和占比。
- **上升/下降趋势**：排名变化明显的模型。

<Callout type="info">
  排行榜基于平台真实用量聚合，数据会随时间更新；用量较少的模型可能不会出现在榜单中。
</Callout>
