# API キー

API キーは Uter のモデル API を呼び出すための資格情報です。左ナビゲーション「API キー」で `/keys` を開きます。上部の「API アドレス」メニューで次の 3 つを切り替えてコピーできます。

- `https://api.uter.ai`: CN2 GIA 最適化、グローバル（既定）。
- `https://api.uter.cc`: 中国本土向け。
- `https://api.uter.pro`: 海外向け。

一覧には名前、状態、マスクされたキー、クォータ、グループ、モデル制限、IP 制限、作成/最終使用時刻、有効期限が表示されます。名前・キー・状態で絞り込めます。

## API キーを作成

1. 右上の「API キーを作成」を押します。
2. 名前を入力し、グループを選択します。
3. 有効期限を設定します（無期限、1 か月、1 日、1 時間、カスタム）。
4. 作成数を指定します（2 以上は名前にランダムな接尾辞）。
5. 「無制限クォータ」を有効にするか、金額を指定します。
6. 「詳細設定」でモデル制限・IP 制限などを設定します。
7. 「変更を保存」を押します。

## 表示・コピー・管理

- **表示/コピー**: キーまたはコピーボタンを押します。完全なキーの表示は機密操作で、セキュリティ確認が必要です。確認手段がない場合は先に設定するよう案内されます。
- **行メニュー**: キーのコピー、接続情報のコピー、アプリ連携、削除。
- **有効/無効**: 無効化すると API を呼べなくなりますが、記録は残ります。
- **編集**: 名前、グループ、クォータ、有効期限、アクセス制限を変更します。

## キーを使う

リクエストヘッダーにキーを含めます。

```bash
curl https://api.uter.ai/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-あなたのキー" \
  -d '{"model":"MiniMax-M2.5","messages":[{"role":"user","content":"こんにちは"}]}'
```

<Callout type="info">
  キーはアカウントの資格情報です。フロントエンド、公開リポジトリ、チャットに記載しないでください。漏洩時は無効化・削除し、新しいキーを作成してください。削除前に本番利用がないか確認してください。
</Callout>
