# プロフィール

## プロフィール

左ナビゲーションの「プロフィール」で `/profile` を開きます。上部にアバター、表示名、ユーザー名、ID、グループ、残高、累計使用量、リクエスト数を表示します。

### 通知と動作設定

- **通知方法**: メール、Webhook、Bark、Gotify。
- **通知メール**: 空欄ならアカウントのメール。
- **残高不足通知**: しきい値（USD）を下回った時に 1 回通知。
- **未価格モデルの許可**: 価格未設定のモデルを許可。オフなら拒否。

変更後「設定を保存」を押します。

### 言語設定

「表示言語」はコンソール、ドキュメント、API エラーメッセージの言語を決め、ログイン中の全端末に同期されます。

<img className="block w-full rounded-lg border border-border hidden dark:block" alt="言語設定" src="/user-guide/en/profile-and-security/dark/05-personal-language-preferences.webp" />

### サイドバーの個人設定

「左サイドバー個人設定」で領域別にメニューを表示/非表示にできます。チャット（プレイグラウンド、チャット）、管理（ダッシュボード、API キー、各ログ）、個人（ウォレット、プロフィール、セキュリティとアクセス）。保存または既定に戻せます。

### 毎日のチェックイン

1 日 1 回チェックインするとランダムなクォータが残高に加算されます。累計回数、今月分、累計報酬、カレンダーを表示します。
