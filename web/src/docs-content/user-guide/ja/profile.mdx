# Settings

Settings controls how the console notifies you and presents itself. These preferences are per-user and do not affect other members.

## Notification methods

Under **Notification Method**, enable the channels you want — **Email**, **Webhook**, **Bark** or **Gotify** — and configure their endpoints. Press **Save Settings** to apply.

## Events you are notified about

**Notifications to receive** lets you choose which events trigger a message, such as low balance, failed login or completed task, so you only hear about what matters.

## Interface language

In **Preferences**, set the **Interface Language**. The guide serves the same chapter URL in every language, so switching language keeps you on the same page.

## Sidebar personalization

**Sidebar Personal Settings** controls which items appear in the **Chat Area**, **Console Area** and **Personal Center Area**. Hide sections you never use with **Reset to Default** to restore the standard layout.
