# Playground

The Playground lets you try any available model directly in the browser, with no API key or code. It is the fastest way to compare answers and tune parameters before integrating.

## Start a chat

The main chat area shows the conversation as a transcript. Type a message and press **Send** to call the selected model; replies stream in token by token. **Clear chat history** resets the conversation.

The **Attach** button adds files for models that accept them, and **Search** enables web lookup where supported.

## Prompt suggestions

Quick prompts such as **Analyze data**, **Summarize text**, **Code** and **Get advice** fill the input with a ready-made instruction. They are useful starting points when you want to probe a model’s strengths quickly.

## Choose a model

The model selector at the bottom switches between the models you are entitled to use. Each entry shows the model id and its provider tag, so you can test exactly the same model your API calls will hit.

## Tune parameters

Open **Parameters** to adjust sampling controls such as temperature and top-p. Lower values make answers more deterministic; higher values increase variety. Changes apply to the next message only.
