# ランキング

「ランキング」はプラットフォームのリアルタイム使用量を表示し、今日/今週/今月/今年を切り替えられます。

<img className="block w-full rounded-lg border border-border dark:hidden" alt="ランキング" src="/user-guide/en/pricing-and-ranking/light/02-leaderboard.webp" />
<img className="block w-full rounded-lg border border-border hidden dark:block" alt="ランキング" src="/user-guide/en/pricing-and-ranking/dark/02-leaderboard.webp" />

- **人気モデル**: モデル別の週次トークン推移。
- **LLM ランキング**: 人気モデルと前週比。
- **市場シェア**: ベンダー別トークン比率。
- **ベンダー別**: 集計使用量とシェア。
- **上昇/下降**: 順位変動の大きいモデル。

<Callout type="info">
  ランキングは実際の使用量を集計し随時更新されます。利用の少ないモデルは表示されない場合があります。
</Callout>
