# 監査ログ

「監査ログ」は `/usage-logs/audit` を開き、ログイン・セキュリティ・アクセスに関するイベントを記録します。

- 期間、結果（すべて/成功/失敗）、カテゴリで絞り込めます。
- 表には時刻、ユーザー名、イベント、IP、クライアント、メソッド、ルートを表示します。
- 「表示」または展開で詳細を確認でき、不審なログイン、キー表示、アカウント安全操作の調査に使えます。
