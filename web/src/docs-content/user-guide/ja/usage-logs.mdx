# 利用履歴

左ナビゲーションの「利用履歴」で `/usage-logs/common` を開き、すべてのモデル呼び出しを記録します。

- **フィルター**: 期間、モデル名、グループ、種類、さらにキー・ユーザーなど。
- **サマリーバー**: 絞り込み結果の合計使用量、RPM、TPM、キャッシュ読み書きと各段階の差分。
- **表**: 時刻、キー、モデル、ストリーミング可否、トークン、費用、所要時間、詳細。
- **操作**: リセット、検索、エクスポート、ページサイズ、ページ送り、詳細。
