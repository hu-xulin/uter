# ウォレット

## ウォレット概要

左ナビゲーションの「ウォレット」で `/wallet` を開きます。上部に残高、累計使用量、API リクエスト数を表示します。

## オンラインチャージ

1. 「資金を追加」でプリセット（$10〜$50,000）または任意の金額を選びます。
2. 右側の支払額（人民元）を確認します。
3. 利用可能な支払い方法（例: Alipay）を選びます。
4. 支払いを完了すると残高が反映され、上部と注文履歴で確認できます。

換算はページの表示が基準です。

## 引き換えコード

「引き換えコードはありますか？」欄に入力して「引き換え」を押すと、クォータが残高に加算されます。コードは管理者やキャンペーンが発行します。信頼できる入手元か確認してください。

## 紹介プログラム

ウォレット下部に紹介プログラムがあります。リンク経由の登録が招待数に数えられます。パネルには確定待ち報酬、累計収益、招待数、リンクのコピーがあります。

  紹介リンクと報酬規則はプラットフォームが設定し、報酬は確定まで待機状態です。紹介リンクと API キーを混同しないでください。
