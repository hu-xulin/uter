# 価格設定

「価格設定」は有効なモデルを一覧し、チャネル・ベンダー・種類・タグで絞り込めます。検索はモデル名、プロバイダー、エンドポイント、タグに対応します。

### 絞り込みと表示

- **チャネル**: Uter チャネル、ベンダーチャネルなど。数字はチャネル内のモデル数。
- **ベンダー**: Anthropic、Google、OpenAI、ByteDance、Alibaba、DeepSeek、Meta、Z.ai、Moonshot、MiniMax など。
- **タグ**: 推論、ツール、視覚など。
- **表示**: 標準、チャージ（人民元）、`/1M`、`/1K`。
- **並び順とレイアウト**: 名前順、リスト/グリッド切替。

### モデルカード

カードには名前、ベンダー、概要、タグ、課金方式、Uter 単価、公式単価、割引、グループ、エンドポイント、状態、遅延/スループットを表示します。「詳細」で全文を開きます。

詳細には、概要（TPS、平均遅延、成功率、基本料金、グループ別料金）、性能、API 例、コンテキスト（最大入出力、モダリティ、知識カットオフ、公開日）が含まれます。
