# ダッシュボード

左ナビゲーションの「ダッシュボード」で `/dashboard/models` を開きます。1 ページに複数のビューがあります。

## モデル分析

期間・モデル・グループで絞り込み、リクエスト数、トークン、キャッシュ読み書き、平均 RPM/TPM、消費分布、推移を確認します。棒/面グラフの切替、設定、フィルターに対応します。

## トラフィック分流

ユーザー、API キー、グループ、モデル、チャネル間のリクエスト分布を確認し、流入元とチャネル利用を把握します。
