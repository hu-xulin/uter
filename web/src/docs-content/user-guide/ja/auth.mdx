# ログイン

Uter は現在、メール認証コード・GitHub・Discord の 3 つのログイン方法を提供しています。ログインするとコンソールに入り、初回のメールコードログインでは一般ユーザーアカウントが自動作成されます。

## メール認証コードでログイン

1. ログインページでメールアドレスを入力します。
2. 「コードを送信」を押し、メールの 6 桁コードを確認します。
3. コードを入力し、利用規約とプライバシーポリシーに同意します。
4. 「ログイン」を押します。

<img className="block w-full rounded-lg border border-border hidden dark:block" alt="メールコードによるログイン" src="/user-guide/en/auth/dark/01-login.webp" />

<Callout type="info">
  コードは 10 分間有効で 1 回のみ使用できます。5 回間違えると無効になり再送が必要です。未登録のメールは認証後にそのままアカウントが作成されます。
</Callout>

## GitHub でログイン

1. 利用規約とプライバシーポリシーに同意します。
2. 「GitHub で続行」を押します。
3. GitHub で認可すると Uter コンソールに戻ります。

## Discord でログイン

1. 利用規約とプライバシーポリシーに同意します。
2. 「Discord で続行」を押します。
3. Discord で認可すると Uter コンソールに戻ります。

<img className="block w-full rounded-lg border border-border dark:hidden" alt="GitHub と Discord のログイン" src="/user-guide/en/auth/light/02-login.webp" />
<img className="block w-full rounded-lg border border-border hidden dark:block" alt="GitHub と Discord のログイン" src="/user-guide/en/auth/dark/02-login.webp" />

<Callout type="info">
  GitHub / Discord は各サービスのアカウントで認可します。Uter はログインに必要な基本情報のみ保存します。ボタンが表示されない場合は無効化されています。
</Callout>

## ログイン後

「概要」に移動します。「プロフィール」でアカウント情報、「セキュリティとアクセス」でセッション・連携・アクセストークン・セキュリティ設定を管理できます。
