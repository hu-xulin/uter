# Overview

Overview is the landing page after sign-in. It summarises your balance and usage, exposes the API connection details, and answers common onboarding questions.

## Setup guide

On your first visit, the **setup guide** is expanded at the top of the page, bringing everything you need before going live into one place. It lists three steps in order: **Create an API Key** (generate a credential for your app or service), **Add credits** (keep a healthy balance before production traffic), and **Send a request** (verify routing with the Playground or your own client). Completed steps show a check mark.

On the right, the guide shows a **First API request** example you can copy in one click, plus three live readiness indicators: **Route active**, **Auth configured**, and **Model selected**. The **Recommended actions** column on the far right links to API Keys, Usage Logs, and Pricing. Once you are connected, click **Hide setup guide** to collapse it.

## Usage at a glance

The top cards show your current balance, today’s requests and recent consumption. These numbers come from the same quota ledger that billing uses, so they reflect real deductions.

## API info

The **API Info** card lists your Base URL and shows a **Copy URL** button. Point your OpenAI-compatible client at this address, then use a key from API Keys to authenticate.

The **Uptime** panel reports service availability over time. A dip here usually corresponds to a maintenance window or an upstream provider incident.
