# Portefeuille

Portefeuille ouvre `/wallet` ; le haut affiche le solde, l'usage total et le nombre de requêtes API.

## Recharge

1. Dans « Ajouter des fonds », choisissez un montant prédéfini (10 $ à 50 000 $) ou un montant libre.
2. Vérifiez le montant à payer (CNY) à droite.
3. Choisissez un moyen de paiement disponible (par ex. Alipay).
4. Finalisez le paiement ; le solde apparaît en haut et dans l'historique des commandes.

La conversion affichée sur la page fait foi.

## Code de remboursement

Saisissez un code dans « Vous avez un code ? » et cliquez sur « Échanger ». Le quota est ajouté au solde. Les codes proviennent des administrateurs ou d'opérations ; vérifiez la source.

## Programme de parrainage

Le bas de la page présente le parrainage : les inscriptions via votre lien comptent comme invitations. Le panneau affiche récompenses en attente, gains totaux et nombre d'invitations, avec copie du lien.

<Callout type="info">
  Les liens et règles de parrainage sont configurés par la plateforme ; les récompenses restent en attente jusqu'à confirmation. Ne confondez pas un lien de parrainage avec une clé API.
