## Connexion et authentification

- **Changer le mot de passe** : saisissez l'ancien et le nouveau ; le nouveau doit respecter les règles affichées.
- **Liaisons de compte** : liez ou déliez e-mail, GitHub et Discord. Gardez au moins une méthode utilisable avant de délier.

## Sessions de connexion

## Jetons d’accès

Les jetons d'accès appellent l'API de la console depuis des scripts ; ils sont distincts des clés API de modèles. À la création :

- **Expiration** : 30/90/180 jours, 1 an, personnalisée ou jamais.
- **Portées** : lecture/écriture personnelles pour profil, clés API, usage, portefeuille et sécurité, selon le moindre privilège.

Le jeton n'est affiché qu'une fois — conservez-le immédiatement et supprimez-le ensuite.

## Opérations de compte et confidentialité

- **Supprimer le compte** : suppression définitive, irréversible.
- **Enregistrer l'IP** : enregistre ou non l'IP des requêtes dans les journaux d'usage et d'erreur.

<Callout type="info">
  Mots de passe, clés, sessions et suppression de compte sont sensibles : vérifiez le compte, la cible et l'impact avant d'agir.
</Callout>
