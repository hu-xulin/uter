# Clés API

Les clés API appellent les endpoints de modèles d'Uter. Ouvrez `/keys` depuis la navigation gauche. Le menu d'adresse API en haut bascule et copie trois endpoints :

- `https://api.uter.ai` : optimisé CN2 GIA, mondial (par défaut).
- `https://api.uter.cc` : optimisé pour la Chine continentale.
- `https://api.uter.pro` : optimisé pour l'étranger.

La liste affiche nom, état, clé masquée, quota, groupe, limites de modèles, limites IP, création/dernière utilisation et expiration. Filtrez par nom ou clé et par état.

## Créer une clé API

1. Cliquez sur « Créer une clé API ».
2. Saisissez un nom et choisissez un groupe.
3. Définissez l'expiration : jamais, 1 mois, 1 jour, 1 heure ou personnalisée.
4. Choisissez la quantité ; au-delà de 1, un suffixe aléatoire est ajouté.
5. Activez « Quota illimité » ou fixez un montant.
6. Dépliez « Paramètres avancés » pour les limites de modèles et d'IP.
7. Cliquez sur « Enregistrer ».

## Voir, copier et gérer

- **Voir/copier** : cliquez sur la clé ou le bouton de copie. Afficher la clé complète est sensible et exige une vérification de sécurité ; la page invite à en configurer une si nécessaire.
- **Menu de ligne** : copier la clé, copier les infos de connexion, ouvrir l'intégration ou supprimer.
- **Activer/désactiver** : une clé désactivée ne peut plus appeler l'API ; les enregistrements restent.
- **Modifier** : nom, groupe, quota, expiration et contraintes d'accès.

## Utiliser la clé

Placez la clé dans l'en-tête :

```bash
curl https://api.uter.ai/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-votre-cle" \
  -d '{"model":"MiniMax-M2.5","messages":[{"role":"user","content":"bonjour"}]}'
```

<Callout type="info">
  Une clé est un identifiant de compte : jamais dans le code front-end, un dépôt public ou une conversation. En cas de fuite, désactivez-la et supprimez-la, puis créez-en une nouvelle. Vérifiez qu'aucun service ne l'utilise avant suppression.
</Callout>
