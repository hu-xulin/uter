# Profil

## Profil

Profil ouvre `/profile`. Le haut affiche avatar, nom affiché, nom d'utilisateur, ID, groupe, solde, usage total et nombre de requêtes.

### Notifications et comportement

- **Moyen de notification** : e-mail, Webhook, Bark ou Gotify.
- **E-mail de notification** : vide = e-mail du compte.
- **Alerte de solde faible** : un avertissement sous un seuil (USD, réglable).
- **Accepter les modèles sans prix** : autoriser les modèles non tarifés ; sinon ils sont refusés.

Cliquez sur « Enregistrer » après modification.

### Langue

La langue de l'interface s'applique à la console, à la documentation et aux messages d'erreur API. Elle se synchronise sur tous les appareils connectés.

### Personnalisation de la barre latérale

Les paramètres de barre latérale masquent ou affichent des éléments par zone : chat (Aire de jeux, Chat), administration (Tableau de bord, Clés API, Journaux) et personnel (Portefeuille, Profil, Sécurité et accès). Enregistrez ou réinitialisez.

### Pointage quotidien

Un pointage par jour donne un quota aléatoire ajouté au solde. Le panneau affiche le total, le mois et le cumul, avec un calendrier.
