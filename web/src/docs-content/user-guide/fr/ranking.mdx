# Classement

Le Classement affiche l'usage en direct et bascule entre Aujourd'hui, Cette semaine, Ce mois et Cette année.

<img className="block w-full rounded-lg border border-border dark:hidden" alt="Classement" src="/user-guide/en/pricing-and-ranking/light/02-leaderboard.webp" />
<img className="block w-full rounded-lg border border-border hidden dark:block" alt="Classement" src="/user-guide/en/pricing-and-ranking/dark/02-leaderboard.webp" />

- **Modèles populaires** : tendance hebdomadaire des tokens.
- **Classement LLM** : modèles les plus utilisés et variation hebdomadaire.
- **Part de marché** : part des tokens par fournisseur.
- **Par fournisseur** : usage agrégé et part.
- **Progressions/reculs** : modèles aux variations notables.

<Callout type="info">
  Le classement agrège l'usage réel et se met à jour ; les modèles peu utilisés peuvent être absents.
</Callout>
