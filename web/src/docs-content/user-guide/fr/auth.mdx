# Connexion

Uter propose trois méthodes de connexion : code par e-mail, GitHub et Discord. Une connexion réussie ouvre la console ; la première connexion par code crée automatiquement un compte utilisateur standard.

## Connexion par code e-mail

1. Ouvrez la page de connexion et saisissez votre adresse e-mail.
2. Cliquez sur « Envoyer le code » et utilisez le code à 6 chiffres reçu.
3. Saisissez le code et acceptez les conditions d'utilisation et la politique de confidentialité.
4. Cliquez sur « Se connecter ».

<Callout type="info">
  Le code est valable 10 minutes et à usage unique ; cinq erreurs l'invalident et il faut en demander un autre. Une adresse inconnue devient un nouveau compte après vérification, sans inscription séparée.
</Callout>

## Se connecter avec GitHub

1. Acceptez les conditions et la politique de confidentialité.
2. Cliquez sur « Continuer avec GitHub ».
3. Confirmez sur GitHub ; vous revenez automatiquement dans la console Uter.

## Se connecter avec Discord

1. Acceptez les conditions et la politique de confidentialité.
2. Cliquez sur « Continuer avec Discord ».
3. Confirmez sur Discord ; vous revenez automatiquement dans la console Uter.

<Callout type="info">
  GitHub et Discord utilisent leurs propres comptes pour l'autorisation ; Uter ne conserve que les informations de base nécessaires. Un bouton absent signifie que la méthode est désactivée.
</Callout>

## Après la connexion

Vous arrivez sur la Vue d'ensemble. Le Profil affiche vos informations, et Sécurité et accès gère les sessions, les liaisons de compte, les jetons d'accès et les paramètres de sécurité.
