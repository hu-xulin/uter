# Journaux d’utilisation

Journaux d'utilisation ouvre `/usage-logs/common` et enregistre chaque appel de modèle.

- **Filtres** : période, modèle, groupe et type, puis clé, utilisateur et autres conditions.
- **Barre de synthèse** : usage total du filtre, RPM, TPM, lectures/écritures de cache et variation de chaque étape.
- **Tableau** : heure, clé, modèle, streaming, tokens, coût, latence et détails.
- **Actions** : réinitialiser, rechercher, exporter, taille de page, pagination, détails.
