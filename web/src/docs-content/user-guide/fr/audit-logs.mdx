# Audit Logs

Audit logs capture security-relevant events such as logins, settings changes and administrative actions. They are read-only and independent of usage logs.

## Event list

Columns include **Time**, **Username**, **Event**, **IP**, **Client**, **Method**, **Route**, **HTTP** status, **Result** and **Details**. Every sign-in and configuration change leaves an entry.

## Filter events

Narrow the list with **Date Range**, **Result** and **Category** filters, then press **Search**. This is the fastest way to investigate a suspicious login.

<img className="block w-full rounded-lg border border-border dark:hidden" alt="Audit filters" src="/user-guide/en/audit-logs/light/02-filters.webp" />
<img className="block w-full rounded-lg border border-border hidden dark:block" alt="Audit filters" src="/user-guide/en/audit-logs/dark/02-filters.webp" />

## Event details

Press **Details** on a row to see the full payload: actor, action, route, status and the request context recorded at the time.
