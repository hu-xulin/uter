# Journaux d’audit

Journaux d'audit ouvre `/usage-logs/audit` et enregistre les événements de connexion, de sécurité et d'accès.

- Filtrez par période, résultat (tous/succès/échec) et catégorie.
- Le tableau affiche heure, utilisateur, événement, IP, client, méthode et route.
- « Voir » ou le dépliage affiche les détails, utile pour les connexions inhabituelles, l'affichage de clés et les actions de sécurité.
