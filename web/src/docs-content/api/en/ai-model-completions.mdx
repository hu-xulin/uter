# Native OpenAI Format

## Native OpenAI Format

Create a text completion based on the given prompt

`POST` `/v1/completions`

### Request body (`application/json`)

| Field | Type | Required | Description |
|---|---|---|---|
| `model` | string | Yes | — |
| `max_tokens` | integer | No | — |
| `temperature` | number | No | — |
| `top_p` | number | No | — |
| `n` | integer | No | — |
| `stream` | boolean | No | — |
| `suffix` | string | No | — |
| `echo` | boolean | No | — |

### Response

| Status | Meaning |
|---|---|
| `200` | Response created |

#### `200` fields

| Field | Type | Description |
|---|---|---|
| `id` | string | — |
| `object` | string | — |
| `created` | integer | — |
| `model` | string | — |
| `choices` | array&lt;object&gt; | — |
| `usage.prompt_tokens` | integer | Prompt token count |
| `usage.completion_tokens` | integer | Completion token count |
| `usage.total_tokens` | integer | Total token count |
| `usage.prompt_tokens_details.cached_tokens` | integer | — |
| `usage.prompt_tokens_details.text_tokens` | integer | — |
| `usage.prompt_tokens_details.audio_tokens` | integer | — |
| `usage.prompt_tokens_details.image_tokens` | integer | — |
| `usage.completion_tokens_details.text_tokens` | integer | — |
| `usage.completion_tokens_details.audio_tokens` | integer | — |
| `usage.completion_tokens_details.reasoning_tokens` | integer | — |
