# Jimeng Video Generation

## Jimeng Video Generation

Video generation API in the official Jimeng API format.

The operation type can be specified with the Action parameter:
- `CVSync2AsyncSubmitTask`: Submit a video generation task
- `CVSync2AsyncGetResult`: Get the task result

Action and Version must be specified in the query parameters.

`POST` `/jimeng/`

### Request parameters

| Parameter | In | Type | Required | Description |
|---|---|---|---|---|
| `Action` | query | enum (`CVSync2AsyncSubmitTask`, `CVSync2AsyncGetResult`) | Yes | API operation type |
| `Version` | query | string | Yes | API version |

### Request body (`application/json`)

| Field | Type | Required | Description |
|---|---|---|---|
| `req_key` | string | No | Request type identifier |
| `prompt` | string | No | Text description |
| `binary_data_base64` | array&lt;string&gt; | No | Base64-encoded image data |

### Response

| Status | Meaning |
|---|---|
| `200` | Request processed successfully |
| `400` | Invalid request parameters |

#### `200` fields

| Field | Type | Description |
|---|---|---|
| `code` | integer | Response code |
| `message` | string | Response message |
| `data` | object | Response data |

#### `400` fields

| Field | Type | Description |
|---|---|---|
| `error.message` | string | Error message |
| `error.type` | string | Error type |
| `error.param` | string | Related parameter |
| `error.code` | string | Error code |
