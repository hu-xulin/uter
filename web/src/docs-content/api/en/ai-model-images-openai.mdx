# Native OpenAI Format

Uter's image endpoints are compatible with the OpenAI Images API. Only models returned by `GET /v1/models` can be used; supported sizes, quality levels and model-specific parameters differ, and out-of-range values are rejected with `400`.

## Generate an image

`POST` `/v1/images/generations`

### Request body (`application/json`)

| Field | Type | Required | Description |
|---|---|---|---|
| `model` | string | Yes | Image model ID from `GET /v1/models` |
| `prompt` | string | Yes | Image description |
| `n` | integer | No | Number of images, 1–128 (platform cap), default 1 |
| `size` | string | No | Image size, e.g. `1024x1024`; accepted values depend on the model |
| `quality` | string | No | Quality tier; accepted values depend on the model |
| `response_format` | enum (`url`, `b64_json`) | No | Response format, default `url` |
| `background` | string | No | Background mode (`transparent` / `opaque` / `auto`); model-specific |
| `output_format` | string | No | Output format (`png` / `jpeg` / `webp`); model-specific |
| `output_compression` | integer | No | Output compression; model-specific |
| `moderation` | string | No | Moderation level; model-specific |
| `stream` | boolean | No | Stream partial images; model-specific |
| `user` | string | No | Caller-supplied user identifier |

### Response

| Status | Meaning |
|---|---|
| `200` | Generated |
| `400` | Invalid parameters (including `n` over the cap or a size the model rejects) |
| `403` | Insufficient quota |

#### `200` fields

| Field | Type | Description |
|---|---|---|
| `created` | integer | Creation time (Unix seconds) |
| `data` | array&lt;object&gt; | Results |
| `data[].url` | string | Image URL (`response_format=url`) |
| `data[].b64_json` | string | Base64 image data (`response_format=b64_json`) |
| `data[].revised_prompt` | string | Upstream-rewritten prompt, when returned |
| `metadata` | object | Extra upstream metadata, when present |

## Edit an image

`POST` `/v1/images/edits`

### Request body (`multipart/form-data`)

| Field | Type | Required | Description |
|---|---|---|---|
| `image` | file (or string array) | Yes | Image(s) to edit; some models accept multiple inputs |
| `mask` | file | No | Mask whose transparent area marks the region to repaint |
| `prompt` | string | Yes | Edit description |
| `model` | string | Yes | Image model ID from `GET /v1/models` |
| `n` | integer | No | Number of images, 1–128 (platform cap), default 1 |
| `size` | string | No | Output size; accepted values depend on the model |
| `response_format` | enum (`url`, `b64_json`) | No | Response format, default `url` |
| `user` | string | No | Caller-supplied user identifier |

### Response

Same structure as "Generate an image"; the fields inside `data` follow `response_format`.
