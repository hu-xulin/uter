# Native OpenAI Format

## Native OpenAI Format

Establish a WebSocket connection for real-time conversations.

**Note**: This is a WebSocket endpoint and must be connected using the WebSocket protocol.

Connection URL example: `wss://uter.ai/v1/realtime?model=gpt-4o-realtime`

Authentication: send `Authorization: Bearer sk-...` in the handshake headers. Browser clients that cannot set headers can use the `Sec-WebSocket-Protocol: openai-insecure-api-key.sk-...` subprotocol instead.

`GET` `/v1/realtime`

### Request Parameters

| Name | In | Type | Required | Description |
|---|---|---|---|---|
| `model` | query | string | No | Model to use |

### Response

| Status | Description |
|---|---|
| `101` | WebSocket protocol switch |
| `400` | Bad request |

#### `400` Response Fields

| Field | Type | Description |
|---|---|---|
| `error.message` | string | Error message |
| `error.type` | string | Error type |
| `error.param` | string | Related parameter |
| `error.code` | string | Error code |
