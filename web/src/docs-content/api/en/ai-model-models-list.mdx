# Models

Uter exposes four model lookup endpoints:

| Endpoint | Description |
|---|---|
| `GET /v1/models` | Models the current token can call |
| `GET /v1/models/{model}` | One model's details |
| `GET /v1beta/models` | The same list in native Gemini format |
| `GET /v1beta/openai/models` | The same list in OpenAI format (Gemini-compatible entry point) |

The list is filtered by the token's group, its model allowlist and model billing configuration. Trust the returned list and do not hardcode model names.

`GET /v1/models` selects the response format from the request headers:

- `x-api-key` and `anthropic-version` headers → Anthropic format
- `x-goog-api-key` header or `key` query parameter → Gemini format
- Otherwise → OpenAI format

See "Native OpenAI Format" and "Native Gemini Format" for the fields and example responses of each format.
