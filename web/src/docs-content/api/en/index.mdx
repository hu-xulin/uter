# API Reference

## Access

| Item | Value |
|---|---|
| Base URL | `https://uter.ai` (API-only entry point: `https://api.uter.ai`) |
| Authentication | `Authorization: Bearer sk-...` |
| Token | Created on the console's Tokens page; can be limited to a group, a model allowlist and source IPs |

Claude format (`/v1/messages`) also accepts an `x-api-key` header; Gemini format (`/v1beta/models/...`) accepts an `x-goog-api-key` header or a `?key=` query parameter. WebSocket endpoints additionally accept the `Sec-WebSocket-Protocol: openai-insecure-api-key.<key>` subprotocol for browser clients that cannot set headers.

## Error format

The error envelope depends on the endpoint family. Always branch on the body, not only the HTTP status:

| Family | Envelope | Example |
|---|---|---|
| OpenAI / Responses / Embeddings / Audio / Moderations / Rerank / Gemini | OpenAI | `{"error": {"message": "...", "type": "...", "param": "", "code": "..."}}` |
| Claude (`/v1/messages`) | Anthropic | `{"type": "error", "error": {"type": "...", "message": "..."}}` |
| Video / generic tasks (`/v1/video/generations`, `/v1/videos`, `/v1/tasks/*`) | Flat task error | `{"code": "task_not_exist", "message": "...", "data": {}}` |
| Auth / rate limit (middleware) | OpenAI without `param` | `{"error": {"message": "...", "type": "new_api_error", "code": "..."}}` |

A few endpoints are exceptions: `GET /v1/models/{model}` returns `200` with an OpenAI error body for an unknown model, and `GET /v1/videos/{id}/content` returns `404` for a missing task while the generic task query returns `400 task_not_exist`.

Which models a token can call is decided by its group, the token's model allowlist and the model's billing configuration. Always use the model names returned by `GET /v1/models`; do not guess model IDs.

## Billing and limits

- When a request is accepted, quota is pre-deducted from the model price and the estimated usage, then settled against the actual usage. Failed requests and tasks that produced no output are refunded.
- Insufficient quota returns `403`; rate limiting or saturated upstream concurrency returns `429`; an unknown model or no channel available in the current group returns `503`.
- Image generation count `n` is capped at 128. Video duration, resolution and batch size follow the selected model's limits; out-of-range requests are rejected before acceptance.

## Not implemented

`/v1/files*`, `/v1/fine-tunes*`, `/v1/images/variations` and `DELETE /v1/models/{model}` currently return `501`. Gemini `:countTokens` returns `404`. Do not call them in production. Fine-tuning is documented separately on the [fine-tuning page](./ai-model-unimplemented-fine-tuning).
