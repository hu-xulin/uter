# Native Gemini Format

Returns the available models in the Gemini API format.

Authentication: use the `?key=sk-...` query parameter or the `x-goog-api-key` header. The list is filtered by the token's group and model allowlist.

`GET` `/v1beta/models`

### Response

| Status | Meaning |
|---|---|
| `200` | Model list returned |
| `401` | Authentication failed |

#### `200` fields

| Field | Type | Description |
|---|---|---|
| `models` | array&lt;object&gt; | Models |
| `models[].name` | string | Model ID (no `models/` prefix), used verbatim in requests |
| `models[].displayName` | string | Display name |
| `nextPageToken` | null | Always `null`; paging is not supported |
