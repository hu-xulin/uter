# qwen

## Generate Images

Bailian qwen-image series image generation

`POST` `/v1/images/generations`

### Request body (`application/json`)

| Field | Type | Required | Description |
|---|---|---|---|
| `model` | string | Yes | — |
| `input.messages` | array&lt;object&gt; | No | — |
| `parameters.negative_prompt` | string | No | — |
| `parameters.prompt_extend` | boolean | No | — |
| `parameters.watermark` | boolean | No | — |
| `parameters.size` | string | No | — |

### Response

| Status | Meaning |
|---|---|
| `200` | Image generated successfully |

#### `200` fields

| Field | Type | Description |
|---|---|---|
| `created` | integer | — |
| `data` | array&lt;object&gt; | — |
