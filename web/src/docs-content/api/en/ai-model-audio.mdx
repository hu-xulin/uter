# Native Gemini Format

## Native Gemini Format

Gemini audio generation API.
You can use models such as gemini-2.5-flash-preview-tts.

`POST` `/v1beta/models/{model}:generateContent`

### Request parameters

| Parameter | In | Type | Required | Description |
|---|---|---|---|---|
| `model` | path | string | Yes | Model name |

### Request body (`application/json`)

| Field | Type | Required | Description |
|---|---|---|---|
| `contents` | array&lt;object&gt; | Yes | — |
| `generationConfig.responseModalities` | array&lt;string&gt; | No | — |

### Response

| Status | Meaning |
|---|---|
| `200` | Success |

#### `200` fields

| Field | Type | Description |
|---|---|---|
| `candidates` | array&lt;object&gt; | — |
| `usageMetadata.promptTokenCount` | integer | — |
| `usageMetadata.candidatesTokenCount` | integer | — |
| `usageMetadata.totalTokenCount` | integer | — |
