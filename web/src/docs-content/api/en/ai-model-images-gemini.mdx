# gemini

## Gemini Native Format

Gemini image generation

`POST` `/v1beta/models/{model}:generateContent`

### Request Parameters

| Name | In | Type | Required | Description |
|---|---|---|---|---|
| `model` | path | string | Yes | Model name |

### Request Body (`application/json`)

| Field | Type | Required | Description |
|---|---|---|---|
| `contents` | array&lt;object&gt; | Yes | — |
| `generationConfig.thinkingConfig.includeThoughts` | boolean | No | Whether to return thinking content |
| `generationConfig.responseModalities` | array&lt;string&gt; | No | — |
| `generationConfig.imageConfig.aspectRatio` | string | No | — |
| `generationConfig.imageConfig.imageSize` | string | No | — |

### Response

| Status | Description |
|---|---|
| `200` | Success |

#### `200` Response Fields

| Field | Type | Description |
|---|---|---|
| `candidates` | array&lt;object&gt; | — |
| `usageMetadata.promptTokenCount` | integer | — |
| `usageMetadata.candidatesTokenCount` | integer | — |
| `usageMetadata.totalTokenCount` | integer | — |
