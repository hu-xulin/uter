# Document Reranking

## Document Reranking

Re-rank a list of documents by relevance to a query

`POST` `/v1/rerank`

### Request body (`application/json`)

| Field | Type | Required | Description |
|---|---|---|---|
| `model` | string | Yes | — |
| `query` | string | Yes | Query text |
| `documents` | array&lt;string&gt; | Yes | List of documents to re-rank |
| `top_n` | integer | No | Return the top N results |
| `return_documents` | boolean | No | — |

### Response

| Status | Meaning |
|---|---|
| `200` | Re-ranking completed |

#### `200` fields

| Field | Type | Description |
|---|---|---|
| `id` | string | — |
| `results` | array&lt;object&gt; | — |
| `meta` | object | — |
