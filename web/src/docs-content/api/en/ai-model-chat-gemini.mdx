# gemini

## Gemini Media Recognition

Gemini image, PDF, audio, and video recognition requests

⚠️ Note: Native Gemini format requests support passing media via inlineData (base64) or fileData.fileUri (a publicly accessible URL, including YouTube links). Whether a file URI uploaded through the Gemini File API is accessible depends on the permissions of the upstream channel key; publicly accessible URLs are recommended. When an OpenAI-format (chat/completions) request is converted to Gemini, media is downloaded and converted to inlineData (base64).

`POST` `/v1beta/models/{model}:generateContent`

### Request Parameters

| Name | In | Type | Required | Description |
|---|---|---|---|---|
| `model` | path | string | Yes | Model name |

### Request Body (`application/json`)

| Field | Type | Required | Description |
|---|---|---|---|
| `contents` | array&lt;object&gt; | No | — |
| `generationConfig.temperature` | number | No | — |
| `generationConfig.topP` | number | No | — |
| `generationConfig.topK` | integer | No | — |
| `generationConfig.maxOutputTokens` | integer | No | — |
| `generationConfig.stopSequences` | array&lt;string&gt; | No | — |
| `safetySettings` | array&lt;object&gt; | No | — |
| `tools` | array&lt;object&gt; | No | — |
| `systemInstruction.parts` | array&lt;object&gt; | No | — |

### Response

| Status | Description |
|---|---|
| `200` | Success |

#### `200` Response Fields

| Field | Type | Description |
|---|---|---|
| `candidates` | array&lt;object&gt; | — |
| `usageMetadata.promptTokenCount` | integer | — |
| `usageMetadata.candidatesTokenCount` | integer | — |
| `usageMetadata.totalTokenCount` | integer | — |

## Gemini Text Chat

Path format: `/v1beta/models/{model_name}:{action}`

For example:
- `/v1beta/models/gemini-2.5-pro:generateContent`
