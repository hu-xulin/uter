## ChatCompletions Format

Create a model response from a conversation history. Both streaming and non-streaming responses are supported.

Compatible with the OpenAI Chat Completions API.

`POST` `/v1/chat/completions`

### Request body (`application/json`)

| Field | Type | Required | Description |
|---|---|---|---|
| `model` | string | Yes | Model ID |
| `messages` | array&lt;object&gt; | Yes | Conversation messages |
| `temperature` | number | No | Sampling temperature |
| `top_p` | number | No | Nucleus (top-p) sampling |
| `n` | integer | No | Number of completions |
| `stream` | boolean | No | Whether to stream the response |
| `stream_options.include_usage` | boolean | No | Include usage in the final stream chunk |
| `max_tokens` | integer | No | Maximum number of tokens to generate |
| `max_completion_tokens` | integer | No | Maximum number of completion tokens |
| `presence_penalty` | number | No | Presence penalty |
| `frequency_penalty` | number | No | Frequency penalty |
| `logit_bias` | object | No | Logit bias |
| `user` | string | No | Caller-supplied user identifier |
| `tools` | array&lt;object&gt; | No | Tool definitions |
| `response_format.type` | enum (`text`, `json_object`, `json_schema`) | No | Response format type |
| `response_format.json_schema` | object | No | JSON Schema definition |
| `seed` | integer | No | Sampling seed |
| `reasoning_effort` | enum (`low`, `medium`, `high`) | No | Reasoning effort (for reasoning models) |
| `modalities` | array&lt;enum (`text`, `audio`)&gt; | No | Output modalities |
| `audio.voice` | string | No | Audio voice |
| `audio.format` | string | No | Audio output format |

### Response

| Status | Meaning |
|---|---|
| `200` | Response created |
| `400` | Invalid request parameters |
| `429` | Rate limit |

#### `200` fields

| Field | Type | Description |
|---|---|---|
| `id` | string | Response ID |
| `object` | string | Object type |
| `created` | integer | Creation time (Unix seconds) |
| `model` | string | Model used |
| `choices` | array&lt;object&gt; | Completion choices |
| `usage.prompt_tokens` | integer | Prompt token count |
| `usage.completion_tokens` | integer | Completion token count |
| `usage.total_tokens` | integer | Total token count |
| `usage.prompt_tokens_details.cached_tokens` | integer | Cached prompt tokens |
| `usage.prompt_tokens_details.text_tokens` | integer | Text prompt tokens |
| `usage.prompt_tokens_details.audio_tokens` | integer | Audio prompt tokens |
| `usage.prompt_tokens_details.image_tokens` | integer | Image prompt tokens |
| `usage.completion_tokens_details.text_tokens` | integer | Text completion tokens |
| `usage.completion_tokens_details.audio_tokens` | integer | Audio completion tokens |
| `usage.completion_tokens_details.reasoning_tokens` | integer | Reasoning tokens |
| `system_fingerprint` | string | System fingerprint |

#### `400` fields

| Field | Type | Description |
|---|---|---|
| `error.message` | string | Error message |
| `error.type` | string | Error type |
| `error.param` | string | Related parameter |
| `error.code` | string | Error code |

#### `429` fields

| Field | Type | Description |
|---|---|---|
| `error.message` | string | Error message |
| `error.type` | string | Error type |
| `error.param` | string | Related parameter |
| `error.code` | string | Error code |

## Responses Format

The OpenAI Responses API creates model responses with support for multi-turn conversations, tool calls and reasoning. Uter exposes the full Responses surface—create, retrieve, WebSocket streaming and compaction—on the [Responses API](./ai-model-responses) page.

`POST` `/v1/responses`

### Request body (`application/json`)

| Field | Type | Required | Description |
|---|---|---|---|
| `model` | string | Yes | Model ID |
| `instructions` | string | No | System instructions |
| `max_output_tokens` | integer | No | Maximum output tokens |
| `temperature` | number | No | Sampling temperature |
| `top_p` | number | No | Nucleus (top-p) sampling |
| `stream` | boolean | No | Whether to stream the response |
| `tools` | array&lt;object&gt; | No | Tool definitions |
| `reasoning.effort` | enum (`low`, `medium`, `high`) | No | Reasoning effort |
| `reasoning.summary` | string | No | Reasoning summary |
| `previous_response_id` | string | No | ID of a previous response to continue from |
| `truncation` | enum (`auto`, `disabled`) | No | Truncation mode |

### Response

| Status | Meaning |
|---|---|
| `200` | Response created |

#### `200` fields

| Field | Type | Description |
|---|---|---|
| `id` | string | Response ID |
| `object` | string | Object type |
| `created_at` | integer | Creation time (Unix seconds) |
| `status` | enum (`completed`, `failed`, `in_progress`, `incomplete`) | Response status |
| `model` | string | Model used |
| `output` | array&lt;object&gt; | Output items |
| `usage.prompt_tokens` | integer | Prompt token count |
| `usage.completion_tokens` | integer | Completion token count |
| `usage.total_tokens` | integer | Total token count |
| `usage.prompt_tokens_details.cached_tokens` | integer | Cached prompt tokens |
| `usage.prompt_tokens_details.text_tokens` | integer | Text prompt tokens |
| `usage.prompt_tokens_details.audio_tokens` | integer | Audio prompt tokens |
| `usage.prompt_tokens_details.image_tokens` | integer | Image prompt tokens |
| `usage.completion_tokens_details.text_tokens` | integer | Text completion tokens |
| `usage.completion_tokens_details.audio_tokens` | integer | Audio completion tokens |
| `usage.completion_tokens_details.reasoning_tokens` | integer | Reasoning tokens |
