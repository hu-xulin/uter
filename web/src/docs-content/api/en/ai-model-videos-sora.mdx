# sora

## Create Video 

OpenAI-compatible video generation API.

Reference: https://platform.openai.com/docs/api-reference/videos/create

`POST` `/v1/videos`

### Request body (`multipart/form-data`)

| Field | Type | Required | Description |
|---|---|---|---|
| `model` | string | No | Model/style ID |
| `prompt` | string | No | Text description prompt |
| `image` | string | No | Image input (URL or Base64) |
| `duration` | number | No | Video duration (seconds) |
| `width` | integer | No | Video width |
| `height` | integer | No | Video height |
| `fps` | integer | No | Video frame rate |
| `seed` | integer | No | Random seed |
| `n` | integer | No | Number of videos to generate |
| `response_format` | string | No | Response format |
| `user` | string | No | User identifier |
| `metadata` | object | No | Additional parameters (such as negative_prompt, style, quality_level, etc.) |

### Response

| Status | Meaning |
|---|---|
| `200` | Video task created successfully |
| `400` | Invalid request parameters |

#### `200` fields

| Field | Type | Description |
|---|---|---|
| `id` | string | Video ID |
| `object` | string | Object type |
| `model` | string | Model used |
| `status` | string | Task status |
| `progress` | integer | Progress percentage |
| `created_at` | integer | Creation timestamp |
| `seconds` | string | Video duration |
| `completed_at` | integer | Completion timestamp |
| `expires_at` | integer | Expiration timestamp |
| `size` | string | Video dimensions |
| `error.message` | string | Error message |
| `error.code` | string | Error code |
| `metadata` | object | Additional metadata |

#### `400` fields

| Field | Type | Description |
|---|---|---|
| `error.message` | string | Error message |
| `error.type` | string | Error type |
| `error.param` | string | Related parameter |
| `error.code` | string | Error code |

Returns detailed status information for a video task.

`GET` `/v1/videos/{task_id}`

### Request parameters

## Remix a video

Generate again from an existing video (remix); the new task reuses the original video's channel and model.

`POST` `/v1/videos/{video_id}/remix`

### Request body (`application/json`)

| Field | Type | Required | Description |
|---|---|---|---|
| `prompt` | string | No | New prompt for this remix |
| `model` | string | No | Reuses the original video's model when omitted |

### Response

Returns a new OpenAI video object with the same fields as "Create Video". A missing video, or one owned by another user, returns `400`.

## Get Video Content

Get the video file content of a completed video task.

This endpoint proxies and returns the video file stream.

`GET` `/v1/videos/{task_id}/content`

### Request parameters

| Parameter | In | Type | Required | Description |
|---|---|---|---|---|
| `task_id` | path | string | Yes | Video task ID |

### Response

| Status | Meaning |
|---|---|
| `200` | Video content retrieved successfully |
| `404` | Video does not exist or is not complete |

#### `404` fields

| Field | Type | Description |
|---|---|---|
| `error.message` | string | Error message |
| `error.type` | string | Error type |
| `error.param` | string | Related parameter |
| `error.code` | string | Error code |
