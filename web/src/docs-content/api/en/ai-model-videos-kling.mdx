# kling

## Kling Image to Video

Generate videos from an image with the Kling model.

The image parameter accepts either an image URL or Base64-encoded image data.

`POST` `/kling/v1/videos/image2video`

### Request Body (`application/json`)

| Field | Type | Required | Description |
|---|---|---|---|
| `model` | string | No | Model/style ID |
| `prompt` | string | No | Text description prompt |
| `image` | string | No | Image input (URL or Base64) |
| `duration` | number | No | Video duration (seconds) |
| `width` | integer | No | Video width |
| `height` | integer | No | Video height |
| `fps` | integer | No | Video frame rate |
| `seed` | integer | No | Random seed |
| `n` | integer | No | Number of videos to generate |
| `response_format` | string | No | Response format |
| `user` | string | No | User identifier |
| `metadata` | object | No | Additional parameters (e.g. negative_prompt, style, quality_level, etc.) |

### Response

| Status | Description |
|---|---|
| `200` | Video generation task created successfully |
| `400` | Invalid request parameters |

#### `200` Response Fields

| Field | Type | Description |
|---|---|---|
| `task_id` | string | Task ID |
| `status` | string | Task status |

#### `400` Response Fields

| Field | Type | Description |
|---|---|---|
| `error.message` | string | Error message |
| `error.type` | string | Error type |
| `error.param` | string | Related parameter |
| `error.code` | string | Error code |

## Get Kling Image-to-Video Task Status

Query the status and result of a Kling image-to-video task.

`GET` `/kling/v1/videos/image2video/{task_id}`

### Request Parameters

| Name | In | Type | Required | Description |
|---|---|---|---|---|
| `task_id` | path | string | Yes | Task ID |

### Response

| Status | Description |
|---|---|
| `200` | Task status retrieved successfully |
| `404` | Task not found |

#### `200` Response Fields

| Field | Type | Description |
|---|---|---|
| `task_id` | string | Task ID |
| `status` | enum (`queued`, `in_progress`, `completed`, `failed`) | Task status |
| `url` | string | Video resource URL (on success) |
| `format` | string | Video format |
| `metadata.duration` | number | Actual duration of the generated video |
| `metadata.fps` | integer | Actual frame rate |
| `metadata.width` | integer | Actual width |
| `metadata.height` | integer | Actual height |
| `metadata.seed` | integer | Random seed used |
| `error.code` | integer | Error code |
| `error.message` | string | Error message |

#### `404` Response Fields

| Field | Type | Description |
|---|---|---|
| `error.message` | string | Error message |
| `error.type` | string | Error type |
| `error.param` | string | Related parameter |
| `error.code` | string | Error code |
