# openai

## Text-to-Speech

Convert text to audio

`POST` `/v1/audio/speech`

### Request body (`application/json`)

| Field | Type | Required | Description |
|---|---|---|---|
| `model` | string | Yes | — |
| `input` | string | Yes | Text to convert |
| `voice` | enum (`alloy`, `echo`, `fable`, `onyx`, `nova`, `shimmer`) | Yes | — |
| `response_format` | enum (`mp3`, `opus`, `aac`, `flac`, `wav`, `pcm`) | No | — |
| `speed` | number | No | — |

### Response

| Status | Meaning |
|---|---|
| `200` | Audio generated successfully |

## Audio Transcriptions

Convert audio to text

`POST` `/v1/audio/transcriptions`

### Request body (`multipart/form-data`)

| Field | Type | Required | Description |
|---|---|---|---|
| `file` | string (binary) | Yes | Audio file |
| `model` | string | Yes | — |
| `language` | string | No | ISO-639-1 language code |
| `prompt` | string | No | — |
| `response_format` | enum (`json`, `text`, `srt`, `verbose_json`, `vtt`) | No | — |
| `temperature` | number | No | — |
| `timestamp_granularities` | array&lt;enum (`word`, `segment`)&gt; | No | — |

### Response

| Status | Meaning |
|---|---|
| `200` | Transcription completed |

#### `200` fields

| Field | Type | Description |
|---|---|---|
| `text` | string | — |
