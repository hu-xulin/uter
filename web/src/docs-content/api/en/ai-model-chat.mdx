# Native Claude Format

## Native Claude Format

Requests in the Anthropic Claude Messages API format.
The `anthropic-version` header must be included in the request.

`POST` `/v1/messages`

### Request parameters

| Parameter | In | Type | Required | Description |
|---|---|---|---|---|
| `anthropic-version` | header | string | Yes | Anthropic API version |
| `x-api-key` | header | string | No | Anthropic API Key (optional; a Bearer token can also be used) |

### Request body (`application/json`)

| Field | Type | Required | Description |
|---|---|---|---|
| `model` | string | Yes | — |
| `messages` | array&lt;object&gt; | Yes | — |
| `max_tokens` | integer | Yes | — |
| `temperature` | number | No | — |
| `top_p` | number | No | — |
| `top_k` | integer | No | — |
| `stream` | boolean | No | — |
| `stop_sequences` | array&lt;string&gt; | No | — |
| `tools` | array&lt;object&gt; | No | — |
| `tool_choice.type` | enum (`auto`, `any`, `tool`) | No | — |
| `tool_choice.name` | string | No | — |
| `thinking.type` | enum (`enabled`, `disabled`) | No | — |
| `thinking.budget_tokens` | integer | No | — |
| `metadata.user_id` | string | No | — |

### Response

| Status | Meaning |
|---|---|
| `200` | Response created |

#### `200` fields

| Field | Type | Description |
|---|---|---|
| `id` | string | — |
| `type` | string | — |
| `role` | string | — |
| `content` | array&lt;object&gt; | — |
| `model` | string | — |
| `stop_reason` | enum (`end_turn`, `max_tokens`, `stop_sequence`, `tool_use`) | — |
| `usage.input_tokens` | integer | — |
| `usage.output_tokens` | integer | — |
| `usage.cache_creation_input_tokens` | integer | — |
| `usage.cache_read_input_tokens` | integer | — |
