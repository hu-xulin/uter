# 模型（Models）

Uter 提供四個模型查詢入口：

| 端點 | 說明 |
|---|---|
| `GET /v1/models` | 目前權杖可呼叫的模型列表 |
| `GET /v1/models/{model}` | 單一模型詳情 |
| `GET /v1beta/models` | 同一列表的 Gemini 原生格式 |
| `GET /v1beta/openai/models` | 同一列表的 OpenAI 格式（Gemini 相容入口） |

列表已依權杖所屬分組、權杖模型白名單與模型計費設定過濾，請以回傳結果為準，不要硬編碼模型名稱。

`GET /v1/models` 依請求標頭自動選擇回傳格式：

- 包含 `x-api-key` 和 `anthropic-version` 標頭 → Anthropic 格式
- 包含 `x-goog-api-key` 標頭或 `key` 查詢參數 → Gemini 格式
- 其他情況 → OpenAI 格式

各格式的欄位說明與回應範例見「原生OpenAI格式」與「原生Gemini格式」兩頁。
