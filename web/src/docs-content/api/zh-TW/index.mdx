# API 參考

## 接入資訊

| 項目 | 值 |
|---|---|
| Base URL | `https://uter.ai`（API 專用入口：`https://api.uter.ai`） |
| 鑑權 | 請求標頭 `Authorization: Bearer sk-...` |
| 權杖 | 在主控台「權杖」頁建立，可限制分組、模型白名單與 IP |

Claude 格式（`/v1/messages`）同時接受 `x-api-key` 請求標頭；Gemini 格式（`/v1beta/models/...`）接受 `x-goog-api-key` 請求標頭或 `?key=` 查詢參數。無法設定請求標頭的瀏覽器客戶端，WebSocket 端點還可用 `Sec-WebSocket-Protocol: openai-insecure-api-key.<key>` 子協定鑑權。

## 錯誤格式

錯誤結構取決於端點類別，請依響應體判斷，而不要只看 HTTP 狀態碼：

| 類別 | 結構 | 範例 |
|---|---|---|
| OpenAI / Responses / Embeddings / Audio / Moderations / Rerank / Gemini | OpenAI 格式 | `{"error": {"message": "...", "type": "...", "param": "", "code": "..."}}` |
| Claude（`/v1/messages`） | Anthropic 格式 | `{"type": "error", "error": {"type": "...", "message": "..."}}` |
| 影片 / 通用任務（`/v1/video/generations`、`/v1/videos`、`/v1/tasks/*`） | 扁平任務錯誤 | `{"code": "task_not_exist", "message": "...", "data": {}}` |
| 鑑權 / 限流（中介軟體） | OpenAI 格式但無 `param` | `{"error": {"message": "...", "type": "new_api_error", "code": "..."}}` |

少數端點為例外：`GET /v1/models/{model}` 對不存在的模型仍回傳 `200` 並攜帶 OpenAI 錯誤體；`GET /v1/videos/{id}/content` 對不存在的任務回傳 `404`，而通用任務查詢回傳 `400 task_not_exist`。

一個權杖即可呼叫平台聚合的全部上游供應商。端點依協定族分組如下，欄位說明見對應頁面：

| 類別 | 端點 | 詳情 |
|---|---|---|
| 文字 · OpenAI | `POST /v1/chat/completions`、`POST /v1/completions` | [openai](./ai-model-chat-openai)、[completions](./ai-model-completions-openai) |
| 文字 · Claude | `POST /v1/messages` | [原生 Claude 格式](./ai-model-chat) |

| 音訊 | `POST /v1/audio/speech`、`POST /v1/audio/transcriptions`、`POST /v1/audio/translations` | [openai](./ai-model-audio-openai)、[gemini](./ai-model-audio-gemini) |

## 計費與限制

- 請求受理時依模型單價與預估用量預扣額度，結束後依實際用量結算差額；失敗或未生成內容的任務自動退回預扣額度。
- 額度不足回傳 `403`；請求頻率或上游併發飽和回傳 `429`；模型不存在或目前分組無可用渠道回傳 `503`。
- 圖像生成數量 `n` 上限為 128；影片時長、解析度與批次數量依所選模型的限制校驗，超界請求在受理前即被拒絕。

## 尚未實現的端點

`/v1/files*`、`/v1/fine-tunes*`、`/v1/images/variations`、`DELETE /v1/models/{model}` 目前回傳 `501`；Gemini `:countTokens` 回傳 `404`，請勿在生產環境呼叫。微調相關說明見[微調頁面](./ai-model-unimplemented-fine-tuning)。
