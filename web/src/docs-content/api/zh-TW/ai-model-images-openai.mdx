# 原生OpenAI格式

Uter 的圖像介面相容 OpenAI Images API。可用模型以 `GET /v1/models` 回傳為準，不同模型支援的尺寸、品質與專用參數不同，超出範圍的參數會回傳 `400`。

## 生成圖像

`POST` `/v1/images/generations`

### 請求主體（`application/json`）

| 欄位 | 類型 | 必填 | 說明 |
|---|---|---|---|
| `model` | string | 是 | 圖像模型 ID，取自 `GET /v1/models` |
| `prompt` | string | 是 | 圖像描述 |
| `n` | integer | 否 | 生成數量，1–128（平台上限），預設 1 |
| `size` | string | 否 | 圖像尺寸，如 `1024x1024`，可選值隨模型 |
| `quality` | string | 否 | 品質檔位，可選值隨模型 |
| `response_format` | enum（`url`, `b64_json`） | 否 | 回傳格式，預設 `url` |
| `background` | string | 否 | 背景模式（`transparent` / `opaque` / `auto`），僅部分模型支援 |
| `output_format` | string | 否 | 輸出格式（`png` / `jpeg` / `webp`），僅部分模型支援 |
| `output_compression` | integer | 否 | 輸出壓縮率，僅部分模型支援 |
| `moderation` | string | 否 | 內容審核等級，僅部分模型支援 |
| `stream` | boolean | 否 | 是否串流回傳部分圖像，僅部分模型支援 |
| `user` | string | 否 | 呼叫方自帶的使用者識別碼 |

### 回應

| 狀態碼 | 說明 |
|---|---|
| `200` | 生成成功 |
| `400` | 參數錯誤（含 `n` 超限、尺寸不被模型支援） |
| `403` | 額度不足 |

#### `200` 回應欄位

| 欄位 | 類型 | 說明 |
|---|---|---|
| `created` | integer | 生成時間（Unix 秒） |
| `data` | array&lt;object&gt; | 結果列表 |
| `data[].url` | string | 圖片位址（`response_format=url`） |
| `data[].b64_json` | string | Base64 圖片資料（`response_format=b64_json`） |
| `data[].revised_prompt` | string | 上游改寫後的提示詞（若上游回傳） |
| `metadata` | object | 上游附帶的額外中繼資料（若有） |

## 編輯圖像

`POST` `/v1/images/edits`

該端點同時接受 `multipart/form-data`（檔案上傳）與 `application/json`（圖片以 URL 或 Base64 字串傳入）。請使用與用戶端匹配的內容類型。

### 請求主體（`multipart/form-data`）

| 欄位 | 類型 | 必填 | 說明 |
|---|---|---|---|
| `image` | file（或字串陣列） | 是 | 待編輯的圖像；部分模型支援多圖輸入 |
| `mask` | file | 否 | 遮罩圖，透明區域為需要重繪的位置 |
| `prompt` | string | 是 | 編輯描述 |
| `model` | string | 是 | 圖像模型 ID，取自 `GET /v1/models` |
| `n` | integer | 否 | 生成數量，1–128（平台上限），預設 1 |
| `size` | string | 否 | 輸出尺寸，可選值隨模型 |
| `response_format` | enum（`url`, `b64_json`） | 否 | 回傳格式，預設 `url` |
| `user` | string | 否 | 呼叫方自帶的使用者識別碼 |

### 回應

回應結構與「生成圖像」一致；`data` 中的欄位隨 `response_format` 變化。
