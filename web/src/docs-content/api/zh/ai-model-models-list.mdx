# 模型（Models）

Uter 提供三个模型查询入口：

| 端点 | 说明 |
|---|---|
| `GET /v1/models` | 当前令牌可调用的模型列表 |
| `GET /v1/models/{model}` | 单个模型详情 |
| `GET /v1beta/models` | 同一列表的 Gemini 原生格式 |

列表已按令牌所属分组、令牌模型白名单与模型计费配置过滤，请以返回结果为准，不要硬编码模型名。

`GET /v1/models` 根据请求头自动选择返回格式：

- 包含 `x-api-key` 和 `anthropic-version` 头 → Anthropic 格式
- 包含 `x-goog-api-key` 头或 `key` 查询参数 → Gemini 格式
- 其他情况 → OpenAI 格式

各格式的字段说明与响应示例见「原生OpenAI格式」与「原生Gemini格式」两页。
