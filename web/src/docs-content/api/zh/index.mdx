# API 参考

## 接入信息

| 项目 | 值 |
|---|---|
| Base URL | `https://uter.ai`（API 专用入口：`https://api.uter.ai`） |
| 鉴权 | 请求头 `Authorization: Bearer sk-...` |
| 令牌 | 在控制台「令牌」页创建，可限制分组、模型白名单与 IP |

Claude 格式（`/v1/messages`）同时接受 `x-api-key` 请求头；Gemini 格式（`/v1beta/models/...`）接受 `x-goog-api-key` 请求头或 `?key=` 查询参数。无法设置请求头的浏览器客户端，WebSocket 端点还可用 `Sec-WebSocket-Protocol: openai-insecure-api-key.<key>` 子协议鉴权。

## 错误格式

错误结构取决于端点类别，请按响应体判断，而不要只看 HTTP 状态码：

| 类别 | 结构 | 示例 |
|---|---|---|
| OpenAI / Responses / Embeddings / Audio / Moderations / Rerank / Gemini | OpenAI 格式 | `{"error": {"message": "...", "type": "...", "param": "", "code": "..."}}` |
| Claude（`/v1/messages`） | Anthropic 格式 | `{"type": "error", "error": {"type": "...", "message": "..."}}` |
| 视频 / 通用任务（`/v1/video/generations`、`/v1/videos`、`/v1/tasks/*`） | 扁平任务错误 | `{"code": "task_not_exist", "message": "...", "data": {}}` |
| 鉴权 / 限流（中间件） | OpenAI 格式但无 `param` | `{"error": {"message": "...", "type": "new_api_error", "code": "..."}}` |

少数端点为例外：`GET /v1/models/{model}` 对不存在的模型仍返回 `200` 并携带 OpenAI 错误体；`GET /v1/videos/{id}/content` 对不存在的任务返回 `404`，而通用任务查询返回 `400 task_not_exist`。

一个令牌即可调用平台聚合的全部上游供应商。端点按协议族分组如下，字段说明见对应页面：

| 类别 | 端点 | 详情 |
|---|---|---|
| 文本 · OpenAI | `POST /v1/chat/completions`、`POST /v1/completions` | [openai](./ai-model-chat-openai)、[completions](./ai-model-completions-openai) |
| 文本 · Claude | `POST /v1/messages` | [原生 Claude 格式](./ai-model-chat) |

| 音频 | `POST /v1/audio/speech`、`POST /v1/audio/transcriptions`、`POST /v1/audio/translations` | [openai](./ai-model-audio-openai)、[gemini](./ai-model-audio-gemini) |

## 计费与限制

- 请求受理时按模型单价与预估用量预扣额度，结束后按实际用量结算差额；失败或未生成内容的任务自动退回预扣额度。
- 额度不足返回 `403`；请求频率或上游并发饱和返回 `429`；模型不存在或当前分组无可用渠道返回 `503`。
- 图像生成数量 `n` 上限为 128；视频时长、分辨率与批量数量按所选模型的限制校验，超界请求在受理前即被拒绝。
