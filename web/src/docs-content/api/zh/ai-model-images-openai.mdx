# 原生OpenAI格式

Uter 的图像接口兼容 OpenAI Images API。可用模型以 `GET /v1/models` 返回为准，不同模型支持的尺寸、质量与专用参数不同，超范围参数会返回 `400`。

## 生成图像

`POST` `/v1/images/generations`

### 请求体（`application/json`）

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `model` | string | 是 | 图像模型 ID，取自 `GET /v1/models` |
| `prompt` | string | 是 | 图像描述 |
| `n` | integer | 否 | 生成数量，1–128（平台上限），默认 1 |
| `size` | string | 否 | 图像尺寸，如 `1024x1024`，可选取值随模型 |
| `quality` | string | 否 | 质量档位，可选取值随模型 |
| `response_format` | enum（`url`, `b64_json`） | 否 | 返回格式，默认 `url` |
| `background` | string | 否 | 背景模式（`transparent` / `opaque` / `auto`），仅部分模型支持 |
| `output_format` | string | 否 | 输出格式（`png` / `jpeg` / `webp`），仅部分模型支持 |
| `output_compression` | integer | 否 | 输出压缩率，仅部分模型支持 |
| `moderation` | string | 否 | 内容审核级别，仅部分模型支持 |
| `stream` | boolean | 否 | 是否流式返回部分图像，仅部分模型支持 |
| `user` | string | 否 | 调用方自带的用户标识 |

### 响应

| 状态码 | 说明 |
|---|---|
| `200` | 生成成功 |
| `400` | 参数错误（含 `n` 超限、尺寸不被模型支持） |
| `403` | 额度不足 |

#### `200` 响应字段

| 字段 | 类型 | 说明 |
|---|---|---|
| `created` | integer | 生成时间（Unix 秒） |
| `data` | array&lt;object&gt; | 结果列表 |
| `data[].url` | string | 图片地址（`response_format=url`） |
| `data[].b64_json` | string | Base64 图片数据（`response_format=b64_json`） |
| `data[].revised_prompt` | string | 上游改写后的提示词（若上游返回） |
| `metadata` | object | 上游附带的额外元数据（若有） |

## 编辑图像

`POST` `/v1/images/edits`

该端点同时接受 `multipart/form-data`（文件上传）与 `application/json`（图片以 URL 或 Base64 字符串传入）。请使用与客户端匹配的内容类型。

### 请求体（`multipart/form-data`）

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `image` | file（或字符串数组） | 是 | 待编辑的图像；部分模型支持多图输入 |
| `mask` | file | 否 | 遮罩图，透明区域为需要重绘的位置 |
| `prompt` | string | 是 | 编辑描述 |
| `model` | string | 是 | 图像模型 ID，取自 `GET /v1/models` |
| `n` | integer | 否 | 生成数量，1–128（平台上限），默认 1 |
| `size` | string | 否 | 输出尺寸，可选取值随模型 |
| `response_format` | enum（`url`, `b64_json`） | 否 | 返回格式，默认 `url` |
| `user` | string | 否 | 调用方自带的用户标识 |

### 响应

响应结构与「生成图像」一致；`data` 中的字段随 `response_format` 变化。
