# Format OpenAI natif

Les points de terminaison d'image d'Uter sont compatibles avec l'API OpenAI Images. Seuls les modèles renvoyés par `GET /v1/models` sont utilisables ; les tailles, niveaux de qualité et paramètres spécifiques varient selon le modèle, et les valeurs hors limites sont rejetées avec `400`.

## Générer une image

`POST` `/v1/images/generations`

### Corps de requête (`application/json`)

| Champ | Type | Obligatoire | Description |
|---|---|---|---|
| `model` | string | Oui | ID du modèle d'image, issu de `GET /v1/models` |
| `prompt` | string | Oui | Description de l'image |
| `n` | integer | Non | Nombre d'images, 1–128 (plafond de la plateforme), par défaut 1 |
| `size` | string | Non | Taille, par exemple `1024x1024` ; les valeurs acceptées dépendent du modèle |
| `quality` | string | Non | Niveau de qualité ; dépend du modèle |
| `response_format` | enum (`url`, `b64_json`) | Non | Format de réponse, par défaut `url` |
| `background` | string | Non | Mode de fond (`transparent` / `opaque` / `auto`) ; selon le modèle |
| `output_format` | string | Non | Format de sortie (`png` / `jpeg` / `webp`) ; selon le modèle |
| `output_compression` | integer | Non | Compression de sortie ; selon le modèle |
| `moderation` | string | Non | Niveau de modération ; selon le modèle |
| `stream` | boolean | Non | Flux d'images partielles ; selon le modèle |
| `user` | string | Non | Identifiant utilisateur fourni par l'appelant |

### Réponse

| Statut | Signification |
|---|---|
| `200` | Généré |
| `400` | Paramètres invalides (`n` au-delà du plafond, taille non prise en charge) |
| `403` | Quota insuffisant |

#### Champs `200`

| Champ | Type | Description |
|---|---|---|
| `created` | integer | Date de création (secondes Unix) |
| `data` | array&lt;object&gt; | Résultats |
| `data[].url` | string | URL de l'image (`response_format=url`) |
| `data[].b64_json` | string | Image en Base64 (`response_format=b64_json`) |
| `data[].revised_prompt` | string | Prompt reformulé par l'amont, s'il est renvoyé |
| `metadata` | object | Métadonnées amont supplémentaires, le cas échéant |

## Éditer une image

`POST` `/v1/images/edits`

Ce point de terminaison accepte aussi bien `multipart/form-data` (téléversement de fichiers) que `application/json` (image transmise sous forme d'URL ou de chaîne base64). Utilisez le type de contenu qui correspond à votre client.

### Corps de requête (`multipart/form-data`)

| Champ | Type | Obligatoire | Description |
|---|---|---|---|
| `image` | fichier (ou tableau de chaînes) | Oui | Image(s) à éditer ; certains modèles acceptent plusieurs entrées |
| `mask` | fichier | Non | Masque dont la zone transparente indique la région à repeindre |
| `prompt` | string | Oui | Description de l'édition |
| `model` | string | Oui | ID du modèle d'image, issu de `GET /v1/models` |
| `n` | integer | Non | Nombre d'images, 1–128 (plafond de la plateforme), par défaut 1 |
| `size` | string | Non | Taille de sortie ; dépend du modèle |
| `response_format` | enum (`url`, `b64_json`) | Non | Format de réponse, par défaut `url` |
| `user` | string | Non | Identifiant utilisateur fourni par l'appelant |

### Corps de requête (`application/json`)

| Champ | Type | Obligatoire | Description |
|---|---|---|---|
| `model` | string | Oui | ID du modèle d'image, issu de `GET /v1/models` |
| `image` | string ou array&lt;string&gt; | Oui | URL de l'image ou data URI base64 à éditer |
| `prompt` | string | Oui | Description de l'édition |
| `n` | integer | Non | Nombre d'images, 1–128 (plafond de la plateforme), par défaut 1 |
| `size` | string | Non | Taille de sortie ; dépend du modèle |
| `response_format` | enum (`url`, `b64_json`) | Non | Format de réponse, par défaut `url` |
| `user` | string | Non | Identifiant utilisateur fourni par l'appelant |

```json
{
  "model": "gpt-image-1",
  "image": "https://example.com/source.png",
  "prompt": "Replace the background with a studio backdrop",
  "size": "1024x1024"
}
```

### Réponse

Même structure que « Générer une image » ; les champs de `data` suivent `response_format`.
