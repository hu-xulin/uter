# Modèles (Models)

Uter expose quatre points de terminaison de consultation des modèles :

| Point de terminaison | Description |
|---|---|
| `GET /v1/models` | Modèles que le jeton courant peut appeler |
| `GET /v1/models/{model}` | Détails d'un modèle |
| `GET /v1beta/models` | La même liste au format natif Gemini |
| `GET /v1beta/openai/models` | La même liste au format OpenAI (point d'entrée compatible Gemini) |

La liste est filtrée par le groupe du jeton, sa liste de modèles autorisés et la configuration de facturation. Fiez-vous à la liste renvoyée et ne codez pas les noms de modèles en dur.

`GET /v1/models` choisit le format de réponse d'après les en-têtes :

- en-têtes `x-api-key` et `anthropic-version` → format Anthropic
- en-tête `x-goog-api-key` ou paramètre `key` → format Gemini
- sinon → format OpenAI

Voir « Format OpenAI natif » et « Format Gemini natif » pour les champs et exemples de réponse de chaque format.
