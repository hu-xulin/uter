# Нативный формат Gemini

Возвращает список доступных моделей в формате Gemini API.

Аутентификация: параметр запроса `?key=sk-...` или заголовок `x-goog-api-key`. Список фильтруется по группе токена и его списку разрешённых моделей.

`GET` `/v1beta/models`

### Ответ

| Код статуса | Описание |
|---|---|
| `200` | Список моделей успешно получен |
| `401` | Ошибка аутентификации |

#### Поля ответа `200`

| Поле | Тип | Описание |
|---|---|---|
| `models` | array&lt;object&gt; | Модели |
| `models[].name` | string | ID модели (без префикса `models/`), используется как есть |
| `models[].displayName` | string | Отображаемое имя |
| `nextPageToken` | null | Всегда `null`; постраничная выдача не поддерживается |
