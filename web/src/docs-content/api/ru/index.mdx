# Справочник API

## Подключение

| Параметр | Значение |
|---|---|
| Base URL | `https://uter.ai` (отдельный адрес для API: `https://api.uter.ai`) |
| Аутентификация | Заголовок `Authorization: Bearer sk-...` |
| Токен | Создаётся на странице «Токены» в консоли; можно ограничить группой, списком моделей и IP-адресами |

Формат Claude (`/v1/messages`) также принимает заголовок `x-api-key`; формат Gemini (`/v1beta/models/...`) — заголовок `x-goog-api-key` или параметр запроса `?key=`.

Ошибки возвращаются в формате OpenAI:

```json
{"error": {"message": "описание ошибки", "type": "тип ошибки", "param": "", "code": "код ошибки"}}
```

## API моделей ИИ

Один токен открывает доступ ко всем провайдерам, агрегированным платформой. API делятся на четыре семейства протоколов:

| Протокол | Основные эндпоинты |
|---|---|
| OpenAI | `POST /v1/chat/completions`, `POST /v1/completions`, `POST /v1/responses`, `POST /v1/embeddings`, `POST /v1/images/generations`, `POST /v1/images/edits`, `POST /v1/audio/speech`, `POST /v1/audio/transcriptions`, `POST /v1/audio/translations`, `POST /v1/moderations`, `POST /v1/rerank`, `GET /v1/models`, `GET /v1/models/{model}` |
| Anthropic | `POST /v1/messages` |
| Gemini | `POST /v1beta/models/{model}:generateContent`, `POST /v1/engines/{model}/embeddings` |
| Видеозадачи | `POST /v1/video/generations`, `GET /v1/video/generations/{task_id}`, `POST /v1/videos`, `GET /v1/videos/{id}`, `GET /v1/videos/{id}/content`, `POST /v1/videos/{id}/remix` |

Доступные токену модели определяются его группой, списком разрешённых моделей и настройками тарификации модели. Всегда используйте имена моделей из ответа `GET /v1/models` и не угадывайте идентификаторы.

## Тарификация и ограничения

- При приёме запроса квота списывается по цене модели и оценённому объёму, затем пересчитывается по фактическому использованию. Неудачные запросы и задачи без результата возвращают списанное.
- Недостаток квоты — `403`; ограничение частоты или насыщение параллельных запросов на стороне провайдера — `429`; неизвестная модель или отсутствие доступного канала в группе — `503`.
- Количество изображений `n` ограничено 128. Длительность, разрешение и размер пакета видео определяются выбранной моделью; запросы вне допустимых значений отклоняются до приёма.

## Не реализовано

`/v1/files*`, `/v1/fine-tunes*`, `/v1/images/variations` и `DELETE /v1/models/{model}` сейчас возвращают `501`. Не вызывайте их в продакшене.
