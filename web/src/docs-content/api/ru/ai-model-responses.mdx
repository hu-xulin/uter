# Responses API

OpenAI Responses API поддерживает многоходовые диалоги, вызовы инструментов, рассуждения и состояние ответа на стороне сервера. Uter предоставляет эндпоинты создания, получения, потоковой передачи через WebSocket и сжатия (compaction). Один токен открывает доступ к любому каналу, обслуживающему семейство эндпоинтов `openai-response` (например Uter Route / Uter API / Codex и совместимые с OpenAI каналы).

ID моделей берутся из `GET /v1/models`. Запросы к моделям, не поддерживающим это семейство эндпоинтов, отклоняются; ограничения по группе токена и списку разрешённых моделей продолжают действовать.

> Примечание: `POST /v1/responses` и `GET /v1/responses/{response_id}` — эндпоинты хост-протокола. Если модель закреплена за плагином задачи, вызов обрабатывает плагин; в противном случае запрос направляется во встроенный ретранслятор Responses.

## Создание ответа

`POST` `/v1/responses`

### Тело запроса (`application/json`)

| Поле | Тип | Обязательно | Описание |
|---|---|---|---|
| `model` | string | Да | ID модели |
| `instructions` | string | Нет | Системные инструкции |
| `input` | string or array&lt;object&gt; | Нет | Входный промпт или элементы сообщений |
| `max_output_tokens` | integer | Нет | Максимальное число выходных токенов |
| `temperature` | number | Нет | Температура сэмплирования |
| `top_p` | number | Нет | Ядерная (top-p) выборка |
| `stream` | boolean | Нет | Потоковая отдача ответа |
| `tools` | array&lt;object&gt; | Нет | Определения инструментов |
| `previous_response_id` | string | Нет | ID предыдущего ответа, который нужно продолжить |
| `reasoning.effort` | enum (`low`, `medium`, `high`) | Нет | Интенсивность рассуждений |
| `reasoning.summary` | string | Нет | Краткое изложение рассуждений |
| `truncation` | enum (`auto`, `disabled`) | Нет | Режим усечения |
| `store` | boolean | Нет | Сохранить ответ для последующего получения |

### Ответ

| Статус | Значение |
|---|---|
| `200` | Ответ создан |
| `400` | Некорректные параметры запроса |
| `403` | Недостаточно квоты |
| `429` | Ограничение частоты запросов |
| `503` | Нет доступного канала для этой модели |

#### Поля `200`

| Поле | Тип | Описание |
|---|---|---|
| `id` | string | ID ответа (используется для получения и сжатия) |
| `object` | string | `response` |
| `created_at` | integer | Время создания (Unix-секунды) |
| `status` | enum (`completed`, `failed`, `in_progress`, `incomplete`) | Статус ответа |
| `model` | string | Использованная модель |
| `output` | array&lt;object&gt; | Выходные элементы (сообщения, вызовы инструментов, рассуждения) |
| `usage.input_tokens` | integer | Число входных токенов |
| `usage.output_tokens` | integer | Число выходных токенов |
| `usage.total_tokens` | integer | Общее число токенов |

## Получение ответа

`GET` `/v1/responses/{response_id}`

Возвращает ранее сохранённый ответ по ID.

| Параметр | Расположение | Тип | Обязательно | Описание |
|---|---|---|---|---|
| `response_id` | path | string | Да | ID, возвращённый при создании |

Тело ответа использует те же поля, что и при создании. Неизвестный ID возвращает ошибку в формате OpenAI.

## Ответы через WebSocket

`GET` `/v1/responses`

Эндпоинт WebSocket для потоковой передачи ответов. Выбор канала происходит после первого события `response.create`, и каждое событие проходит через обычный ограничитель частоты запросов. Клиенты, которые не могут задать заголовки рукопожатия, могут аутентифицироваться через подпротокол `Sec-WebSocket-Protocol: openai-insecure-api-key.<key>` в дополнение к `Authorization: Bearer`.

URL подключения: `wss://uter.ai/v1/responses`

## Сжатие ответа

`POST` `/v1/responses/compact`

Сжимает состояние диалога ответа, чтобы уменьшить число токенов при продолжении сессии.

### Тело запроса (`application/json`)

| Поле | Тип | Обязательно | Описание |
|---|---|---|---|
| `model` | string | Да | ID модели |
| `input` | string or array&lt;object&gt; | Да | Диалог, который нужно сжать |
| `instructions` | string | Нет | Системные инструкции |

Ответ использует ту же структуру объекта, что и при создании, при этом сжатый диалог находится в `output`.
