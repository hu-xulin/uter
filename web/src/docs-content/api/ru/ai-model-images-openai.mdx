# Нативный формат OpenAI

Эндпоинты изображений Uter совместимы с OpenAI Images API. Доступны только модели из `GET /v1/models`; поддерживаемые размеры, уровни качества и специальные параметры зависят от модели, а значения вне допустимого диапазона отклоняются с `400`.

## Генерация изображения

`POST` `/v1/images/generations`

### Тело запроса (`application/json`)

| Поле | Тип | Обязательно | Описание |
|---|---|---|---|
| `model` | string | Да | ID модели изображений из `GET /v1/models` |
| `prompt` | string | Да | Описание изображения |
| `n` | integer | Нет | Количество изображений, 1–128 (лимит платформы), по умолчанию 1 |
| `size` | string | Нет | Размер, например `1024x1024`; допустимые значения зависят от модели |
| `quality` | string | Нет | Уровень качества; зависит от модели |
| `response_format` | enum (`url`, `b64_json`) | Нет | Формат ответа, по умолчанию `url` |
| `background` | string | Нет | Режим фона (`transparent` / `opaque` / `auto`); только для части моделей |
| `output_format` | string | Нет | Формат вывода (`png` / `jpeg` / `webp`); только для части моделей |
| `output_compression` | integer | Нет | Сжатие вывода; только для части моделей |
| `moderation` | string | Нет | Уровень модерации; только для части моделей |
| `stream` | boolean | Нет | Потоковая отдача частичных изображений; только для части моделей |
| `user` | string | Нет | Идентификатор пользователя от вызывающей стороны |

### Ответ

| Статус | Значение |
|---|---|
| `200` | Изображение создано |
| `400` | Некорректные параметры (`n` сверх лимита, неподдерживаемый размер) |
| `403` | Недостаточно квоты |

#### Поля `200`

| Поле | Тип | Описание |
|---|---|---|
| `created` | integer | Время создания (Unix-секунды) |
| `data` | array&lt;object&gt; | Результаты |
| `data[].url` | string | URL изображения (`response_format=url`) |
| `data[].b64_json` | string | Данные изображения в Base64 (`response_format=b64_json`) |
| `data[].revised_prompt` | string | Переписанный провайдером промпт, если возвращается |
| `metadata` | object | Дополнительные метаданные провайдера, если есть |

## Редактирование изображения

`POST` `/v1/images/edits`

### Тело запроса (`multipart/form-data`)

| Поле | Тип | Обязательно | Описание |
|---|---|---|---|
| `image` | файл (или массив строк) | Да | Изображение(я) для редактирования; часть моделей принимает несколько |
| `mask` | файл | Нет | Маска: прозрачная область указывает, что перерисовать |
| `prompt` | string | Да | Описание правки |
| `model` | string | Да | ID модели изображений из `GET /v1/models` |
| `n` | integer | Нет | Количество изображений, 1–128, по умолчанию 1 |
| `size` | string | Нет | Размер результата; зависит от модели |
| `response_format` | enum (`url`, `b64_json`) | Нет | Формат ответа, по умолчанию `url` |
| `user` | string | Нет | Идентификатор пользователя от вызывающей стороны |

### Ответ

Та же структура, что у «Генерации изображения»; поля в `data` следуют `response_format`.
