# Поиск и инструменты

Uter предоставляет два семейства эндпоинтов-ретрансляторов поиска и инструментов. Исходное тело запроса передаётся провайдеру, а его ответ возвращается без изменений. Вызовы тарифицируются по запросу по цене маршрутизирующей модели (без учёта токенов). Эти эндпоинты доступны только на поддерживающих их каналах; если канал их не поддерживает, возвращается ошибка, и запрос может быть повторён на другом подходящем канале.

## Alpha-поиск

`POST` `/v1/alpha/search`

Автономный веб-поиск, используемый клиентами в стиле Codex. Поддерживается на каналах Uter Route / Uter API / Sub2API / NewAPI / Codex / Advanced Custom, а также на каналах плагинов провайдеров.

### Тело запроса (`application/json`)

| Поле | Тип | Обязательно | Описание |
|---|---|---|---|
| `model` | string | Да | ID маршрутизирующей модели (например модель `alpha-search` из `GET /v1/models`) |
| `id` | string | Нет | ID запроса, заданный клиентом |
| `stream` | boolean | Нет | Потоковая отдача результата |

Дополнительные поля, специфичные для провайдера, передаются без изменений.

### Ответ

| Статус | Значение |
|---|---|
| `200` | Результат поиска возвращён |
| `400` | Некорректный запрос или канал не поддерживает этот эндпоинт |
| `403` | Недостаточно квоты |

Тело ответа — это ответ провайдера, возвращаемый как есть.

## Поиск и загрузка DeepSeek

`POST` `/v1/tools/search`

`POST` `/v1/tools/fetch`

Инструменты веб-поиска и загрузки страниц, используемые клиентами в стиле DeepSeek. Поддерживаются на каналах DeepSeek, Uter Route / Uter API, Sub2API, NewAPI и Advanced Custom, а также на каналах плагинов провайдеров. Имена моделей `deepseek-search` и `deepseek-fetch` выбирают соответствующее семейство эндпоинтов.

### Тело запроса (`application/json`)

| Поле | Тип | Обязательно | Описание |
|---|---|---|---|
| `model` | string | Нет | ID маршрутизирующей модели (`deepseek-search` для поиска, `deepseek-fetch` для загрузки) |

Все остальные поля специфичны для провайдера и передаются без изменений.

### Ответ

| Статус | Значение |
|---|---|
| `200` | Результат инструмента возвращён |
| `400` | Некорректный запрос или канал не поддерживает этот эндпоинт |
| `403` | Недостаточно квоты |

Тело ответа — это ответ провайдера, возвращаемый как есть.
