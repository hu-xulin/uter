# Модели (Models)

Uter предоставляет три эндпоинта для работы со списком моделей:

| Эндпоинт | Описание |
|---|---|
| `GET /v1/models` | Модели, доступные текущему токену |
| `GET /v1/models/{model}` | Сведения об одной модели |
| `GET /v1beta/models` | Тот же список в нативном формате Gemini |

Список фильтруется по группе токена, его списку разрешённых моделей и настройкам тарификации. Доверяйте возвращённому списку и не хардкодьте имена моделей.

`GET /v1/models` выбирает формат ответа по заголовкам:

- заголовки `x-api-key` и `anthropic-version` → формат Anthropic
- заголовок `x-goog-api-key` или параметр `key` → формат Gemini
- иначе → формат OpenAI

Поля и примеры ответов каждого формата — на страницах «Нативный формат OpenAI» и «Нативный формат Gemini».
