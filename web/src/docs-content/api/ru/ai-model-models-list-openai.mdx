# Нативный формат OpenAI

## Список моделей

`GET` `/v1/models`

Возвращает модели, доступные текущему токену. Список фильтруется по группе токена, его списку разрешённых моделей и настройкам тарификации, поэтому у разных токенов он может отличаться.

Формат ответа определяется по заголовкам запроса:

- заголовки `x-api-key` и `anthropic-version` → формат Anthropic
- заголовок `x-goog-api-key` или параметр `key` → формат Gemini
- иначе → формат OpenAI

### Параметры запроса

| Параметр | Расположение | Тип | Обязательно | Описание |
|---|---|---|---|---|
| `key` | query | string | Нет | API-ключ для формата Gemini |
| `x-api-key` | header | string | Нет | API-ключ для формата Anthropic |
| `anthropic-version` | header | string | Нет | Версия Anthropic API |
| `x-goog-api-key` | header | string | Нет | API-ключ для формата Gemini |

### Ответ

| Статус | Значение |
|---|---|
| `200` | Список моделей получен |
| `401` | Ошибка аутентификации |

#### Поля `200` (формат OpenAI)

| Поле | Тип | Описание |
|---|---|---|
| `success` | boolean | Всегда `true` |
| `object` | string | Всегда `list` |
| `data` | array&lt;object&gt; | Модели |
| `data[].id` | string | ID модели; используйте его в запросах без изменений |
| `data[].object` | string | `model` |
| `data[].created` | integer | Время регистрации (Unix-секунды) |
| `data[].owned_by` | string | Владелец |
| `data[].supported_endpoint_types` | array&lt;string&gt; | Семейства эндпоинтов, которые обслуживает модель. Возможные значения: `openai`, `openai-response`, `openai-response-compact`, `openai-alpha-search`, `deepseek-tools-search`, `deepseek-tools-fetch`, `anthropic`, `gemini`, `embeddings`, `image-generation`, `openai-video`, `jina-rerank`. Точный набор зависит от канала модели. |

## Одна модель

`GET` `/v1/models/{model}`

| Параметр | Расположение | Тип | Обязательно | Описание |
|---|---|---|---|---|
| `model` | path | string | Да | ID модели |

Если модель существует, возвращается её объект (поля выше). Если нет — HTTP-статус всё равно `200`, но тело ответа содержит ошибку:

```json
{"error": {"message": "The model 'xxx' does not exist", "type": "invalid_request_error", "param": "model", "code": "model_not_found"}}
```

Проверяйте наличие поля `error` в теле, а не только HTTP-статус.
