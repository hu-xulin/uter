# Тарификация

Два совместимых с OpenAI эндпоинта тарификации позволяют клиенту узнать оставшуюся квоту и использование за текущий период для используемых учётных данных. Оба доступны по префиксам `/v1/dashboard/...` и устаревшему `/dashboard/...` и требуют токен (`Authorization: Bearer sk-...`).

> Числовые поля `*_USD` следуют настроенному на сайте типу отображения квоты: при отображении в USD они пересчитываются из единиц квоты по `QuotaPerUnit`; при отображении в CNY они переводятся в USD и умножаются на курс обмена; при отображении в токенах они содержат сырое число токенов. Не предполагайте, что суффикс всегда означает доллары США.

## Подписка (оставшаяся квота)

`GET` `/v1/dashboard/billing/subscription`

### Ответ

| Поле | Тип | Описание |
|---|---|---|
| `object` | string | `billing_subscription` |
| `has_payment_method` | boolean | Всегда `true` |
| `soft_limit_usd` | number | Общая квота (оставшаяся + использованная), в единицах отображения |
| `hard_limit_usd` | number | Общая квота, в единицах отображения |
| `system_hard_limit_usd` | number | Общая квота, в единицах отображения |
| `access_until` | integer | Время истечения токена (Unix-секунды); `0`, если без ограничения срока |

Если для токенов включена статистика, значения отражают сам токен; в противном случае — квоту пользователя-владельца. Токен с неограниченной квотой возвращает большое условное значение (100000000).

## Использование (израсходованная квота)

`GET` `/v1/dashboard/billing/usage`

### Ответ

| Поле | Тип | Описание |
|---|---|---|
| `object` | string | Объект использования тарификации |
| `total_usage` | number | Квота, израсходованная за текущий период, в единицах отображения |

При внутренней ошибке этот эндпоинт всё равно возвращает HTTP `200` с телом `{"error": {...}}` (тип `uter_error`). Проверяйте наличие поля `error`, а не только код статуса.
