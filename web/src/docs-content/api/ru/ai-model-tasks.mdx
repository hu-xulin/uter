# Универсальные задачи

API универсальных задач — это независимый от провайдера интерфейс для асинхронных операций (генерация изображений и видео, а также другие плагины задач). Это формат, лежащий в основе `/v1/video/generations`; он также доступен напрямую по пути `/v1/tasks/*`. ID задач являются общими для обеих точек входа.

Все эндпоинты требуют токен (`Authorization: Bearer sk-...`). Для загрузки содержимого артефактов дополнительно принимается авторизация с ограниченной областью доступа к артефактам.

## Отправка задачи

`POST` `/v1/tasks/{key}`

Сегмент пути `key` — это ключ плагина задачи. Тело запроса зависит от провайдера; поле `model` выбирает канал и тарификацию, а параметры провайдера передаются без изменений.

| Параметр | Расположение | Тип | Обязательно | Описание |
|---|---|---|---|---|
| `key` | path | string | Да | Ключ плагина задачи |

### Ответ

| Статус | Значение |
|---|---|
| `200` | Задача принята |
| `400` | Некорректный запрос |
| `403` | Недостаточно квоты |
| `429` | Насыщение параллельных запросов на стороне провайдера |
| `503` | Нет доступного канала |

Ответ содержит ID задачи (`task_id` / `id`) и начальный `status` (обычно `queued`).

## Запрос статуса задачи

`GET` `/v1/tasks/{key}`

Здесь `key` — это ID задачи, возвращённый при отправке.

| Параметр | Расположение | Тип | Обязательно | Описание |
|---|---|---|---|---|
| `key` | path | string | Да | ID задачи |

Возвращает унифицированный конверт задачи:

```json
{
  "code": "success",
  "message": "",
  "data": {
    "task_id": "task_xxx",
    "status": "SUCCESS",
    "progress": "100%",
    "result_url": "https://example.com/result.mp4"
  }
}
```

Отсутствующая задача или задача другого пользователя возвращает `400` с `code: task_not_exist`.

## Список артефактов задачи

`GET` `/v1/tasks/{key}/artifacts`

Возвращает артефакты, созданные завершённой задачей (например сгенерированные файлы).

| Параметр | Расположение | Тип | Обязательно | Описание |
|---|---|---|---|---|
| `key` | path | string | Да | ID задачи |

## Загрузка содержимого артефакта

`GET` `/v1/tasks/{key}/artifacts/{artifact_key}/content`

`HEAD` `/v1/tasks/{key}/artifacts/{artifact_key}/content`

Передаёт файл артефакта потоком. `HEAD` возвращает те же заголовки без тела.

| Параметр | Расположение | Тип | Обязательно | Описание |
|---|---|---|---|---|
| `key` | path | string | Да | ID задачи |
| `artifact_key` | path | string | Да | Ключ артефакта из списка артефактов |

Этот эндпоинт принимает как обычный токен, так и учётные данные с ограниченным доступом к артефактам.
