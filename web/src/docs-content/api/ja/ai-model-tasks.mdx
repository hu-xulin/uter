# Generic Tasks

汎用タスク API は、非同期処理（画像・動画生成やその他のタスクプラグイン）のためのプロバイダー非依存のインターフェースです。`/v1/video/generations` の背景にある形式で、`/v1/tasks/*` から直接使用することもできます。タスク ID は両方の入口で共有されます。

すべてのエンドポイントにはトークン（`Authorization: Bearer sk-...`）が必要です。成果物コンテンツのダウンロードでは、さらにスコープ付きの成果物アクセス認証も受け付けます。

## タスクを送信

`POST` `/v1/tasks/{key}`

パスセグメント `key` はタスクプラグインのキーです。ボディはプロバイダー固有で、`model` フィールドがチャネルと課金を選択し、プロバイダー固有のオプションはそのまま渡されます。

| パラメータ | 位置 | 型 | 必須 | 説明 |
|---|---|---|---|---|
| `key` | path | string | はい | タスクプラグインのキー |

### レスポンス

| ステータス | 意味 |
|---|---|
| `200` | タスク受理済み |
| `400` | リクエストが不正 |
| `403` | クォータ不足 |
| `429` | 上流の同時接続が飽和 |
| `503` | 利用可能なチャネルがない |

レスポンスにはタスク ID（`task_id` / `id`）と初期 `status`（通常は `queued`）が含まれます。

## タスクを照会

`GET` `/v1/tasks/{key}`

ここでの `key` は送信時に返されたタスク ID です。

| パラメータ | 位置 | 型 | 必須 | 説明 |
|---|---|---|---|---|
| `key` | path | string | はい | タスク ID |

統合タスク形式を返します：

```json
{
  "code": "success",
  "message": "",
  "data": {
    "task_id": "task_xxx",
    "status": "SUCCESS",
    "progress": "100%",
    "result_url": "https://example.com/result.mp4"
  }
}
```

タスクが存在しない場合や他ユーザーのタスクの場合は、`code: task_not_exist` で `400` を返します。

## タスクの成果物一覧を取得

`GET` `/v1/tasks/{key}/artifacts`

完了したタスクが生成した成果物（例：生成ファイル）を返します。

| パラメータ | 位置 | 型 | 必須 | 説明 |
|---|---|---|---|---|
| `key` | path | string | はい | タスク ID |

## 成果物コンテンツをダウンロード

`GET` `/v1/tasks/{key}/artifacts/{artifact_key}/content`

`HEAD` `/v1/tasks/{key}/artifacts/{artifact_key}/content`

成果物ファイルをストリーミングします。`HEAD` はボディなしで同じヘッダーを返します。

| パラメータ | 位置 | 型 | 必須 | 説明 |
|---|---|---|---|---|
| `key` | path | string | はい | タスク ID |
| `artifact_key` | path | string | はい | 成果物一覧の成果物キー |

このエンドポイントは通常のトークンまたはスコープ付き成果物アクセス認証のいずれかを受け付けます。
