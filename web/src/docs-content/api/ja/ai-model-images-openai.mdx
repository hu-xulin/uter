# ネイティブ OpenAI 形式

Uter の画像エンドポイントは OpenAI Images API と互換です。利用できるのは `GET /v1/models` が返すモデルだけで、対応するサイズ、品質、専用パラメータはモデルごとに異なります。範囲外の値は `400` で拒否されます。

## 画像を生成

`POST` `/v1/images/generations`

### リクエストボディ（`application/json`）

| フィールド | 型 | 必須 | 説明 |
|---|---|---|---|
| `model` | string | はい | `GET /v1/models` で取得した画像モデル ID |
| `prompt` | string | はい | 画像の説明 |
| `n` | integer | いいえ | 生成枚数。1〜128（プラットフォーム上限）、既定値は 1 |
| `size` | string | いいえ | 画像サイズ（例：`1024x1024`）。許容値はモデル依存 |
| `quality` | string | いいえ | 品質レベル。許容値はモデル依存 |
| `response_format` | enum（`url`, `b64_json`） | いいえ | レスポンス形式。既定値は `url` |
| `background` | string | いいえ | 背景モード（`transparent` / `opaque` / `auto`）。一部モデルのみ |
| `output_format` | string | いいえ | 出力形式（`png` / `jpeg` / `webp`）。一部モデルのみ |
| `output_compression` | integer | いいえ | 出力圧縮率。一部モデルのみ |
| `moderation` | string | いいえ | モデレーションレベル。一部モデルのみ |
| `stream` | boolean | いいえ | 部分画像のストリーミング。一部モデルのみ |
| `user` | string | いいえ | 呼び出し側のユーザー識別子 |

### レスポンス

| ステータス | 意味 |
|---|---|
| `200` | 生成成功 |
| `400` | パラメータ不正（`n` の上限超過、モデルが対応しないサイズなど） |
| `403` | クォータ不足 |

#### `200` のフィールド

| フィールド | 型 | 説明 |
|---|---|---|
| `created` | integer | 生成時刻（Unix 秒） |
| `data` | array&lt;object&gt; | 結果一覧 |
| `data[].url` | string | 画像 URL（`response_format=url`） |
| `data[].b64_json` | string | Base64 画像データ（`response_format=b64_json`） |
| `data[].revised_prompt` | string | 上流が書き換えたプロンプト（返された場合） |
| `metadata` | object | 上流の追加メタデータ（あれば） |

## 画像を編集

`POST` `/v1/images/edits`

このエンドポイントは `multipart/form-data`（ファイルアップロード）と `application/json`（画像を URL または base64 文字列で渡す）の両方を受け付けます。クライアントに合ったコンテンツタイプを使用してください。

### リクエストボディ（`multipart/form-data`）

| フィールド | 型 | 必須 | 説明 |
|---|---|---|---|
| `image` | ファイル（または文字列配列） | はい | 編集する画像。一部モデルは複数入力に対応 |
| `mask` | ファイル | いいえ | 透明部分が再描画領域を示すマスク |
| `prompt` | string | はい | 編集内容の説明 |
| `model` | string | はい | `GET /v1/models` で取得した画像モデル ID |
| `n` | integer | いいえ | 生成枚数。1〜128（プラットフォーム上限）、既定値は 1 |
| `size` | string | いいえ | 出力サイズ。許容値はモデル依存 |
| `response_format` | enum（`url`, `b64_json`） | いいえ | レスポンス形式。既定値は `url` |
| `user` | string | いいえ | 呼び出し側のユーザー識別子 |

### リクエストボディ（`application/json`）

| フィールド | 型 | 必須 | 説明 |
|---|---|---|---|
| `model` | string | はい | `GET /v1/models` で取得した画像モデル ID |
| `image` | string or array&lt;string&gt; | はい | 編集する画像の URL または base64 データ URI |
| `prompt` | string | はい | 編集内容の説明 |
| `n` | integer | いいえ | 生成枚数。1〜128（プラットフォーム上限）、既定値は 1 |
| `size` | string | いいえ | 出力サイズ。許容値はモデル依存 |
| `response_format` | enum（`url`, `b64_json`） | いいえ | レスポンス形式。既定値は `url` |
| `user` | string | いいえ | 呼び出し側のユーザー識別子 |

```json
{
  "model": "gpt-image-1",
  "image": "https://example.com/source.png",
  "prompt": "Replace the background with a studio backdrop",
  "size": "1024x1024"
}
```

### レスポンス

「画像を生成」と同じ構造です。`data` 内のフィールドは `response_format` に従います。
