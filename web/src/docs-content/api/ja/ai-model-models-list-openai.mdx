# ネイティブ OpenAI 形式

## モデル一覧を取得

`GET` `/v1/models`

現在のトークンで呼び出せるモデルを返します。トークンの所属グループ、トークンのモデルホワイトリスト、モデルの課金設定で絞り込まれるため、トークンごとに一覧が異なります。

レスポンス形式はリクエストヘッダーで自動判定されます：

- `x-api-key` と `anthropic-version` ヘッダー → Anthropic 形式
- `x-goog-api-key` ヘッダーまたは `key` クエリパラメータ → Gemini 形式
- それ以外 → OpenAI 形式

### リクエストパラメータ

| パラメータ | 位置 | 型 | 必須 | 説明 |
|---|---|---|---|---|
| `key` | query | string | いいえ | Gemini 形式用の API キー |
| `x-api-key` | header | string | いいえ | Anthropic 形式用の API キー |
| `anthropic-version` | header | string | いいえ | Anthropic API バージョン |
| `x-goog-api-key` | header | string | いいえ | Gemini 形式用の API キー |

### レスポンス

| ステータス | 意味 |
|---|---|
| `200` | モデル一覧を返却 |
| `401` | 認証失敗 |

#### `200` のフィールド（OpenAI 形式）

| フィールド | 型 | 説明 |
|---|---|---|
| `success` | boolean | 常に `true` |
| `object` | string | 常に `list` |
| `data` | array&lt;object&gt; | モデル一覧 |
| `data[].id` | string | モデル ID。リクエストではそのまま使用します |
| `data[].object` | string | `model` |
| `data[].created` | integer | 登録時刻（Unix 秒） |
| `data[].owned_by` | string | 所有元 |
| `data[].supported_endpoint_types` | array&lt;string&gt; | 対応するエンドポイント系統。可能な値：`openai`、`openai-response`、`openai-response-compact`、`openai-alpha-search`、`deepseek-tools-search`、`deepseek-tools-fetch`、`anthropic`、`gemini`、`embeddings`、`image-generation`、`openai-video`、`jina-rerank`。実際の値はモデルのチャネルによって異なります |

## 単一モデルを取得

`GET` `/v1/models/{model}`

| パラメータ | 位置 | 型 | 必須 | 説明 |
|---|---|---|---|---|
| `model` | path | string | はい | モデル ID |

モデルが存在すれば、そのモデルオブジェクト（上記と同じフィールド）を返します。存在しない場合も **HTTP は `200`** のままで、レスポンスボディがエラーオブジェクトになります：

```json
{"error": {"message": "The model 'xxx' does not exist", "type": "invalid_request_error", "param": "model", "code": "model_not_found"}}
```

HTTP ステータスだけで判断せず、ボディに `error` フィールドがあるかを確認してください。
