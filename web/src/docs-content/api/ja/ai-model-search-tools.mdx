# Search & Tools

Uter は 2 つの系統の検索／ツール中継エンドポイントを提供します。リクエストボディはそのまま上流へ転送され、上流のレスポンスも変更せずに返されます。呼び出しはルーティングモデルの単価でリクエストごとに課金されます（トークン数はカウントされません）。これらのエンドポイントは対応するチャネルでのみ利用できます。非対応のチャネルはエラーを返すため、別の適格なチャネルでリクエストを再試行できます。

## Alpha 検索

`POST` `/v1/alpha/search`

Codex 形式のクライアントが使用する単体の Web 検索です。Uter Route / Uter API / Sub2API / NewAPI / Codex / Advanced Custom チャネルおよびプロバイダープラグインチャネルで対応しています。

### リクエストボディ（`application/json`）

| フィールド | 型 | 必須 | 説明 |
|---|---|---|---|
| `model` | string | はい | ルーティングモデル ID（例：`GET /v1/models` で取得した `alpha-search` モデル） |
| `id` | string | いいえ | クライアントが指定するリクエスト ID |
| `stream` | boolean | いいえ | 結果をストリーミングするか |

その他のプロバイダー固有フィールドは変更せずにそのまま渡されます。

### レスポンス

| ステータス | 意味 |
|---|---|
| `200` | 検索結果を返却 |
| `400` | リクエストが不正、またはチャネルがこのエンドポイントに対応していない |
| `403` | クォータ不足 |

レスポンスボディは上流のレスポンスがそのまま返されます。

## DeepSeek 検索とフェッチ

`POST` `/v1/tools/search`

`POST` `/v1/tools/fetch`

DeepSeek 形式のクライアントが使用する Web 検索とページ取得のツールです。DeepSeek、Uter Route / Uter API、Sub2API、NewAPI、Advanced Custom チャネル、およびプロバイダープラグインチャネルで対応しています。モデル名 `deepseek-search` と `deepseek-fetch` で対応するエンドポイント系統を選択します。

### リクエストボディ（`application/json`）

| フィールド | 型 | 必須 | 説明 |
|---|---|---|---|
| `model` | string | いいえ | ルーティングモデル ID（検索は `deepseek-search`、フェッチは `deepseek-fetch`） |

その他のフィールドはすべてプロバイダー固有で、変更せずにそのまま渡されます。

### レスポンス

| ステータス | 意味 |
|---|---|
| `200` | ツールの結果を返却 |
| `400` | リクエストが不正、またはチャネルがこのエンドポイントに対応していない |
| `403` | クォータ不足 |

レスポンスボディは上流のレスポンスがそのまま返されます。
