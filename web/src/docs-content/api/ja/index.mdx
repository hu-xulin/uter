# API リファレンス

## 接続情報

| 項目 | 値 |
|---|---|
| Base URL | `https://uter.ai`（API 専用エンドポイント：`https://api.uter.ai`） |
| 認証 | `Authorization: Bearer sk-...` |
| トークン | コンソールの「トークン」ページで作成。グループ、モデルのホワイトリスト、送信元 IP に制限できます |

Claude 形式（`/v1/messages`）は `x-api-key` ヘッダーも受け付けます。Gemini 形式（`/v1beta/models/...`）は `x-goog-api-key` ヘッダーまたは `?key=` クエリパラメータを受け付けます。さらに WebSocket エンドポイントは、ヘッダーを設定できないブラウザクライアント向けに `Sec-WebSocket-Protocol: openai-insecure-api-key.<key>` サブプロトコルも受け付けます。

## エラー形式

エラーのエンベロープはエンドポイント系統によって異なります。HTTP ステータスだけでなく、必ずボディ内容で分岐してください：

| 系統 | エンベロープ | 例 |
|---|---|---|
| OpenAI / Responses / Embeddings / Audio / Moderations / Rerank / Gemini | OpenAI | `{"error": {"message": "...", "type": "...", "param": "", "code": "..."}}` |
| Claude (`/v1/messages`) | Anthropic | `{"type": "error", "error": {"type": "...", "message": "..."}}` |
| 動画 / 汎用タスク（`/v1/video/generations`、`/v1/videos`、`/v1/tasks/*`） | フラットなタスクエラー | `{"code": "task_not_exist", "message": "...", "data": {}}` |
| 認証 / レート制限（ミドルウェア） | `param` なしの OpenAI 形式 | `{"error": {"message": "...", "type": "new_api_error", "code": "..."}}` |

一部のエンドポイントは例外です。未知のモデルに対して `GET /v1/models/{model}` は OpenAI 形式のエラーボディで `200` を返します。また、タスクが存在しない場合に `GET /v1/videos/{id}/content` は `404` を返すのに対し、汎用タスク照会は `400 task_not_exist` を返します。

## AI モデル API

1 つのトークンで、プラットフォームが集約するすべての上流プロバイダーにアクセスできます。以下はプロトコル系統ごとにエンドポイントをまとめたものです。リクエスト／レスポンスのフィールドはリンク先のページを参照してください。

| 系統 | エンドポイント | 詳細 |
|---|---|---|
| テキスト · OpenAI | `POST /v1/chat/completions`, `POST /v1/completions` | [openai](./ai-model-chat-openai), [completions](./ai-model-completions-openai) |
| テキスト · Claude | `POST /v1/messages` | [ネイティブ Claude 形式](./ai-model-chat) |
| テキスト · Responses | `POST /v1/responses`, `GET /v1/responses/{response_id}`, `GET /v1/responses` (WebSocket), `POST /v1/responses/compact` | [Responses API](./ai-model-responses) |
| テキスト · Gemini | `POST /v1beta/models/{model}:generateContent`, `POST /v1/engines/{model}/embeddings` | [gemini](./ai-model-chat-gemini) |
| 検索とツール | `POST /v1/alpha/search`, `POST /v1/tools/search`, `POST /v1/tools/fetch` | [Search & Tools](./ai-model-search-tools) |
| Embeddings | `POST /v1/embeddings` | [openai](./ai-model-embeddings-openai), [gemini](./ai-model-embeddings-gemini) |
| 画像 | `POST /v1/images/generations`, `POST /v1/images/edits` | [openai](./ai-model-images-openai), [gemini](./ai-model-images-gemini), [qwen](./ai-model-images-qwen) |
| 音声 | `POST /v1/audio/speech`, `POST /v1/audio/transcriptions`, `POST /v1/audio/translations` | [openai](./ai-model-audio-openai), [gemini](./ai-model-audio-gemini) |
| Moderations | `POST /v1/moderations` | [moderations](./ai-model-moderations) |
| Rerank | `POST /v1/rerank` | [rerank](./ai-model-rerank) |
| Realtime | `GET /v1/realtime` (WebSocket) | [realtime](./ai-model-realtime) |
| 動画 | `POST /v1/video/generations`, `GET /v1/video/generations/{task_id}`, `POST /v1/videos`, `GET /v1/videos/{id}`, `GET /v1/videos/{id}/content`, `POST /v1/videos/{id}/remix` | [videos](./ai-model-videos) |
| 汎用タスク | `POST /v1/tasks/{key}`, `GET /v1/tasks/{key}`, `GET /v1/tasks/{key}/artifacts`, `GET\|HEAD /v1/tasks/{key}/artifacts/{artifact_key}/content` | [tasks](./ai-model-tasks) |
| モデル | `GET /v1/models`, `GET /v1/models/{model}`, `GET /v1beta/models`, `GET /v1beta/openai/models` | [models](./ai-model-models-list) |
| 課金 | `GET /v1/dashboard/billing/subscription`, `GET /v1/dashboard/billing/usage` | [billing](./ai-model-billing) |

トークンで呼び出せるモデルは、所属グループ、トークンのモデルホワイトリスト、モデルの課金設定で決まります。必ず `GET /v1/models` が返すモデル名を使用し、モデル ID を推測しないでください。

## 課金と制限

- リクエスト受理時にモデル単価と推定使用量に基づいてクォータを事前控除し、終了後に実使用量で精算します。失敗したリクエストや結果を生成しなかったタスクは返金されます。
- クォータ不足は `403`、レート制限または上流の同時接続飽和は `429`、モデルが存在しない場合や現在のグループ内に利用可能な渠道がない場合は `503` を返します。
- 画像生成数 `n` の上限は 128 です。動画の長さ・解像度・バッチ数は選択したモデルの制限に従い、範囲外のリクエストは受理前に拒否されます。

## 未実装のエンドポイント

`/v1/files*`、`/v1/fine-tunes*`、`/v1/images/variations`、`DELETE /v1/models/{model}` は現在 `501` を返します。Gemini の `:countTokens` は `404` を返します。本番環境では呼び出さないでください。ファインチューニングは[ファインチューニングのページ](./ai-model-unimplemented-fine-tuning)に別途記載されています。
