# Billing

2 つの OpenAI 互換課金エンドポイントにより、クライアントは使用中の認証情報の残りクォータと当期の使用量を確認できます。どちらも `/v1/dashboard/...` と従来の `/dashboard/...` プレフィックスの両方で利用でき、トークン（`Authorization: Bearer sk-...`）が必要です。

> 数値の `*_USD` フィールドは、サイトで設定されたクォータ表示形式に従います。USD 表示の場合はクォータ単位から `QuotaPerUnit` で換算され、CNY 表示の場合は USD に換算されて為替レートが乗じられ、トークン表示の場合は生のトークン数が入ります。サフィックスが常に米ドルを意味すると想定しないでください。

## サブスクリプション（残りクォータ）

`GET` `/v1/dashboard/billing/subscription`

### レスポンス

| フィールド | 型 | 説明 |
|---|---|---|
| `object` | string | `billing_subscription` |
| `has_payment_method` | boolean | 常に `true` |
| `soft_limit_usd` | number | 総クォータ（残り＋使用済み）。表示単位 |
| `hard_limit_usd` | number | 総クォータ。表示単位 |
| `system_hard_limit_usd` | number | 総クォータ。表示単位 |
| `access_until` | integer | トークンの有効期限（Unix 秒）。無制限の場合は `0` |

トークンに対してトークン統計が有効な場合、数値はトークン自体を反映します。それ以外の場合は所有ユーザーのクォータを反映します。クォータ無制限のトークンは、大きな番兵値（100000000）を返します。

## 使用量（消費クォータ）

`GET` `/v1/dashboard/billing/usage`

### レスポンス

| フィールド | 型 | 説明 |
|---|---|---|
| `object` | string | 課金使用量オブジェクト |
| `total_usage` | number | 当期に消費したクォータ。表示単位 |

内部エラーが発生した場合も、このエンドポイントは HTTP `200` で `{"error": {...}}` ボディ（種別は `uter_error`）を返します。ステータスコードだけに頼らず、`error` フィールドの有無を確認してください。
