# モデル（Models）

Uter はモデル照会の入口を 3 つ提供します：

| エンドポイント | 説明 |
|---|---|
| `GET /v1/models` | 現在のトークンで呼び出せるモデル一覧 |
| `GET /v1/models/{model}` | 単一モデルの詳細 |
| `GET /v1beta/models` | 同じ一覧の Gemini ネイティブ形式 |

一覧はトークンの所属グループ、モデルホワイトリスト、モデルの課金設定で絞り込まれます。返された結果を信頼し、モデル名をハードコードしないでください。

`GET /v1/models` はリクエストヘッダーでレスポンス形式を選びます：

- `x-api-key` と `anthropic-version` ヘッダー → Anthropic 形式
- `x-goog-api-key` ヘッダーまたは `key` クエリパラメータ → Gemini 形式
- それ以外 → OpenAI 形式

各形式のフィールドとレスポンス例は「ネイティブ OpenAI 形式」「ネイティブ Gemini 形式」を参照してください。
