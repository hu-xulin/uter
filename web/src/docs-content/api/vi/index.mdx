# Tham khảo API

## Kết nối

| Hạng mục | Giá trị |
|---|---|
| Base URL | `https://uter.ai` (cổng dành riêng cho API: `https://api.uter.ai`) |
| Xác thực | Header `Authorization: Bearer sk-...` |
| Token | Tạo tại trang "Token" trong bảng điều khiển; có thể giới hạn theo nhóm, danh sách model được phép và IP nguồn |

Định dạng Claude (`/v1/messages`) cũng nhận header `x-api-key`; định dạng Gemini (`/v1beta/models/...`) nhận header `x-goog-api-key` hoặc tham số truy vấn `?key=`.

Lỗi được trả về theo định dạng OpenAI:

```json
{"error": {"message": "mô tả lỗi", "type": "loại lỗi", "param": "", "code": "mã lỗi"}}
```

## API mô hình AI

Một token có thể gọi mọi nhà cung cấp mà nền tảng đã tổng hợp. API chia thành bốn nhóm giao thức:

| Giao thức | Các endpoint chính |
|---|---|
| OpenAI | `POST /v1/chat/completions`, `POST /v1/completions`, `POST /v1/responses`, `POST /v1/embeddings`, `POST /v1/images/generations`, `POST /v1/images/edits`, `POST /v1/audio/speech`, `POST /v1/audio/transcriptions`, `POST /v1/audio/translations`, `POST /v1/moderations`, `POST /v1/rerank`, `GET /v1/models`, `GET /v1/models/{model}` |
| Anthropic | `POST /v1/messages` |
| Gemini | `POST /v1beta/models/{model}:generateContent`, `POST /v1/engines/{model}/embeddings` |
| Tác vụ video | `POST /v1/video/generations`, `GET /v1/video/generations/{task_id}`, `POST /v1/videos`, `GET /v1/videos/{id}`, `GET /v1/videos/{id}/content`, `POST /v1/videos/{id}/remix` |

Model mà token gọi được phụ thuộc vào nhóm của token, danh sách model được phép và cấu hình tính phí của model. Luôn dùng tên model do `GET /v1/models` trả về, không tự đoán ID model.

## Tính phí và giới hạn

- Khi nhận yêu cầu, hạn mức được tạm trừ theo đơn giá model và lượng dùng ước tính, sau đó quyết toán theo lượng dùng thực tế. Yêu cầu thất bại và tác vụ không tạo ra kết quả được hoàn lại.
- Hết hạn mức trả về `403`; giới hạn tần suất hoặc nghẽn đồng thời phía upstream trả về `429`; model không tồn tại hoặc nhóm hiện tại không có kênh khả dụng trả về `503`.
- Số lượng ảnh `n` tối đa là 128. Thời lượng, độ phân giải và số lượng lô video theo giới hạn của model đã chọn; yêu cầu vượt giới hạn bị từ chối trước khi được nhận.

## Endpoint chưa triển khai

`/v1/files*`, `/v1/fine-tunes*`, `/v1/images/variations` và `DELETE /v1/models/{model}` hiện trả về `501`. Không gọi trong môi trường production.
