# Mô hình (Models)

Uter cung cấp ba endpoint tra cứu model:

| Endpoint | Mô tả |
|---|---|
| `GET /v1/models` | Danh sách model token hiện tại gọi được |
| `GET /v1/models/{model}` | Chi tiết một model |
| `GET /v1beta/models` | Cùng danh sách ở định dạng Gemini gốc |

Danh sách được lọc theo nhóm của token, danh sách model được phép và cấu hình tính phí. Hãy dựa vào kết quả trả về, không hardcode tên model.

`GET /v1/models` chọn định dạng phản hồi theo header:

- có `x-api-key` và `anthropic-version` → định dạng Anthropic
- có `x-goog-api-key` hoặc tham số `key` → định dạng Gemini
- còn lại → định dạng OpenAI

Xem "Định dạng OpenAI gốc" và "Định dạng Native Gemini" để biết trường dữ liệu và ví dụ phản hồi của từng định dạng.
