# Định dạng OpenAI gốc

Các endpoint hình ảnh của Uter tương thích OpenAI Images API. Chỉ dùng được các model do `GET /v1/models` trả về; kích thước, mức chất lượng và tham số riêng tùy model, giá trị vượt giới hạn sẽ bị từ chối với `400`.

## Tạo hình ảnh

`POST` `/v1/images/generations`

### Body yêu cầu (`application/json`)

| Trường | Kiểu | Bắt buộc | Mô tả |
|---|---|---|---|
| `model` | string | Có | ID model hình ảnh lấy từ `GET /v1/models` |
| `prompt` | string | Có | Mô tả hình ảnh |
| `n` | integer | Không | Số lượng ảnh, 1–128 (giới hạn nền tảng), mặc định 1 |
| `size` | string | Không | Kích thước, ví dụ `1024x1024`; giá trị hợp lệ tùy model |
| `quality` | string | Không | Mức chất lượng; tùy model |
| `response_format` | enum (`url`, `b64_json`) | Không | Định dạng phản hồi, mặc định `url` |
| `background` | string | Không | Chế độ nền (`transparent` / `opaque` / `auto`); chỉ một số model |
| `output_format` | string | Không | Định dạng đầu ra (`png` / `jpeg` / `webp`); chỉ một số model |
| `output_compression` | integer | Không | Mức nén đầu ra; chỉ một số model |
| `moderation` | string | Không | Mức kiểm duyệt; chỉ một số model |
| `stream` | boolean | Không | Trả dần ảnh từng phần; chỉ một số model |
| `user` | string | Không | Mã người dùng do bên gọi cung cấp |

### Phản hồi

| Mã | Ý nghĩa |
|---|---|
| `200` | Tạo thành công |
| `400` | Tham số không hợp lệ (`n` vượt giới hạn, kích thước model không hỗ trợ) |
| `403` | Không đủ hạn mức |

#### Trường `200`

| Trường | Kiểu | Mô tả |
|---|---|---|
| `created` | integer | Thời điểm tạo (giây Unix) |
| `data` | array&lt;object&gt; | Danh sách kết quả |
| `data[].url` | string | URL ảnh (`response_format=url`) |
| `data[].b64_json` | string | Dữ liệu ảnh Base64 (`response_format=b64_json`) |
| `data[].revised_prompt` | string | Prompt đã được upstream viết lại, nếu có trả về |
| `metadata` | object | Siêu dữ liệu bổ sung từ upstream, nếu có |

## Chỉnh sửa hình ảnh

`POST` `/v1/images/edits`

### Body yêu cầu (`multipart/form-data`)

| Trường | Kiểu | Bắt buộc | Mô tả |
|---|---|---|---|
| `image` | tệp (hoặc mảng chuỗi) | Có | Ảnh cần chỉnh sửa; một số model nhận nhiều ảnh |
| `mask` | tệp | Không | Mặt nạ, vùng trong suốt là khu vực cần vẽ lại |
| `prompt` | string | Có | Mô tả chỉnh sửa |
| `model` | string | Có | ID model hình ảnh lấy từ `GET /v1/models` |
| `n` | integer | Không | Số lượng ảnh, 1–128, mặc định 1 |
| `size` | string | Không | Kích thước đầu ra; tùy model |
| `response_format` | enum (`url`, `b64_json`) | Không | Định dạng phản hồi, mặc định `url` |
| `user` | string | Không | Mã người dùng do bên gọi cung cấp |

### Phản hồi

Cấu trúc giống "Tạo hình ảnh"; các trường trong `data` theo `response_format`.
