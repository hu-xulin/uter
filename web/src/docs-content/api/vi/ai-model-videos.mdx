# Video (Videos)

Tạo video là tác vụ bất đồng bộ: gửi tác vụ, thăm dò trạng thái, rồi lấy kết quả. Uter cung cấp hai lối vào:

- **Định dạng tác vụ chung**: `/v1/video/generations` trả về `task_id`; các tùy chọn riêng của nhà cung cấp nằm trong `metadata`.
- **Định dạng video OpenAI**: `/v1/videos` nhận các trường của OpenAI Videos. Với model do một plugin tác vụ `openai_video` đảm nhận, cả yêu cầu và phản hồi đều tuân theo OpenAI Videos API và SDK chính thức dùng được nguyên trạng. Với các model không do plugin đó đảm nhận, yêu cầu được chuyển về relay tác vụ chung và phản hồi dùng phong bì tác vụ bên dưới (`task_id`, `status: queued`) thay vì một đối tượng video OpenAI.

Trường yêu cầu khác nhau theo nhà cung cấp; hãy đọc thêm trang định dạng tương ứng bên dưới.

## Tạo tác vụ tạo video

`POST` `/v1/video/generations`

### Body yêu cầu (`application/json`)

| Trường | Kiểu | Bắt buộc | Mô tả |
|---|---|---|---|
| `model` | string | Có | ID model video lấy từ `GET /v1/models`; cũng quyết định kênh và cách tính phí |
| `prompt` | string | Không | Câu lệnh văn bản |
| `image` | string | Không | Ảnh khung đầu (URL hoặc Base64) |
| `images` | array&lt;string&gt; | Không | Nhiều ảnh tham chiếu (một số model hỗ trợ) |
| `duration` | number | Không | Thời lượng tính bằng giây; giới hạn trên tùy model |
| `size` | string | Không | Độ phân giải, ví dụ `1280x720` |
| `metadata` | object | Không | Tùy chọn của nhà cung cấp như `negative_prompt`, `seed`, `fps` |
| `user` | string | Không | Mã người dùng do bên gọi cung cấp, chỉ để truy vết |

### Phản hồi

| Mã | Ý nghĩa |
|---|---|
| `200` | Đã nhận tác vụ |
| `400` | Yêu cầu không hợp lệ (thiếu model, thời lượng vượt giới hạn…) |
| `403` | Không đủ hạn mức |
| `429` | Nghẽn đồng thời phía upstream |
| `503` | Model không tồn tại hoặc nhóm hiện tại không có kênh khả dụng |

#### Trường `200`

| Trường | Kiểu | Mô tả |
|---|---|---|
| `id` | string | ID tác vụ (giống `task_id`) |
| `task_id` | string | ID tác vụ |
| `status` | string | Trạng thái ban đầu, thường là `queued` |
| `model` | string | Model thực tế được dùng |
| `created_at` | integer | Thời điểm tạo (giây Unix) |

Một số nhà cung cấp trả phản hồi trực tiếp từ plugin tác vụ; khi đó các trường theo trang của nhà cung cấp đó.

## Truy vấn tác vụ video

`GET` `/v1/video/generations/{task_id}`

Trả về phong bì tác vụ thống nhất của Uter (`code` là `success` khi thành công):

```json
{
  "code": "success",
  "message": "",
  "data": {
    "task_id": "task_xxx",
    "status": "SUCCESS",
    "progress": "100%",
    "result_url": "https://example.com/result.mp4",
    "fail_reason": "",
    "submit_time": 1699990000,
    "start_time": 1699990010,
    "finish_time": 1699990200,
    "properties": {},
    "data": {}
  }
}
```

| Trường | Kiểu | Mô tả |
|---|---|---|
| `code` | string | `success` khi thành công; giá trị khác là mã lỗi |
| `data.task_id` | string | ID tác vụ |
| `data.status` | string | `NOT_START` / `SUBMITTED` / `QUEUED` / `IN_PROGRESS` / `SUCCESS` / `FAILURE` |
| `data.progress` | string | Tiến độ, ví dụ `45%` |
| `data.result_url` | string | URL kết quả khi tác vụ thành công |
| `data.fail_reason` | string | Lý do thất bại |
| `data.properties` | object | Bản chụp tham số đã gửi (model, thời lượng, độ phân giải…) |
| `data.data` | object | Kết quả gốc từ nhà cung cấp |

Tác vụ không tồn tại hoặc thuộc người dùng khác trả về `400` (`task_not_exist`).

## Dùng định dạng video OpenAI

`POST` `/v1/videos` nhận `application/json` và `multipart/form-data` với các trường OpenAI Videos: `model`, `prompt`, `seconds`, `size`, `input_reference`… Phản hồi là đối tượng video OpenAI:

```json
{
  "id": "task_xxx",
  "object": "video",
  "model": "sora-2",
  "status": "queued",
  "progress": 0,
  "created_at": 1699990000,
  "seconds": "8",
  "size": "1280x720"
}
```

Các endpoint đi kèm:

| Phương thức và đường dẫn | Mô tả |
|---|---|
| `GET /v1/videos/{id}` | Thăm dò tác vụ; khi thành công trả về `completed_at` và `status` cuối |
| `GET /v1/videos/{id}/content` | Tải luồng tệp video qua proxy; trả về `404` khi tác vụ không tồn tại |
| `POST /v1/videos/{id}/remix` | Tạo lại từ video hiện có (remix), trả về đối tượng video mới |

Lưu ý sự khác nhau về mã trạng thái: `GET /v1/videos/{id}/content` trả về `404` cho tác vụ không xác định, trong khi truy vấn tác vụ chung `GET /v1/video/generations/{task_id}` trả về `400 task_not_exist`.

Giá trị `status`: `queued`, `in_progress`, `completed`, `failed`.
