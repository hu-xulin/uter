# Responsive

## 断点

沿用 Tailwind 默认断点，不自定义：

| 前缀   | 宽度     | 典型场景             |
| ------ | -------- | -------------------- |
| （无） | < 640px  | H5、手机浏览器       |
| `sm:`  | ≥ 640px  | 大屏手机横屏、小平板 |
| `md:`  | ≥ 768px  | 平板                 |
| `lg:`  | ≥ 1024px | 笔记本               |
| `xl:`  | ≥ 1280px | 桌面                 |

## 字号策略

**桌面与移动共用同一套十档阶梯，不为移动端单独定义字号。**

只在两种情况下按断点调整：

1. **营销页主视觉**：`text-3xl md:text-4xl`（30 → 36px），即 `display` 档在
   小屏降一档。阶梯最高只到 `text-4xl`（36px），不存在 `text-5xl`；
2. **指标数值**：`text-2xl md:text-3xl`（24 → 30px），小屏避免溢出。

不允许出现「移动端 14px、桌面 12px」这种反向调整 —— 小屏需要更大的字号，不是更小。

## 输入控件与 iOS

输入控件文字全平台统一 14px（`body-sm`），**不设 H5 16px 例外**（规范 §2.1 明确
要求）。输入内容、占位符与标签字号一致，桌面与移动共用同一套阶梯。

注意：iOS Safari 在 `font-size < 16px` 的控件获得焦点时仍会自动放大页面。
本项目已决定接受该行为、优先保证全平台输入文字一致；如未来要规避，
只能整体加大控件字号，不得单独给移动端加 16px 覆盖。

## 布局

- 侧边栏在 `lg` 以上常驻，以下收起为抽屉。
- 内容区最大宽度 1280px（规范 §3 Composition），超出居中。**「内容区」指后台
  与文档类页面**；营销页（定价页的价格矩阵）按 `exceptions.md` E17 放宽到 1800px，
  弹窗按需放宽但不超过 1280px。
- 卡片网格：`grid-cols-1 sm:grid-cols-2 xl:grid-cols-3`。
- 表格在窄屏允许横向滚动，不允许把列压到文字换行成三行。

### 指标数值的断点

大号指标数值是 `text-2xl md:text-3xl`（24 → 30px）。**放大点是 `md`（768px）
而不是 `sm`（640px）**：640–768 之间的窄平板仍然是单列布局，30px 的数字会把
卡片标题挤成两行；768 之后卡片才进入多列，有横向空间容纳大号数字。

紧凑卡片（一行 4 个的统计卡）里放不下 24px 时，允许用 16/600 + `tabular-nums`
（`typography.md` 的「指标数值」例外），但**不允许**用 `sm:` 提前放大。

## 触控目标

可点击元素最小 24×24px（WCAG 2.2 AA · 2.5.8）。密集容器（徽标内的移除、
表格行内的图标按钮）里视觉尺寸只能是 16–18px，此时加 `.ds-touch-target`：

```tsx
<button className='ds-touch-target flex size-4 items-center justify-center'>
  <X />
</button>
```

它**不改元素盒子**，而是用一个居中的 `::after` 把**命中区**扩到 24px ——
视觉不变、布局不变，只有可点击范围变大。**不要**用 `min-w-6 min-h-6`：
那会把行高撑起来、把徽标顶开。

⚠️ 实现是 `position: relative` + `::after`，所以只能用在没有自己 `::after`
的元素上（侧栏拖拽轨、进度环这类不要加）。

## 长文本的阅读宽度

`body-long`（16/26）用于连续阅读内容时，容器宽度要收在可读区间，否则 16px 长文
在 1280px 里一行 60+ 字，眼睛回行会错行：

| 内容                         | 最大宽度                                            |
| ---------------------------- | --------------------------------------------------- |
| 文章正文、服务协议、隐私政策 | `max-w-[72ch]`（约 720–760px）                      |
| 帮助中心列表 + 正文          | 正文列 `max-w-[72ch]`，侧栏固定 240px               |
| AI 对话气泡                  | `max-w-[84%]`（现有实现），单气泡内仍用 `body-long` |

## 视觉回归

关键页面需要在桌面（1440×900）与手机（390×844）两个视口各取一次基线：

- 登录 / 注册
- Dashboard
- 模型列表与详情
- API Key 管理
- 请求日志
- 充值与账单
- 用户设置
- 官网首页

检查项：文字截断、换行、横向滚动、弹窗高度、输入框聚焦表现（iOS 聚焦自动
放大页面是已知取舍，不再作为回归失败项）。
