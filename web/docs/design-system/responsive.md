# Responsive

## 断点

沿用 Tailwind 默认断点，不自定义：

| 前缀 | 宽度 | 典型场景 |
| --- | --- | --- |
| （无） | < 640px | H5、手机浏览器 |
| `sm:` | ≥ 640px | 大屏手机横屏、小平板 |
| `md:` | ≥ 768px | 平板 |
| `lg:` | ≥ 1024px | 笔记本 |
| `xl:` | ≥ 1280px | 桌面 |

## 字号策略

**桌面与移动共用同一套九档阶梯，不为移动端单独定义字号。**

只在两种情况下按断点调整：

1. **营销页主视觉**：`text-3xl md:text-5xl`，小屏用小档；
2. **指标数值**：`text-base sm:text-2xl`，小屏避免溢出。

不允许出现「移动端 14px、桌面 12px」这种反向调整 —— 小屏需要更大的字号，不是更小。

## 输入控件与 iOS

移动端所有可聚焦文本控件强制 16px：

```css
@media (max-width: 767px) {
  input, select, textarea { font-size: 16px !important; }
}
```

原因：iOS Safari 在 `font-size < 16px` 的控件获得焦点时会自动放大整个页面，
用户必须手动缩放才能继续。这条规则优先于「输入框用 body-sm」的设计取值，
已登记为例外 E1。

## 布局

- 侧边栏在 `lg` 以上常驻，以下收起为抽屉。
- 内容区最大宽度 1280px，超出居中。
- 卡片网格：`grid-cols-1 sm:grid-cols-2 xl:grid-cols-3`。
- 表格在窄屏允许横向滚动，不允许把列压到文字换行成三行。

## 触控目标

可点击元素最小 24×24px（WCAG 2.2 AA）。密集表格里的图标按钮用 `.ds-touch-target`
保证下限，视觉尺寸可以更小但点击区域要够。

## 视觉回归

关键页面需要在桌面（1440×900）与手机（390×844）两个视口各取一次基线：

- 登录 / 注册
- Dashboard
- 模型列表与详情
- API Key 管理
- 请求日志
- 充值与账单
- 用户设置
- 官网首页

检查项：文字截断、换行、横向滚动、弹窗高度、输入框聚焦是否触发缩放。
