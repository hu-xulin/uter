Design Principles（10 项）

Clarity清晰信息一眼可辨，不以装饰压过内容
Consistency一致相同语义只允许一个 Token、一个组件出口
Hierarchy层级明确字号 / 字重 / 表面 / 阴影共同表达优先级
Accessibility可访问WCAG 2.2 AA 为硬门槛，例外必须登记
Efficiency高效减少操作步骤与视觉噪声，服务开发者工作流
Predictability可预测相同状态在所有组件表现一致
Responsiveness响应式7 档断点下结构与交互均有确定规则
Reliability可靠资金 / 状态 / 错误信息不得被视觉弱化
Developer Experience开发者体验代码、API Key、日志、错误栈必须可读可复制
Data Integrity数据表达准确金额 / Token / 用量不因格式或颜色产生歧义
