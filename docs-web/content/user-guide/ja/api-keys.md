# API キー

左ナビゲーションの「API Keys」をクリックするか、`/keys` に直接アクセスします。このページには、キー名、マスキングされたキー、有効状態、クォータ使用量、グループなどの情報が表示され、フィルター、コピー、編集、有効化／無効化、一括削除に対応しています。行メニューからは、接続情報のコピー、管理者が設定したチャットプリセットの開き、対応クライアント連携へのキーの送信も実行できます。

<img alt="API キー情報ページ" src="01-keys-info.webp" />

## API キーの作成

1. 「API Keys」を開き、「Create API Key」をクリックします。
2. アプリケーションや環境を識別しやすいように、キー名を入力します。
3. 必要に応じて、クォータ、有効期限、モデル制限、IP 制限、グループを設定します。
4. 保存後、一覧から完全なキーを確認してコピーします。

<img alt="API キー作成ページ" src="02-create-key.webp" />

### 設定項目の説明

| 設定項目 | 機能 |
|---|---|
| 名前 | API キーの名前（用途に応じた名前をつけることをおすすめします。例：「本番環境」「テスト用」） |
| グループ | このトークンが使用するチャネルグループを指定します |
| 自動グループ順序 | グループが `auto` の場合のみ表示されます。Root のグローバル順序を継承することも、キーの個別順序を設定することもできます。 |
| グループ横断リトライスイッチ | 有効にすると、現在のグループのチャネルで失敗した場合、順番に次のグループのチャネルを試行します。 |
| 有効期限 | 有効期限を過ぎた後は、このキーの使用を拒否します |
| 個数 | 複数の API キーを一度に作成できます（名前にはランダムなサフィックスが付加されます） |
| クォータ | このキーで消費できるクォータを制限します |
| 無制限クォータスイッチ | オンにすると、この API キーのクォータを無制限にします |
| モデル制限 | このトークンから呼び出せるモデルを限定します。空欄の場合は制限なしです |
| IP ホワイトリスト | IP または CIDR を 1 行ずつ入力できます。空欄の場合は制限なしです。信頼できるリバースプロキシや CDN と併用してください |

<Callout type="warn">
  API キーはパスワードと同じ扱いです。完全なキーをコードリポジトリ、スクリーンショット、ログ、チャットツールに貼り付けないでください。漏洩が疑われる場合は、直ちに削除して新しいキーを作成してください。
</Callout>

## API キーの確認とコピー

API キー一覧でマスキングされたキーをクリックすると、ページに表示される案内に従って、完全な値を確認してコピーできます。完全なキーは機密資格情報であり、表示、追加のセキュリティ認証が必要になる場合があります。

「Copy Connection Info」を押すと、アプリケーションのインポート情報としてキーとプラットフォームアドレスをコピーします。左サイドバーの「Chat」で対象のプリセットチャットアプリケーションをクリックすると、ブラウザーはインストール済みのチャットアプリケーションを起動し、設定情報を自動的に入力します。

<img alt="API キー確認ページ" src="03-view-key.webp" />

## API キーの編集

API キー一覧で対象のキーを探し、右側の「Edit」ボタンをクリックして、キーの設定項目を変更します（API キーそのものは変更できません）。

<img alt="API キー編集ページ" src="04-edit-key.webp" />

## API キーの有効化・無効化・削除

一覧の行操作から、キーの有効化、無効化、削除を実行できます。複数の行を選択して一括削除することもできます。無効化では設定は保持されたまま呼び出しが止まり、削除は取り消せません。

<img alt="API キー削除ページ" src="05-delete-key.webp" />

<Callout type="warn">
  削除を確認すると、API キーは直ちに無効となり、復元できません。削除前に選択したキーを必ず確認し、本番用のキーを誤って削除しないようご注意ください。
</Callout>
