# プロフィールとセキュリティ

* ログイン後、左ナビゲーションバーの「Profile」ボタンをクリックすると、プロフィールページ `/profile` にアクセスできます。
  ここでは、アカウント情報、アカウントの紐付け、通知と動作の設定、インターフェース言語、サイドバーの個人設定、チェックイン、2FA、Passkey、アクセストークン、ログインセッションを確認・管理できます。

## アカウント情報の確認

アカウント情報には、表示名、ユーザー ID、残高、累計消費クォータ、API リクエスト数などの詳細を確認できます。

<img alt="アカウント情報ページ" src="01-personal.webp" />

## アカウント紐付け情報の管理

メールアドレスやサードパーティ OAuth アカウントなど、アカウントの紐付け情報を管理します。

* メールアドレスの紐付け

1. 設定エリアで「Account Binding」→「Email」を探し、「Bind」をクリックします。
2. 紐付けたいメールアドレスを入力します。
3. 「Send」をクリックして認証コードを取得します。
4. 認証コードを入力して「Bind Email」をクリックします。

<img alt="メールアドレス紐付けページ" src="02-personal-link-email.webp" />

* サードパーティ OAuth アカウントの紐付け

1. 設定エリアで「Account Binding」→「Third-party OAuth Accounts」を探します。
2. 紐付けたいサードパーティ OAuth プラットフォームに対応する「Bind」ボタンをクリックします。
3. プラットフォームの認可ページに移動するので、ログインして「Authorize」をクリックします。
4. 認可が完了すると自動的に元の画面に戻り、紐付けの状態が「Bound」に変わります。

<img alt="サードパーティ OAuth アカウント紐付けページ" src="03-personal-link-OAuth.webp" />

## 通知と動作の設定

このページでは、アカウントの通知方法とシステム利用時の動作を設定します。

* 通知設定

1. **通知方法**：Email、Webhook、Bark、Gotify の中から選択してシステム通知を受け取れます。
2. **残高警告しきい値**：残高アラートの金額を設定します。アカウント残高がこの値を下回ると通知が送信されます。
3. **通知先メールアドレス**：通知を受け取るメールアドレスを指定します。空欄の場合は、アカウントに紐付けたメールアドレスがデフォルトで使われます。
4. 該当する情報を入力し、設定が完了したら「Save Settings」をクリックして反映させます。

* 動作の設定

1. **上流モデルの更新通知を受け取る**：有効にすると、定期的なモデルチェックで上流モデルの変更やチェック失敗を検出した場合、選択した通知方法で要約通知が送信されます。この機能は管理者のみ利用できます。
2. **未価格設定のモデルを受け入れる**：有効にすると、价格がまだ設定されていないモデルを使用できるようにします。（推奨しません）
3. **IP アドレスを記録**：有効にすると、モデルを呼び出したユーザーとリクエストでエラーが発生したときの IP アドレスを記録します。
4. 該当する情報を入力し、設定が完了したら「Save Settings」をクリックして反映させます。

<img alt="通知と動作の設定ページ" src="04-personal-notification-behavior-preferences.webp" />

<Callout type="warn">
  「未価格設定のモデルを受け入れる」を有効にすると、消費量が想定外に増える可能性があります。「未価格設定のモデルを受け入れる」はデフォルトで無効のままにすることを推奨します。
</Callout>

## デイリーチェックイン

* 毎日のチェックインを実施し、チェックイン記録と特典を確認できます。

1. 「Check in now」をクリックすると、その日のランダムなクォータ特典を受け取れます（ランダムなクォータ量はプラットフォームのシステム管理者が設定します）。
2. ページには、累計チェックイン日数、今月取得したクォータ、累計取得クォータが表示されます。
3. チェックインは 1 日 1 回のみ可能です。特典はアカウント残高に付与され、入金までにわずかに時間がかかる場合があります。

<img alt="デイリーチェックインページ" src="07-personal-check-in.webp" />

## セキュリティ設定

* このページでは、アカウントのセキュリティ設定とアクセス権限を管理します。

1. **パスワード変更**：アカウントのログインパスワードを更新し、アカウントのセキュリティを強化します。
2. **アクセストークン**：API アクセストークンを生成・管理し、外部のアプリケーションやサービスがトークンを用いて該当するインターフェースにアクセスできるようにします。
3. **アカウント削除**：現在のアカウントと関連するすべてのデータを完全に削除します。この操作は取り消せず、実行前に慎重に確認してください。

<img alt="セキュリティ設定ページ" src="08-personal-security.webp" />

<Callout type="info">
  * API アクセストークンの漏洩が疑われる場合は、リセットできます：

  1. プロフィールページで「Security Settings」エリアを探します。
  2. 「Access Tokens」→「Regenerate」をクリックします。
  3. 操作を確認すると、システムが uter アクセストークンを生成します。
  4. 古い API アクセストークンは直ちに無効となり、古い API アクセストークンを使用しているすべてのサービスを新しいトークンで再設定する必要があります。
</Callout>

<Callout type="warn">
  * アクセストークンはアカウント管理用のインターフェースで使用するもので、モデル呼び出し用の API キーとは異なります。サードパーティの AI クライアントに入力しないでください。
  * API アクセストークンをリセットすると、既存の API アクセストークンはすべて無効となり、uter アクセストークンを再作成する必要があります。
</Callout>

## 二要素認証（2FA）の有効化・無効化

* このページでは、アカウントの二要素認証（2FA）を有効化または無効化します。パスワードに追加でセキュリティ層が加わります。

1. **二要素認証を有効にする**：プロフィールページで「Two-Factor Authentication」の横にある「Enable」ボタンをクリックします。
2. **QR コードをスキャンする**：Google Authenticator や Microsoft Authenticator などの認証アプリでページ内の QR コードをスキャンするか、キーを手動で入力して紐付けます。
3. **バックアップコードを保存する**：システムが生成したバックアップコードを保存します。各コードは通常 1 回しか使えず、認証アプリが使えない場合にアカウントへのアクセスを復元するために使用できます。
4. **認証コードを入力する**：認証アプリを開いて、現在生成されている 6 桁の認証コードを入力します。
5. **有効化の完了**：「Enable 2FA」ボタンをクリックします。認証が通り次第、二要素認証の設定が完了します。
6. **バックアップコードの再生成または 2FA の無効化**：「Regenerate Backup Codes」ボタンまたは「Disable 2FA」ボタンをクリックし、表示に従って該当する操作を完了します。

<img alt="2FA 設定ページ" src="09-personal-2fa.webp" />

<Callout type="warn">
  バックアップコードは一度しか表示されず、ポップアップを閉じると再表示できません。バックアップコードを紛失し、認証アプリも使用できない場合は、管理者に連絡してリセットを依頼してください。
</Callout>

## Passkey パスワードレスログインの有効化・無効化

* このアカウントの Passkey ログイン機能を有効化または無効化できます。有効にすると、デバイスの顔認識や指紋などの本人確認方法、画面ロック、セキュリティキーを使用して、パスワードを入力せずにログインできます。

1. **Passkey を有効にする**：「Passkey Login」エリアで「Enable Passkey」をクリックします。
2. **セキュリティ認証を完了する**：表示に従って、認証アプリが生成した 6 桁の動的認証コードを入力するか、8 桁のバックアップコードを入力して「Verify」をクリックします。
3. **Passkey を登録する**：ブラウザーがシステム認証のダイアログを表示します。指示に従って、デバイスの指紋、顔認識、PIN などのシステム認証方法を使って Passkey の登録を完了してください。
4. **状態を確認する**：登録が成功すると、ページに「Passkey Authentication · Enabled」と表示され、最後に使用した日時が記録されます。
5. **Passkey の紐付けを解除する**：この機能を無効にするには、「Unbind Passkey」をクリックします。本人確認を完了すると、現在のアカウントの Passkey ログインが削除されます。

<img alt="Passkey 設定ページ" src="10-personal-passkey.webp" />

## ログインセッション管理

* 異なるデバイスやブラウザーでの現在のアカウントのログインセッションを確認・管理します。不審なログイン状態を早期に検知して取り除くことができます。

1. **セッション情報の表示**：ログイン中のデバイス、オペレーティングシステム、ブラウザー、IP アドレス、ログイン方法、最終アクティブ時刻、セッションの有効期限を表示します。
2. **特定のセッションからログアウト**：該当するログインセッションの右側にある「Log Out」または「Revoke」をクリックして、そのデバイスを現在のアカウントからログアウトさせます。
3. **他のセッションからログアウト**：ページ右上の「Log Out of Other Sessions」をクリックして、現在のデバイス以外のすべてのログイン中のデバイスからログアウトさせます。
4. **ログイン状態の管理**：見覚えのないデバイスや異常なログイン記録に気づいたら、直ちに該当のセッションを無効化し、速やかにアカウントパスワードを変更してください。
