# チャットアプリケーション連携

* Uter は設定を各種 AI チャットアプリケーションへ高速にインポートでき、テストや日常利用を快地に行えます。

## チャット連携の方法

* Uter は 3 つのチャット連携方法を提供しています：

1. **チャットプリセットをワンクリックでインポート**
2. **API キー設定をワンクリックでインポート**
3. **チャットアプリケーションを手動で設定**

### 利用前の準備

1. Uter にログインし、「API Key」ページでキーを作成します。
2. キーが有効であること、クォータが十分であること、有効期限が切れていないこと、現在の IP・グループ・モデル制限が呼び出しを許可していることを確認します。

<Callout type="info">
  **API キーの作成と使用方法の詳細については、[API キー](../api-keys/) のページを参照してください。**
</Callout>

### チャットプリセットのワンクリックインポート

1. 左サイドバーの「Chat」をクリックして、プラットフォームに設定されたチャットプリセットを展開します。
2. 対象のチャットプリセットをクリックします。
3. ブラウザーは、インストール済みの外部アプリケーションを新しいウィンドウで起動しようとします。
4. システムが自動的に対象のアプリケーションに移動し、設定情報を入力します。

<img alt="チャットプリセットのワンクリックインポート設定ページ" src="01-chat-presets-configuration-import.webp" />

<Callout type="info">
  Root ユーザーは、「System Settings」→「Console Content」→「Chat」でチャットプリセットを維持・管理できます。
</Callout>

### API キー設定のワンクリックインポート

1. 左サイドバーの「API Key」をクリックして入ります。
2. 使用する API キーを選択します。
3. 選択したキーの横にある「...」→「Chat」→「対象のチャットアプリケーション」をクリックします。
4. 対応するアプリケーションに移動し、選択したキーでワンクリック設定インポートを行います。

<img alt="API キー設定のワンクリックインポートページ" src="02-api-key-configuration-import.webp" />

### チャットアプリケーションの手動設定

ワンクリックインポートに対応していないアプリケーションでは、手動で設定できます：

* Uter から次の設定情報を取得します：

| 設定項目 | 内容 | 取得場所 |
|---|---|---|
| API ベース URL | API エンドポイントアドレス | Uter のアドレス。例：`https://api.example.com/v1` |
| API キー | API キー | API キーページ |
| 利用可能なモデル | 対応モデルの一覧 | モデルマーケットプレイスで、キーのグループに属する利用可能なモデルを絞り込み表示 |

* 一般的な設定手順

1. 対象のアプリケーションで「Settings」または「Configuration」の項目を探します。
2. 「Custom API」または「OpenAI Compatible Interface」の設定エリアを特定します。
3. API ベース URL と API キーを入力します。
4. 設定を保存して使用を開始します。

<Callout type="info">
  1) OpenAI API 互換インターフェースに対応したほとんどのアプリケーションは、カスタム API アドレスを入力するだけで Uter と連携できます。
  2) アプリケーションが完全なエンドポイントを要求する場合は、`https://api.example.com/v1/chat/completions` を使用してください。パスについては、アプリケーションの設定手順を参照して補完してください。
  3) **主要な AI アプリケーションのほとんどは、上記のカスタム API で接続できます。それぞれのアプリケーションの設定ガイドに従ってください。**
</Callout>

## よくある質問

* **サイドバーにチャットプリセットが表示されない**：「Profile」→「Left Sidebar Personal Settings」で「Chat」モジュールが有効になっているか確認してください。
* **利用可能なキーがないという表示**：API キーを作成または有効化し、クォータ、有効期限、モデル制限、IP ホワイトリストを確認してください。
* **デスクトップアプリケーションが起動しない**：まず対象のアプリケーションをインストールし、オペレーティングシステムが該当するカスタムプロトコルを登録済みか確認してください。ブラウザーが外部アプリケーションを開く確認を求める場合もあります。
* **Web プリセットが空白または読み込み拒否される**：対象のサイトによっては、CSP や `X-Frame-Options` によって iframe が禁止されている可能性があります。この場合は、そのアプリケーションを手動設定に切り替えてください。
* **FluentRead のキーが接続後に無効になる**：拡張機能が現在のページにインストールされ、有効になっているか確認してください。現在のバージョンではキーの接頭辞の互換性に違いがある可能性があります。それでも失敗する場合は、手動設定または別のプリセットに切り替えてください。
* **リクエストが unauthorized または forbidden を返す**：認証ヘッダーの形式、モデル名、キーの状態、グループ権限、IP 制限を確認してください。Claude や Gemini のリクエストでは、正しいパスとリクエストヘッダーを使用しているかについても確認してください。
