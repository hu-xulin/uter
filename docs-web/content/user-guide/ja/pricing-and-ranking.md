# モデルマーケットプレイスとランキング

## モデルマーケットプレイス

* 右上の「Model Marketplace」をクリックするか、`/pricing` にアクセスすると、モデルマーケットプレイスに入ります。このページには、平台上でのユーザー向けに公開されている価格が表示されます。上流サービスプロバイダーの元の価格とは異なる場合があります。
* モデルマーケットプレイスは、プラットフォームで有効になっている AI モデルを参照し、プロバイダー、課金価格、パフォーマンス、稼働状況を比較して、業務シーンに適したモデルを選ぶために使用します。

1. **モデル検索**：モデル名、プロバイダー、エンドポイント、タグに基づいて、対象モデルをすばやく検索できます。
2. **モデル絞り込み**：グループ、プロバイダー、モデルタイプ、タグなどの条件でモデルを絞り込め、すべての絞り込み条件をリセットすることもできます。
3. **価格表示**：モデルの入力・出力・キャッシュ価格を表示し、従量課金などの課金方法を表示します。
4. **価格表示の切り替え**：標準価格とチャージ価格の切り替えに対応し、1M トークンあたりまたは 1K トークンあたりの価格を表示できます。
5. **モデル並び替え**：モデル名などの条件に基づいて、モデルの表示順を調整できます。
6. **表示モード**：グリッド表示とリスト表示を切り替えられます。
7. **パフォーマンス情報**：モデルのレイテンシ、スループット、現在の稼働状況を表示し、モデルの利用可能性と応答性を評価できます。
8. **モデル詳細**：「Details」をクリックすると、モデルの完全な紹介、能力、関連する設定情報を確認できます。
9. **モデル名のコピー**：コピーボタンをクリックするとモデル名がすばやくコピーされ、API 呼び出しやシステム設定で利用できます。

## ランキング

* 右上の「Leaderboard」をクリックするか、`/rankings` にアクセスすると、ランキングに入ります。
* ランキングは、プラットフォームのモデルとプロバイダーの利用ランキングと推移を確認するためのもので、データはトークン使用量に基づいてリアルタイムで更新されます。

1. **期間の切り替え**：今日、今週、今月、今年など、異なる期間のランキングデータを表示できます。
2. **人気モデル**：グラフを通じて各モデルのデイリートークン使用量を表示し、モデルの人気度を比較できます。
3. **LLM ランキング**：プラットフォームで最も人気のあるモデルと、トークン使用量に基づく順位を表示します。
4. **市場シェア**：異なるモデルプロバイダーのトークン使用量の比率とデイリーでの変動を表示します。
5. **モデルプロバイダー順位**：総トークン使用量に基づいてモデルプロバイダーを順位付けし、各プロバイダーの利用規模を把握できます。
6. **上昇トレンド**：順位が上昇しているモデルと、その順位の変化を表示します。
7. **下降トレンド**：順位が下降しているモデルと、その順位の変化を表示します。
