# 登録とログイン

アカウント登録、パスワード忘れのリセット、アカウントパスワードでのログイン、および Passkey と各種サードパーティ OAuth 連携によるワンクリックログインに対応しています。初めてご利用になる場合は、先に登録を完了してください。

## ログイン

### アカウントパスワードでログイン

1. プラットフォームのトップページを開き、右上隅の「Login」ボタンをクリックするか、`/sign-in` に直接アクセスします。
2. ユーザー名またはメールアドレスとパスワードを入力します。
3. ページに Cloudflare Turnstile が表示されている場合は、人間認証を完了してください。
4. まず、ユーザー規約とプライバシーポリシーを読み、同意することを確認してから、「Login」をクリックします。
5. アカウントで 2FA が有効になっている場合、ワンタイム認証コードまたはバックアップコードの入力も求められます。

<img alt="ログインページ" src="01-login.webp" />

### Passkey およびサードパーティ OAuth でのログイン

ログインページには、GitHub、Discord、LinuxDO、Passkey など、プラットフォームで有効になっているサードパーティプラットフォームのアイコンが表示されます。サードパーティアカウントまたは Passkey でログインするには、次の手順で操作します。

1. ユーザー規約とプライバシーポリシーを読み、同意することを確認します。
2. ページ下部にある、該当するプラットフォーム（GitHub、Discord、LinuxDO など）または Passkey のアイコンをクリックします。
3. サードパーティアカウントを使う場合はサードパーティの認可ページに移動して認可を完了し、Passkey を使う場合はブラウザーやデバイスに表示される指示に従って認証を完了してください。

<img alt="OAuth ログインページ" src="02-login.webp" />

<Callout type="info">
  Passkey およびサードパーティ OAuth のログイン方法、および人間認証を有効にするかどうかは、プラットフォームのスーパー管理者（Root）が「System Settings」→「Authentication」で設定します。無効にした方法はログインページに表示されません。
</Callout>

## 登録

### 登録手順

1. ログインページで「Register」をクリックするか、`/sign-up` に直接アクセスします。
2. ユーザー名、パスワード、パスワード（確認）を入力します。
3. プラットフォームの設定でメールアドレスの確認が求められる場合は、メールアドレスを入力し、認証コードを送信して、受け取ったコードを入力します。
4. プラットフォームで Cloudflare Turnstile が有効になっている場合は、人間認証を完了してください。
5. まず、ユーザー規約とプライバシーポリシーを読み、同意することを確認してから、「Create Account」をクリックして登録を完了します。

<img alt="登録ページ" src="03-register.webp" />

<Callout type="info">
  パスワードでの登録、OAuth での登録、メールアドレスの確認、およびメールアドレスドメインやエイリアスの制限を許可できるかどうかは、Root の認証設定によって決まります。
</Callout>

### ログインセッション管理

ログインに成功すると、独立したセッションが確立されます。ログイン中のユーザーは、左サイドバーの「Profile」→「Login Sessions」から、現在の他のデバイスとのログインセッションを確認したり、個々のセッションを無効化したり、すべての他のセッションを一度にログアウトしたりできます。現在のセッションを無効化した場合は、ログインページに戻ります。

<img alt="ログインセッションページ" src="04-login-session.webp" />

## パスワード忘れのリセット

1. ログインページで「Forgot Password」をクリックします。
2. アカウントに関連付けたメールアドレスを入力して送信します。
3. システムから送信されたリセットリンクを開きます。
4. リセットページで新しいパスワードを設定してから、もう一度ログインします。
