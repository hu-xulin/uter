# 概要とダッシュボード

## 概要ページ

* ログイン後、左ナビゲーションバーの「Overview」ボタンをクリックすると、概要ページ `/dashboard/overview` に入ります。
  クイックスタートガイド、利用状況とヘルスステータス、API 情報、お知らせ、FAQ、アップタイムなどのカードを確認できます。

### クイックスタートガイド

1. 「Create API Key」をクリックして `/keys` に移動します。
2. ウォレットにクォータをチャージします（課金が有効な場合）。
3. プレイグラウンドを開くか、ご自身のクライアントから最初のリクエストを送信して、経路を確認します。

<img alt="クイックスタートページ" src="01-overview-get-started.webp" />

### 利用状況とヘルスステータス

このページは、現在のアカウントとインスタンスのデータに基づいて、残高、消費量、リクエスト数、成功率、レイテンシ、スループットなどの指標をまとめて表示します。

<img alt="概要情報ページ1" src="02-overview-info-1.webp" />

### API 情報、お知らせ、FAQ、アップタイム

このページには、API 情報、お知らせ、FAQ、アップタイムなどの情報が表示されます。

<img alt="概要情報ページ2" src="03-overview-info-2.webp" />

<Callout type="info">
  これらのカードは、Root が「System Settings」→「Console Content」で設定します。
</Callout>

## ダッシュボード

* ログイン後、左ナビゲーションバーの「Dashboard」ボタンをクリックすると、ダッシュボードページ `/dashboard/models` に入ります。
  モデル呼び出しの分析とトラフィック分散を確認できます。ユーザー統計については `/dashboard/users` を開いてください（Admin と Root のみ）。

### モデル呼び出し分析

期間、モデル、グループごとに、呼び出し回数、トークン使用量、消費の分布、パフォーマンス指標を表示します。

<img alt="データダッシュボード情報ページ1" src="04-dashboard-info-1.webp" />

### トラフィック分散

ユーザー、API キー、グループ、モデル、チャネル間のリクエストの流れを表示します。

<img alt="データダッシュボード情報ページ2" src="05-dashboard-info-2.webp" />

### ユーザー統計

`/dashboard/users` にアクセスしてユーザー分析を表示できるのは、Admin と Root のみです。一般ユーザーのナビゲーションには、このセクションは表示されません。
