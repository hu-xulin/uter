# API 金鑰

左側導航點選「API 金鑰」，或直接訪問 `/keys`。頁面展示金鑰名稱、掩碼金鑰、啟用狀態、額度使用情況、分組等資訊，並支援篩選、複製、編輯、啟用/禁用和批次刪除。行選單還可複製連線資訊、開啟管理員配置的聊天預設，以及把金鑰傳送到受支援的客戶端整合。

<img alt="API金鑰資訊頁" src="01-keys-info.webp" />

## 建立 API 金鑰

1. 開啟「API 金鑰」，點選「建立 API 金鑰」。
2. 填寫金鑰名稱，便於區分應用或環境。
3. 按需設定額度、過期時間、模型限制、IP 限制和分組。
4. 儲存後從列表中檢視並複製完整金鑰。

<img alt="建立API金鑰頁" src="02-create-key.webp" />

### 配置項說明

| 設定        | 作用                                           |
| --------- | -------------------------------------------- |
| 名稱        | API金鑰名稱（建議按用途命名，如「生產環境」「測試用」）                |
| 分組        | 指定該令牌使用的渠道分組                                 |
| Auto 分組順序 | 僅在分組為 `auto` 時顯示；可以繼承 Root 的全域性順序，也可以設定金鑰級順序。 |
| 跨分組重試開關   | 開啟後，當前分組渠道失敗時會按順序嘗試下一個分組的渠道。                 |
| 過期時間      | 到期後拒絕使用該金鑰                                   |
| 數量        | 可一次性建立多個 API 金鑰（名稱將新增隨機字尾）                   |
| 額度        | 限制該金鑰可消耗的額度                                  |
| 無限額度開關    | 開啟後為此 API 金鑰啟用無限配額                           |
| 模型限制      | 限定該令牌只能呼叫指定模型，留空表示不限制                        |
| IP 白名單    | 支援逐行填寫 IP 或 CIDR，留空表示不限制；應配合可信反向代理/CDN 使用    |

<Callout type="warn">
  API 金鑰等同於密碼。不要把完整金鑰提交到程式碼倉庫、截圖、日誌或聊天工具；懷疑洩露時應立即刪除並建立新金鑰。
</Callout>

## 檢視和複製 API 金鑰

在 API 金鑰列表中點選掩碼金鑰，按頁面提示檢視和複製完整值。完整金鑰屬於敏感憑證，檢視行為可能需要額外安全驗證。

「複製連線資訊」會將金鑰和平臺地址複製為應用匯入資訊；點選左側欄「聊天」中的目標預設聊天應用，瀏覽器將嘗試啟動已安裝的聊天應用，並自動跳轉填充配置資訊。

<img alt="檢視API金鑰頁" src="03-view-key.webp" />

## 編輯 API 金鑰

在API金鑰列表中找到目標金鑰，點選右側「編輯」按鈕，可修改金鑰的配置選項（不包括API金鑰本身）。

<img alt="編輯API金鑰頁" src="04-edit-key.webp" />

## 啟用、禁用和刪除API 金鑰

在列表行操作中可啟用、禁用或刪除金鑰；選擇多行後可以批次刪除。禁用可保留配置並停止呼叫，刪除則不可恢復。

<img alt="刪除API金鑰頁" src="05-delete-key.webp" />

<Callout type="warn">
  刪除確認後該API金鑰立即失效，無法恢復。刪除前請確認所選金鑰，避免誤刪生產金鑰。
</Callout>
