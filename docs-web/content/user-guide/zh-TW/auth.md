# 註冊與登入

支援賬號註冊、忘記密碼重置、賬號密碼登入以及Passkey和多種第三方 OAuth 一鍵登入，首次使用請先完成註冊。

## 登入

### 賬號密碼登入

1. 開啟平臺首頁，點選右上角的「登入」按鈕，或直接訪問 `/sign-in`。
2. 輸入使用者名稱或電子郵件和密碼。
3. 若頁面顯示 ​Cloudflare Turnstile，需要完成人機驗證。
4. 先點選已閱讀並同意接受使用者協議和隱私政策後，再點選「登入」。
5. 賬號啟用 2FA 時，登入會額外需要輸入一次性驗證碼或備份碼。

<img alt="登入頁" src="01-login.webp" />

### Passkey 和第三方 OAuth 登入

登入頁會顯示平臺已啟用的 GitHub、Discord、LinuxDO 等第三方平臺或Passkey圖示。如需使用第三方賬號或Passkey登入:

1. 點選已閱讀並同意接受使用者協議和隱私政策。
2. 點選頁面下方對應平臺的圖示(GitHub、Discord、LinuxDO 等)或Passkey圖示。
3. 使用第三方賬號時，跳轉至第三方授權頁面完成授權；使用 Passkey 時，按瀏覽器或裝置提示完成驗證。

<img alt="OAuth登入頁" src="02-login.webp" />

<Callout type="info">
  Passkey和第三方OAuth登入方式以及是否開啟人機驗證由平臺超級管理員（Root）在「系統設定」 → 「身份驗證」中啟用。未啟用的方式不會出現在登入頁。
</Callout>

## 註冊

### 註冊流程

1. 在登入頁點選「註冊」，或直接訪問 `/sign-up`。
2. 填寫使用者名稱、密碼和確認密碼。
3. 若平臺設定要求郵箱驗證，填寫郵箱、傳送驗證碼並輸入收到的驗證碼。
4. 若平臺啟用了 ​Cloudflare Turnstile，需要完成人機驗證。
5. 先點選已閱讀並同意接受使用者協議和隱私政策後，再點選「建立賬戶」完成註冊。

<img alt="註冊頁" src="03-register.webp" />

<Callout type="info">
  是否允許密碼註冊、OAuth 註冊、郵箱驗證以及郵箱域名/別名限制，均由 Root 的身份驗證設定決定。
</Callout>

### 登入會話管理

登入成功後會建立獨立會話。已登入使用者可以點選左側邊欄「個人資料」 → 「登入會話」區域檢視當前與其他裝置的登入會話，撤銷單個會話或一次退出其他會話；撤銷當前會話後會返回登入頁。

<img alt="登入會話頁" src="04-login-session.webp" />

## 忘記密碼重置

1. 在登入頁點選「忘記密碼」。
2. 輸入與賬戶關聯的郵箱並提交。
3. 開啟系統傳送的重置連結。
4. 在重置頁面設定新密碼，然後重新登入。
