# 個人資料與安全

* 登入後點選左側導航欄按鈕「個人資料」進入個人資料頁 `/profile`。
  可檢視或管理賬戶資訊、賬戶繫結、通知與行為偏好、介面語言、個人側邊欄、簽到、2FA、Passkey、訪問令牌和登入會話。

## 管理賬號繫結資訊

管理賬號繫結資訊包括郵箱和第三方OAuth賬號。

* 繫結郵箱

1. 在設定區域找到「賬戶繫結」 → 「郵箱」 → 點選「繫結」。
2. 輸入需要繫結的電子郵箱。
3. 點選「傳送」獲取驗證碼。
4. 輸入驗證碼並點選「繫結郵箱」。

<img alt="繫結郵箱頁" src="02-personal-link-email.webp" />

* 繫結第三方OAuth賬號

1. 在設定區域找到「賬戶繫結」 → 「第三方OAuth賬號」。
2. 點選要繫結的第三方OAuth平臺對應的「繫結」按鈕。
3. 頁面跳轉至該平臺的授權頁面，登入並點選「授權」。
4. 授權完成後自動跳回，繫結狀態變為"已繫結"。

<img alt="繫結第三方OAuth賬號頁" src="03-personal-link-OAuth.webp" />

## 設定通知和行為偏好

該頁面用於配置賬戶通知方式及系統使用偏好。

* 通知設定

1. **通知方式**：支援選擇郵箱、Webhook、Bark 或 Gotify 接收系統通知。
2. **餘額警告閾值**：設定餘額預警金額，當賬戶餘額低於該數值時傳送通知。
3. **通知郵箱**：指定接收通知的郵箱地址；留空時預設使用賬戶繫結郵箱。
4. 輸入對應資訊，完成配置後，單擊 “儲存設定” 使修改生效。

* 行為偏好設定

1. **接收上游模型更新通知**：開啟後，定時模型檢查發現上游模型發生變化或檢查失敗時，將透過所選通知方式傳送彙總通知；該功能僅管理員可用。
2. **接受未定價模型**：開啟後，允許使用尚未配置價格的模型。（不推薦）
3. **記錄 IP 地址**：開啟後，記錄使用者呼叫模型以及請求發生錯誤時的 IP 地址。
4. 輸入對應資訊，完成配置後，單擊 “儲存設定” 使修改生效。

<img alt="通知和行為偏好設定頁" src="04-personal-notification-behavior-preferences.webp" />

<Callout type="warn">
  開啟「接受未定價模型」可能導致意外的高額消耗，建議保持預設的關閉「接受未定價模型」設定
</Callout>

## 安全設定

* 該頁面用於管理賬戶安全配置及賬戶訪問許可權。

1. **更改密碼**：用於更新賬戶登入密碼，提升賬戶安全性。
2. **訪問令牌**：用於生成和管理 API 訪問令牌，支援外部應用或服務透過令牌訪問相關介面。
3. **刪除賬戶**：用於永久刪除當前賬戶及其所有相關資料。該操作具有不可逆性，執行前應謹慎確認。

<img alt="安全設定頁" src="08-personal-security.webp" />

<Callout type="info">
  * 如果懷疑 API 訪問令牌洩露，可以重置 API 訪問令牌：

  1. 在個人資料頁找到「安全設定」區域
  2. 點選「訪問令牌」 → 「重新生成」
  3. 確認操作後，系統生成新的 API 訪問令牌
  4. 舊 API 訪問令牌立即失效，所有使用的舊 API 訪問令牌需要重新建立
</Callout>

<Callout type="warn">
  * 訪問令牌用於賬戶管理介面，與呼叫模型的 API 金鑰不同，不應填入第三方 AI 客戶端。
  * 重置 API 訪問令牌後，所有現有 API 訪問令牌將失效，需要重新建立 API 訪問令牌。
</Callout>

## 啟用或禁用兩步認證（2FA）

* 該頁面用於為賬戶啟用或禁用雙重身份驗證（2FA），在密碼之外增加額外的安全保護。

1. **啟用兩步驗證**：在個人資料頁面點選「兩步驗證」旁的「啟用」按鈕。
2. **掃描二維碼**：使用 Google Authenticator、Microsoft Authenticator 等身份驗證器應用掃描頁面中的二維碼，也可以手動輸入金鑰進行繫結。
3. **儲存備份程式碼**：儲存系統生成的備份程式碼，每個程式碼通常只能使用一次，用於身份驗證器無法使用時恢復賬戶訪問。
4. **輸入驗證碼**：開啟身份驗證器應用，輸入當前生成的 6 位數字驗證碼。
5. **完成啟用**：點選「啟用 2FA」按鈕，驗證透過後即可完成雙重身份驗證設定。
6. **重新生成備用程式碼或禁用2FA**：點選「重新生成備用程式碼」按鈕或「禁用 2FA 」按鈕，按照提示完成對應操作。

<img alt="2FA設定頁" src="09-personal-2fa.webp" />

<Callout type="warn">
  備用碼只顯示一次，關閉彈窗後無法再次檢視。丟失備用碼且無法使用驗證器時，需聯絡管理員重置。
</Callout>

## 啟用或禁用 Passkey 無密碼登入

* 可啟用或禁用該賬號的 Passkey（通行金鑰）登入功能，啟用後可使用裝置的生物識別、螢幕鎖或安全金鑰登入，無需輸入密碼。

1. **啟用 Passkey**：在「Passkey登入」區域點選「啟用 Passkey」。
2. **完成安全驗證**：根據提示輸入身份驗證器應用生成的 6 位動態驗證碼，或輸入 8 位備份程式碼並點選「驗證」。
3. **註冊通行金鑰**：瀏覽器彈出系統驗證提示，按提示完成裝置的指紋、人臉識別、PIN 碼或其他系統驗證方式完成 Passkey 註冊。
4. **檢視狀態**：註冊成功後，頁面會顯示“通行金鑰認證·已啟用”，並記錄最近一次使用時間。
5. **解綁 Passkey**：如需停用該功能，點選「解綁 Passkey」，完成身份驗證後即可解除當前賬戶的通行金鑰登入。

<img alt="Passkey設定頁" src="10-personal-passkey.webp" />

## 登入會話管理

* 用於檢視和管理當前賬戶在不同裝置及瀏覽器上的登入會話，幫助使用者及時發現並移除異常登入狀態。

1. **檢視會話資訊**：檢視已登入裝置、作業系統、瀏覽器、IP 地址、登入方式、最近活躍時間和會話到期時間。
2. **退出指定會話**：在對應登入會話右側點選「登出」或「撤銷」，使該裝置退出當前賬戶。
3. **退出其他會話**：點選頁面右上角「退出其他會話」，可一次性退出除當前裝置之外的其他登入裝置。
4. **管理登入狀態**：發現不熟悉的裝置或異常登入記錄時，立即撤銷對應會話，並及時修改賬戶密碼。

<img alt="登入會話管理頁" src="11-personal-login-sessions.webp" />
