# 聊天應用整合

* 優特 支援快速匯入配置到多種 AI 聊天應用，方便測試和日常使用。

## 聊天整合方式

* 優特 的聊天整合有三種方式：

1. **聊天預設一鍵匯入配置**
2. **API金鑰一鍵匯入配置**
3. **手動配置聊天應用**

### 使用前準備

1. 登入 優特，並在「API 金鑰」頁面建立一個金鑰。
2. 確認金鑰處於啟用狀態，額度充足，金鑰狀態未過期，並且當前 IP、分組和模型限制允許本次呼叫。

<Callout type="info">
  **建立和使用API金鑰的具體步驟請參閱[API 金鑰](../api-keys/)頁面。**
</Callout>

### 聊天預設一鍵匯入配置

1. 點選左側欄「聊天」展開平臺已配置的聊天預設
2. 點選目標聊天預設
3. 瀏覽器會嘗試在新視窗中啟動已安裝的外部應用
4. 系統自動跳轉到目標應用並填充配置資訊

<img alt="聊天預設一鍵匯入配置頁" src="01-chat-presets-configuration-import.webp" />

<Callout type="info">
  Root 可以在「系統設定」 → 「控制檯內容」 → 「聊天」維護管理聊天預設。
</Callout>

### API金鑰一鍵匯入配置

1. 點選進入左側欄「API 金鑰」
2. 選中需要使用的API金鑰
3. 在選中的金鑰旁點選「 ... 」 → 「聊天」 → 「目標聊天應用」
4. 快速跳轉至對應應用並使用選中金鑰一鍵匯入配置

<img alt="API金鑰一鍵匯入配置頁" src="02-api-key-configuration-import.webp" />

### 手動配置聊天應用

對於不支援一鍵匯入的應用，可以手動配置：

* 從 優特 獲取以下配置資訊：

| 配置項          | 說明       | 獲取位置                                      |
| ------------ | -------- | ----------------------------------------- |
| API Base URL | API 介面地址 | 優特地址，例如 `https://api.example.com/v1` |
| API Key      | API 金鑰   | API 金鑰頁面                                  |
| 可用模型         | 支援的模型列表  | 模型廣場篩選檢視金鑰所在分組下的可用模型                      |

* 通用配置步驟

1. 在目標應用中找到「設定」或「配置」入口
2. 找到「自定義 API」或「OpenAI 相容介面」配置區域
3. 填寫 API Base URL 和 API Key
4. 儲存配置後即可使用

<Callout type="info">
  1) 大多數支援 OpenAI API 相容介面的應用都可以透過填寫自定義 API 地址的方式接入 優特。
  2) 如果應用要求完整端點，則使用 `https://api.example.com/v1/chat/completions`，看應用具體配置說明補充路徑。
  3) **主流 AI 應用大多可透過上述自定義 API 的方式接入，具體以各應用官方的配置說明為準。**
</Callout>

## 常見問題

* **側邊欄沒有聊天預設**：在「個人資料」→「左側邊欄個人設定」區域確認「聊天」模組已啟用。
* **提示沒有可用金鑰**：建立或啟用 API 金鑰，並檢查額度、過期時間、模型限制和 IP 白名單。
* **桌面應用沒有啟動**：先安裝目標應用，並確認作業系統已註冊對應的自定義協議；瀏覽器可能還會要求確認是否開啟外部應用。
* **網頁預設空白或拒絕載入**：目標站點可能透過 CSP 或 `X-Frame-Options` 禁止 iframe。此時改用該應用的手動配置方式。
* **FluentRead 連線後金鑰無效**：確認擴充套件已安裝並在當前頁面啟用；當前版本可能存在金鑰字首相容差異，仍失敗時改用手動配置或其他預設。
* **請求返回未授權或禁止訪問**：檢查認證頭格式、模型名稱、金鑰狀態、分組許可權和 IP 限制；Claude、Gemini 請求還要確認使用了對應的路徑和請求頭。
