# 模型廣場和排行榜

## 模型廣場

* 點選右上角「模型廣場」或訪問 `/pricing` ，進入模型廣場。頁面展示的是當前平臺對使用者公開的價格，不等同於上游服務商的原始價格。
* 模型廣場用於瀏覽平臺已啟用的 AI 模型，並對比不同模型的供應商、計費價格、效能及執行狀態，幫助使用者選擇適合業務場景的模型。

1. **模型搜尋**：支援根據模型名稱、供應商、端點或標籤快速查詢目標模型。
2. **模型篩選**：支援按照分組、供應商、模型型別和標籤等條件篩選模型，也可重置全部篩選條件。
3. **價格檢視**：展示模型的輸入、輸出及快取價格，並標明按量計費等計費方式。
4. **計價切換**：支援切換標準價格與充值價格，並可按每 1M Tokens 或每 1K Tokens 檢視價格。
5. **模型排序**：支援按照模型名稱等條件調整模型的展示順序。
6. **展示方式**：支援在網格檢視與列表檢視之間切換。
7. **效能資訊**：展示模型的延遲、吞吐量及當前執行狀態，便於評估模型的可用性與響應能力。
8. **模型詳情**：點選“詳情”可檢視模型的完整介紹、能力和相關配置資訊。
9. **複製模型名稱**：點選複製按鈕，可快速複製模型名稱，方便在介面呼叫或系統配置中使用。

## 排行榜

* 點選右上角「排行榜」或訪問 `/rankings` ，進入排行榜。
* 排行榜用於檢視平臺模型及供應商的使用量排名與變化趨勢，資料基於 Token 用量實時更新。

1. **時間範圍切換**：支援按今天、本週、本月和今年檢視不同時間範圍內的排行資料。
2. **熱門模型**：透過圖表展示各模型每日 Token 用量，便於對比模型的使用熱度。
3. **LLM 排行榜**：按照 Token 用量展示平臺中最受歡迎的模型及其排名。
4. **市場份額**：展示不同模型供應商的 Token 用量佔比及每日變化情況。
5. **模型廠商排行**：根據 Token 總用量對模型供應商進行排序，便於瞭解各廠商的使用規模。
6. **上升趨勢**：展示排名正在提升的模型及其名次變化。
7. **下降趨勢**：展示排名出現下滑的模型及其名次變化。
