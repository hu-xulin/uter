# Каталог моделей и рейтинг

## Каталог моделей

* «Каталог моделей» доступен в правом верхнем углу; также можно перейти на `/pricing`, чтобы открыть Каталог моделей. Страница отображает цены, публично доступные пользователям платформы, которые могут отличаться от исходных цен апстрим-поставщиков.
* Каталог моделей предназначен для просмотра доступных на платформе AI-моделей, сравнения поставщиков, тарифов, производительности и эксплуатационного состояния различных моделей, что помогает пользователям выбирать модели, подходящие для их бизнес-сценариев.

1. **Поиск моделей**: поддерживает быстрый поиск целевых моделей по названию модели, поставщику, конечной точке или тегам.
2. **Фильтрация моделей**: поддерживает фильтрацию моделей по таким условиям, как Группа, поставщик, тип модели и теги, а также позволяет сбросить все условия фильтрации.
3. **Просмотр цен**: отображает цены на входные, выходные данные и кэш, а также указывает способы тарификации, например оплату по факту.
4. **Переключение тарифов**: поддерживает переключение между стандартными ценами и ценами пополнения, а также позволяет просматривать цены за 1 млн Токенов или за 1 тыс. Токенов.
5. **Сортировка моделей**: поддерживает изменение порядка отображения моделей по таким условиям, как название модели.
6. **Режим отображения**: поддерживает переключение между сеткой и списком.
7. **Информация о производительности**: отображает задержку модели, пропускную способность и текущее эксплуатационное состояние, что упрощает оценку доступности и отзывчивости моделей.
8. **Сведения о модели**: нажмите «Подробнее», чтобы просмотреть полное описание модели, её возможности и связанные с ней сведения о конфигурации.
9. **Копирование названия модели**: нажмите кнопку копирования, чтобы быстро скопировать название модели, что удобно для использования в вызовах API или системных конфигурациях.

## Рейтинг

* «Рейтинг» доступен в правом верхнем углу; также можно перейти на `/rankings`, чтобы открыть Рейтинг.
* Рейтинг предназначен для просмотра рейтингов использования и тенденций моделей и поставщиков платформы; данные обновляются в реальном времени на основе расхода Токенов.

1. **Переключение временного диапазона**: поддерживает просмотр данных рейтинга за различные периоды: сегодня, на этой неделе, в этом месяце и в этом году.
2. **Популярные модели**: отображает ежедневный расход Токенов по каждой модели в виде диаграмм, что упрощает сравнение популярности моделей.
3. **Рейтинг LLM**: отображает самые популярные модели платформы и их позиции на основе расхода Токенов.
4. **Доля рынка**: отображает долю расхода Токенов по различным поставщикам моделей и её ежедневные изменения.
5. **Рейтинг поставщиков моделей**: ранжирует поставщиков моделей по суммарному расходу Токенов, что помогает оценить масштаб использования каждого поставщика.
6. **Восходящий тренд**: отображает модели с улучшающимися позициями и изменения их рейтинга.
7. **Нисходящий тренд**: отображает модели со снижающимися позициями и изменения их рейтинга.
