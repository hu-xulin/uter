# Обзор и Панель

## Страница обзора

* После входа нажмите кнопку «Обзор» на левой панели навигации, чтобы перейти на страницу обзора `/dashboard/overview`.
  Доступны карточки «Быстрый старт», «Расход и состояние», «Информация об API», «Объявления», «FAQ» и «Время работы».

### Быстрый старт

1. Выбор «Создать ключ API» открывает `/keys`.
2. Пополнение кошелька квотой (если биллинг включён).
3. Открытие Песочницы или использование клиента позволяет отправить первый запрос и проверить маршрут.

<img alt="Страница быстрого старта" src="01-overview-get-started.webp" />

### Расход и состояние

Страница обобщает такие метрики, как баланс, потребление, число запросов, долю успешных запросов, задержку и пропускную способность, на основе текущих данных учётной записи и экземпляра.

<img alt="Страница информации обзора 1" src="02-overview-info-1.webp" />

### Информация об API, объявления, FAQ и время работы

Страница отображает такую информацию, как «Информация об API», «Объявления», «FAQ» и «Время работы».

<img alt="Страница информации обзора 2" src="03-overview-info-2.webp" />

<Callout type="info">
  Эти карточки настраиваются Root в разделе «Системные настройки» → «Содержимое консоли».
</Callout>

## Панель

* После входа нажмите кнопку «Панель» на левой панели навигации, чтобы перейти на страницу панели `/dashboard/models`.
  Доступны анализ вызовов моделей и распределение трафика; статистика по пользователям доступна на `/dashboard/users` (только для администраторов и Root).

### Анализ вызовов моделей

Просмотр количества вызовов, расхода Токенов, распределения потребления и показателей производительности по временным диапазонам, моделям и группам.

<img alt="Страница информации панели 1" src="04-dashboard-info-1.webp" />

### Распределение трафика

Просмотр потока запросов между пользователями, ключами API, группами, моделями и каналами.

<img alt="Страница информации панели 2" src="05-dashboard-info-2.webp" />

### Статистика по пользователям

Только Admin и Root могут открыть `/dashboard/users` для просмотра аналитики по пользователям; у обычных пользователей этот раздел не отображается в навигации.
