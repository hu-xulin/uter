# Интеграция с чат-приложениями

* Uter поддерживает быстрый импорт конфигураций в различные AI-чат-приложения, что упрощает тестирование и повседневное использование.

## Способы интеграции с чатами

* Uter предлагает три способа интеграции с чатами:

1. **Однокликовый импорт чат-пресетов**
2. **Однокликовый импорт конфигураций ключа API**
3. **Ручная настройка чат-приложений**

### Подготовка перед использованием

1. Выполнить вход в Uter и создать ключ на странице «Ключ API».
2. Убедиться, что ключ включён, имеет достаточную квоту, не истёк и что текущие ограничения по IP, группе и модели допускают вызов.

<Callout type="info">
  **Подробные шаги по созданию и использованию ключей API приведены на странице [Ключ API](../api-keys/).**
</Callout>

### Однокликовый импорт чат-пресетов

1. Нажать «Чат» в левой боковой панели, чтобы раскрыть настроенные на платформе чат-пресеты.
2. Нажать нужный чат-пресет.
3. Браузер попытается запустить установленное внешнее приложение в новом окне.
4. Система автоматически переходит к целевому приложению и заполняет конфигурацию.

<img alt="Страница однокликового импорта конфигурации чат-пресетов" src="01-chat-presets-configuration-import.webp" />

<Callout type="info">
  Пользователи Root могут создавать и управлять чат-пресетами в разделе «Системные настройки» → «Содержимое консоли» → «Чат».
</Callout>

### Однокликовый импорт конфигураций ключа API

1. Нажать, чтобы открыть «Ключ API» в левой боковой панели.
2. Выбрать используемый ключ API.
3. Рядом с выбранным ключом нажать «...» → «Чат» → «Целевое чат-приложение».
4. Быстро перейти к соответствующему приложению и импортировать конфигурацию в один клик с использованием выбранного ключа.

<img alt="Страница однокликового импорта конфигурации ключа API" src="02-api-key-configuration-import.webp" />

### Ручная настройка чат-приложений

Для приложений, не поддерживающих однокликовый импорт, доступна ручная настройка:

* Получить в Uter следующие сведения о конфигурации:

| Параметр конфигурации | Описание | Где получить |
| ------------------ | ------------------------ | ------------------------------------------------------------------------------- |
| Базовый URL API | Адрес конечной точки API | Адрес Uter, например `https://api.example.com/v1` |
| Ключ API | Ключ API | Страница «Ключ API» |
| Доступные модели | Список поддерживаемых моделей | Отфильтровать и просмотреть доступные модели в группе ключа в Каталоге моделей |

* Общие шаги настройки

1. В целевом приложении найти раздел «Настройки» или «Конфигурация».
2. Определить область настройки «Пользовательский API» или «Интерфейс, совместимый с OpenAI».
3. Ввести базовый URL API и ключ API.
4. Сохранить конфигурацию, чтобы начать использование.

<Callout type="info">
  1) Большинство приложений, поддерживающих интерфейсы, совместимые с OpenAI API, могут интегрироваться с Uter путём указания пользовательского адреса API.
  2) Если приложению требуется полная конечная точка, используется `https://api.example.com/v1/chat/completions`; конкретные инструкции по настройке приложения позволяют дополнить путь.
  3) **Большинство основных AI-приложений подключаются через описанный выше пользовательский API; следует придерживаться собственного руководства по настройке каждого приложения.**
</Callout>

## Часто задаваемые вопросы

* **В боковой панели нет чат-пресетов**: убедиться, что модуль «Чат» включён в разделе «Профиль» → «Личные настройки левой боковой панели».
* **Отображается сообщение об отсутствии доступного ключа**: создать или включить ключ API и проверить квоту, срок действия, ограничения по моделям и белый список IP.
* **Настольное приложение не запускается**: сначала установить целевое приложение и убедиться, что операционная система зарегистрировала соответствующий пользовательский протокол; браузер также может запрашивать подтверждение открытия внешнего приложения.
* **Веб-пресет пуст или отказывается загружаться**: целевой сайт может запрещать iframe с помощью CSP или `X-Frame-Options`. В этом случае следует перейти к ручной настройке данного приложения.
* **Ключ FluentRead недействителен после подключения**: убедиться, что расширение установлено и активно на текущей странице; в текущей версии возможны различия в совместимости префиксов ключей, и если ошибка сохраняется, следует перейти к ручной настройке или другому пресету.
* **Запрос возвращает «unauthorized» или «forbidden»**: проверить формат заголовка аутентификации, название модели, статус ключа, права группы и ограничения по IP; для запросов к Claude и Gemini дополнительно убедиться, что используются корректные пути и заголовки запроса.
