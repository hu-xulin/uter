# Ключи API

«Ключи API» доступны на левой панели навигации; также можно перейти непосредственно на `/keys`. Страница отображает такую информацию, как название ключа, замаскированный ключ, статус активности, расход квоты и группу, а также поддерживает фильтрацию, копирование, редактирование, включение и отключение, пакетное удаление. Меню строки также позволяет копировать сведения о подключении, открывать настроенные администратором чат-пресеты и передавать ключ в поддерживаемые клиентские интеграции.

<img alt="Страница информации о ключах API" src="01-keys-info.webp" />

## Создание ключей API

1. Открыть «Ключи API» и нажать «Создать ключ API».
2. Указать название ключа, чтобы удобно различать приложения или окружения.
3. При необходимости задать квоту, срок действия, ограничения по моделям, ограничения по IP и группы.
4. После сохранения просмотреть и скопировать полный ключ из списка.

<img alt="Страница создания ключа API" src="02-create-key.webp" />

### Описание параметров конфигурации

| Параметр                 | Функция                                                                                                                       |
| ------------------------ | ------------------------------------------------------------------------------------------------------------------------------ |
| Название | Название ключа API (рекомендуется указывать назначение, например «Рабочее окружение», «Тестовое использование») |
| Группа | Указывает группу каналов, используемую этим токеном |
| Порядок автогруппы | Отображается только при группе `auto`; может наследовать глобальный порядок Root или задавать собственный порядок на уровне ключа |
| Переключатель повтора между группами | Если включён, при сбое канала текущей группы выполняется попытка использовать канал следующей группы по порядку |
| Срок действия | Запрещает использование этого ключа после истечения срока |
| Количество | Позволяет создать несколько ключей API одновременно (к названию добавляется случайный суффикс) |
| Квота | Ограничивает квоту, которую может израсходовать этот ключ |
| Переключатель безлимитной квоты | При включении разрешает неограниченную квоту для этого ключа API |
| Ограничения по моделям | Ограничивает вызовы этим токеном только указанными моделями; пустое значение означает отсутствие ограничений |
| Белый список IP | Поддерживает ввод IP или CIDR построчно; пустое значение означает отсутствие ограничений; следует использовать только с доверенными обратными прокси и CDN |

<Callout type="warn">
  Ключи API эквивалентны паролям. Не передавайте полный ключ в репозитории кода, скриншоты, журналы или чат-инструменты; при подозрении на утечку немедленно удалите ключ и создайте новый.
</Callout>

## Просмотр и копирование ключей API

В списке ключей API нажмите на замаскированный ключ, чтобы просмотреть и скопировать полное значение согласно подсказке на странице. Полный ключ является конфиденциальными учётными данными, и его просмотр может потребовать дополнительной проверки безопасности.

«Копировать сведения о подключении» копирует ключ и адрес платформы в качестве данных для импорта в приложение; нажмите на целевой пресет чат-приложения в левой боковой панели «Чат», и браузер попытается запустить установленное чат-приложение и автоматически перейти к заполнению конфигурации.

<img alt="Страница просмотра ключа API" src="03-view-key.webp" />

## Редактирование ключей API

В списке ключей API найти нужный ключ и нажать кнопку «Редактировать» справа, чтобы изменить параметры конфигурации ключа (за исключением самого ключа API).

<img alt="Страница редактирования ключа API" src="04-edit-key.webp" />

## Включение, отключение и удаление ключей API

В списке ключей доступны включение, отключение и удаление в действиях строки; можно выбрать несколько строк для пакетного удаления. Отключение сохраняет конфигурацию и останавливает вызовы, тогда как удаление необратимо.

<img alt="Страница удаления ключа API" src="05-delete-key.webp" />

<Callout type="warn">
  После подтверждения удаления ключ API немедленно станет недействительным, и его восстановление будет невозможно. Перед удалением следует убедиться в выборе правильного ключа, чтобы случайно не удалить рабочие ключи.
</Callout>
