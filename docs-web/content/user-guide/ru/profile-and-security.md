# Профиль и безопасность

* После входа нажмите кнопку «Профиль» на левой панели навигации, чтобы открыть страницу профиля `/profile`.
  Здесь можно просматривать и управлять информацией об учётной записи, привязками учётной записи, настройками уведомлений и поведения, языком интерфейса, личной боковой панелью, отметками о посещении, 2FA, Passkey, токенами доступа и сеансами входа.

Просмотр информации об учётной записи, включая имя, идентификатор пользователя, остаток баланса, суммарно израсходованную квоту, количество запросов API и другие сведения.

## Управление информацией о привязке учётной записи

Управление информацией о привязке учётной записи, включая адрес электронной почты и сторонние учётные записи OAuth.

* Привязка электронной почты

1. В области настроек найти «Привязка учётной записи» → «Электронная почта» → нажать «Привязать».
2. Ввести адрес электронной почты, который необходимо привязать.
3. Нажать «Отправить», чтобы получить код подтверждения.
4. Ввести код подтверждения и нажать «Привязать электронную почту».

<img alt="Страница привязки электронной почты" src="02-personal-link-email.webp" />

* Привязка сторонней учётной записи OAuth

1. В области настроек найти «Привязка учётной записи» → «Сторонние учётные записи OAuth».
2. Нажать кнопку «Привязать», соответствующую сторонней платформе OAuth, которую необходимо привязать.
3. Страница перенаправит на страницу авторизации платформы; выполнить вход и нажать «Авторизовать».
4. После завершения авторизации произойдёт автоматический возврат, а статус привязки изменится на «Привязано».

<img alt="Страница привязки сторонней учётной записи OAuth" src="03-personal-link-OAuth.webp" />

## Настройка предпочтений уведомлений и поведения

Эта страница используется для настройки способов уведомления учётной записи и предпочтений использования системы.

* Настройки уведомлений

1. **Способ уведомления**: поддерживается выбор Email, Webhook, Bark или Gotify для получения системных уведомлений.
2. **Порог предупреждения о балансе**: задаёт сумму оповещения о балансе; при снижении баланса учётной записи ниже этого значения отправляется уведомление.
3. **Электронная почта для уведомлений**: указывается адрес электронной почты для получения уведомлений; если оставить пустым, по умолчанию используется привязанный к учётной записи адрес.
4. Ввести соответствующие сведения и после завершения настройки нажать «Сохранить настройки», чтобы изменения вступили в силу.

* Настройки предпочтений поведения

1. **Получать уведомления об обновлении апстрим-моделей**: если включено, при обнаружении изменений в апстрим-моделях или сбоях проверки по расписанию сводное уведомление отправляется выбранным способом уведомления; эта функция доступна только администраторам.
2. **Разрешать модели без тарификации**: если включено, разрешается использование моделей, цены для которых ещё не настроены. (Не рекомендуется)
3. **Записывать IP-адреса**: если включено, записываются IP-адреса пользователей, вызывающих модели, и моменты возникновения ошибок запросов.
4. Ввести соответствующие сведения и после завершения настройки нажать «Сохранить настройки», чтобы изменения вступили в силу.

<img alt="Страница предпочтений уведомлений и поведения" src="04-personal-notification-behavior-preferences.webp" />

<Callout type="warn">
  Включение «Разрешать модели без тарификации» может привести к непреднамеренно высокому потреблению. Рекомендуется сохранять настройку «Разрешать модели без тарификации» в выключенном состоянии по умолчанию.
</Callout>

## Ежедневная отметка о посещении

* Используется для ежедневных отметок о посещении, а также для просмотра записей о посещении и наград.

1. Нажать «Отметиться сейчас», чтобы получить случайную награду в виде квоты за текущий день. (Диапазон случайной квоты задаётся системным администратором платформы)
2. Страница отображает суммарное число дней посещения, квоту, полученную в текущем месяце, и суммарно полученную квоту.
3. Отметиться можно только один раз в сутки. Награды зачисляются на баланс учётной записи, при этом зачисление может происходить с небольшой задержкой.

## Настройки безопасности

* Эта страница используется для управления конфигурациями безопасности учётной записи и правами доступа к ней.

1. **Смена пароля**: используется для обновления пароля входа в учётную запись с целью повышения её безопасности.
2. **Токены доступа**: используются для создания и управления токенами доступа к API, позволяя внешним приложениям или сервисам обращаться к соответствующим интерфейсам с помощью токенов.
3. **Удаление учётной записи**: используется для безвозвратного удаления текущей учётной записи и всех связанных с ней данных. Эта операция необратима, и её следует тщательно подтвердить перед выполнением.

<img alt="Страница настроек безопасности" src="08-personal-security.webp" />

<Callout type="info">
  * При подозрении на компрометацию токена доступа к API его можно сбросить:

  1. На странице профиля найти область «Настройки безопасности».
  2. Нажать «Токены доступа» → «Сгенерировать заново».
  3. После подтверждения операции система создаст токен доступа uter.
  4. Старый токен доступа к API немедленно станет недействительным, и все сервисы, использующие старый токен доступа к API, потребуется перенастроить с новым.
</Callout>

<Callout type="warn">
  * Токены доступа предназначены для интерфейсов управления учётной записью и отличаются от ключей API, используемых для вызова моделей; их не следует вводить в сторонние AI-клиенты.
  * После сброса токена доступа к API все существующие токены доступа к API станут недействительными, и токены доступа uter потребуется создать заново.
</Callout>

## Включение или отключение двухфакторной аутентификации (2FA)

* Эта страница используется для включения или отключения двухфакторной аутентификации (2FA) для учётной записи, добавляя дополнительный уровень безопасности поверх пароля.

1. **Включение двухфакторной аутентификации**: на странице профиля нажать кнопку «Включить» рядом с пунктом «Двухфакторная аутентификация».
2. **Сканирование QR-кода**: использовать приложение-аутентификатор, например Google Authenticator или Microsoft Authenticator, чтобы отсканировать QR-код на странице, либо ввести ключ вручную для привязки.
3. **Сохранение резервных кодов**: сохранить сгенерированные системой резервные коды. Каждый код, как правило, можно использовать только один раз для восстановления доступа к учётной записи, если аутентификатор недоступен.
4. **Ввод кода подтверждения**: открыть приложение-аутентификатор и ввести сгенерированный в данный момент шестизначный код подтверждения.
5. **Завершение включения**: нажать кнопку «Включить 2FA». После проверки настройка двухфакторной аутентификации будет завершена.
6. **Генерация новых резервных кодов или отключение 2FA**: нажать кнопку «Сгенерировать резервные коды заново» или кнопку «Отключить 2FA» и следовать подсказкам, чтобы выполнить соответствующее действие.

<img alt="Страница настроек 2FA" src="09-personal-2fa.webp" />

<Callout type="warn">
  Резервные коды отображаются только один раз и недоступны для повторного просмотра после закрытия всплывающего окна. При утрате резервных кодов и невозможности использовать аутентификатор необходимо обратиться к администратору для сброса.
</Callout>

## Включение или отключение входа по Passkey без пароля

* Для этой учётной записи можно включить или отключить функцию входа по Passkey. После включения вход выполняется с помощью биометрии устройства, блокировки экрана или ключа безопасности, без ввода пароля.

1. **Включение Passkey**: в области «Вход по Passkey» нажать «Включить Passkey».
2. **Прохождение проверки безопасности**: по запросу ввести шестизначный динамический код, сгенерированный приложением-аутентификатором, либо восьмизначный резервный код и нажать «Подтвердить».
3. **Регистрация Passkey**: браузер отобразит системный запрос подтверждения. Следуя инструкциям, завершить регистрацию Passkey с помощью отпечатка пальца, распознавания лица, PIN-кода или других системных методов подтверждения устройства.
4. **Просмотр статуса**: после успешной регистрации страница отобразит «Аутентификация Passkey · Включена» и время последнего использования.
5. **Отвязка Passkey**: чтобы отключить эту функцию, нажать «Отвязать Passkey». После прохождения подтверждения личности вход по Passkey для текущей учётной записи будет удалён.

<img alt="Страница настроек Passkey" src="10-personal-passkey.webp" />

## Управление сеансами входа

* Используется для просмотра и управления сеансами входа текущей учётной записи на различных устройствах и в браузерах, что помогает пользователям оперативно обнаруживать и удалять аномальные состояния входа.

1. **Просмотр сведений о сеансе**: просмотр устройств, на которых выполнен вход, операционных систем, браузеров, IP-адресов, способов входа, времени последней активности и срока действия сеанса.
2. **Выход из конкретного сеанса**: нажать «Выйти» или «Отозвать» справа от соответствующего сеанса входа, чтобы завершить сеанс этого устройства в текущей учётной записи.
3. **Выход из других сеансов**: нажать «Выйти из других сеансов» в правом верхнем углу страницы, чтобы завершить все сеансы входа, кроме текущего.
4. **Управление статусом входа**: при обнаружении незнакомых устройств или необычных записей входа необходимо немедленно отозвать соответствующий сеанс и оперативно сменить пароль учётной записи.
