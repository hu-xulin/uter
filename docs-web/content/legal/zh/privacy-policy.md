## 第二章　关键概念与角色界定

> 本章是本政策的核心。本平台为**面向开发者与企业客户的大模型 API 服务平台**，业务链条中存在"您"与"您的终端用户"两个层次。准确理解我们各自的法律角色，是判断权利义务的前提。

**2.1 两层数据关系**

```
您的终端用户 ──(向您的应用提交信息)──> 您的应用 ──(调用本平台 API)──> 本平台 ──> 上游模型提供商
        ↑                                        ↑
   由【您】作为处理者                     由【您】作为处理者，我们作为受托处理者
```

**2.2 我们的两种角色**

| 场景 | 涉及的数据 | 您的角色 | 我们的角色 | 适用规则 |
|---|---|---|---|---|
| **场景 A：您注册、认证、充值、登录本平台** | 您的手机号、邮箱、身份证/营业执照信息、支付信息、登录日志 | 个人 | **个人信息处理者** | 适用本政策第三章至第七章全文 |
| **场景 B：您通过 API 提交请求内容，其中包含个人信息** | 提示词、上传文件、模型返回内容 | **个人信息处理者** | **受托处理者** | 我们仅按您的指令处理，不用于自身目的；适用本政策第 2.3 条 |

**2.3 作为受托处理者的特别约定**

2.3.1 在场景 B 中：

1. **您应自行取得您终端用户的合法授权**（告知同意或其他合法性基础），并在您自身的隐私政策中履行充分告知义务；
2. 我们按照您的指令处理数据，处理目的、方式、期限均由您的调用行为决定；
3. **我们不将该等数据用于本政策第 2.2 条场景 A 之外的任何目的**，包括但不限于商业化利用、模型训练、用户画像、数据售卖；
4. 出现安全事件时，我们会及时通知您，并由您向您的终端用户及监管机关履行告知与报告义务；
5. 您可与我们另行签署《数据处理协议（DPA）》，约定处理细节与审计安排。

2.3.2 **我们建议并且支持您在提交前对个人信息进行脱敏处理。** 若您提交的数据涉及敏感个人信息（如生物识别、医疗健康、金融账户、行踪轨迹、不满十四周岁未成年人信息），您应确保已取得**单独同意**并完成个人信息保护影响评估。

2.3.3 除法律另有规定外，我们**不会主动访问**您的请求内容。仅在下列情形下，我们可能在最小必要范围内查看：为您排查技术故障且经您授权；应监管机关、司法机关的合法要求；发现涉嫌严重违法或危害公共安全的内容。

## 第五章　数据出境

**5.1 触发条件**

本平台默认采用境内节点与境内模型，**数据不出境**。

**仅在您主动选择调用境外模型节点时**，您的请求内容会传输至境外上游模型提供商并可能在境外处理与存储。

**5.2 我们的处理原则**

5.2.1 该等传输由**您主动选择并发起**。您在控制台选择境外模型的行为，构成您对数据出境的明确指示。

5.2.2 我们**不在境内留存**您的请求与响应正文内容，出境传输为实时转发，不构成境内数据的增量存储（仅保留必要的元数据用于计费与审计，且该等元数据存储于中国境内）。

5.2.3 **依据《个人信息保护法》第三章第三节及《数据出境安全评估办法》等规定，您在向本平台提交含个人信息的请求内容前，应自行完成所需的数据出境合规程序**，包括但不限于：个人信息出境标准合同订立与备案、个人信息保护认证，或安全评估申报（如达到申报门槛）。

5.2.4 我们建议并支持您通过以下方式降低出境风险：选择境内模型；在客户端实施数据脱敏、字段替换、假名化处理；对敏感个人信息一律避免出境。

**5.3 跨境传输的例外**

涉及关键信息基础设施运营者、重要数据、或法律法规禁止出境的数据，**不得通过本平台的境外节点处理**。您违反本条约定造成的后果由您自行承担。

## 第六章　我们如何存储与保护个人信息

**6.1 存储地点**

您的个人信息存储于**中华人民共和国境内**的服务器（位于中国境内数据中心）。除第 5.1 条所述情形外，我们不向境外传输您的个人信息。

**6.2 存储期限**

我们遵循**最小必要期限**原则，具体如下：

| 信息类型 | 存储期限 | 依据 |
|---|---|---|
| 请求与响应**正文内容** | **默认不留存**（实时转发后即释放） | 最小必要原则 |
| 调用元数据（时间、模型、Token 数、状态码、耗时） | **12 个月** | 计费对账与审计需要 |
| 账户与实名认证信息 | 账户存续期间，账户注销后 **6 个月**内删除或匿名化 | 服务关系与监管核查需要 |
| 支付与开票记录 | 依据《电子商务法》《会计档案管理办法》，自交易完成之日起 **不少于 3 年** | 法定义务 |
| 网络安全日志 | **不少于 6 个月** | 《网络安全法》第二十一条 |
| 安全事件处置记录 | **3 年** | 合规追溯需要 |

**超过上述期限的，我们将删除或匿名化处理，不再用于任何目的。**

**6.3 安全保护措施**

我们采取符合业界标准的安全措施保护您的个人信息：

| 层面 | 措施 |
|---|---|
| 传输安全 | 全站 HTTPS / TLS 1.3 加密，API 强制密钥鉴权 |
| 存储安全 | 敏感字段（身份证件号码、密码）加密存储；数据库访问最小权限 |
| 访问控制 | 员工分级授权、操作留痕审计；API Key 支持 IP 白名单与轮换 |

## 第十三章　名词解释

| 术语 | 含义 |
|---|---|
| **个人信息** | 以电子或其他方式记录的与已识别或可识别的自然人有关的各种信息，不包括匿名化处理后的信息 |
| **敏感个人信息** | 一旦泄露或非法使用，容易导致自然人的人格尊严受到侵害或人身、财产安全受到危害的个人信息，包括生物识别、宗教信仰、特定身份、医疗健康、金融账户、行踪轨迹等信息，以及不满十四周岁未成年人的个人信息 |

| **受托处理者** | 接受个人信息处理者委托，按其指令处理个人信息的组织、个人 |
| **去标识化** | 个人信息经过处理，使其在不借助额外信息的情况下无法识别特定自然人的过程 |
| **匿名化** | 个人信息经过处理无法识别特定自然人且不能复原的过程 |
| **自动化决策** | 通过计算机程序自动分析、评估个人的行为习惯、兴趣爱好或经济、健康、信用状况等，并进行决策的活动 |
| **数据出境** | 将在中国境内运营中收集和产生的个人信息传输、存储至境外，或允许境外的机构、组织、个人访问、调取该等信息 |
| **上游模型提供商** | 实际提供大模型推理能力的第三方，包括但不限于 OpenAI、Anthropic、Google、阿里云、字节跳动、腾讯、DeepSeek、智谱等 |
