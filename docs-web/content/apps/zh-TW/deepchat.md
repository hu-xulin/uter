    ```json
    { "DeepChat": "deepchat://provider/install?v=1&data={deepchatConfig}" }
    ```

## 優特接入方法

### 方式一：一鍵匯入

1. 在 優特控制檯側邊欄進入「令牌管理」，找到需要使用的令牌

2. 在令牌操作中選擇 **DeepChat**

3. 瀏覽器喚起 DeepChat，確認開啟應用
   ![開啟 DeepChat](/apps-assets/deepchat/3-open-deepchat.webp)

4. 在 DeepChat 的 Provider 匯入預覽中確認配置
   ![確認 DeepChat 配置](/apps-assets/deepchat/4-deepchat-ok.webp)

5. 開啟模型列表，選擇 優特模型開始使用
   ![開啟模型列表](/apps-assets/deepchat/5-open-models.webp)

### 方式二：手動匯入

1. 在 優特控制檯複製 API Key 和站點地址
   ![優特手動配置指引](/apps-assets/deepchat/7-uter-manual-guidance.webp)

2. 在 DeepChat 設定中新增或編輯 優特 Provider，填寫 API 地址和 API Key
   ![DeepChat 手動配置指引](/apps-assets/deepchat/6-deepchat-manual-guidance.webp)

3. 開啟模型列表，選擇 優特模型開始使用
   ![開啟模型列表](/apps-assets/deepchat/5-open-models.webp)
