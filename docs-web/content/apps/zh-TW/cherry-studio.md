# Cherry Studio - 桌面 AI 客戶端

> **聊天設定選項**
>
> 在 優特
>   控制檯的系統設定->聊天設定中，可新增如下快捷選項，便於在令牌管理頁一鍵填充到
>   Cherry Studio：

    ```json
    { "Cherry Studio": "cherrystudio://providers/api-keys?v=1&data={cherryConfig}" }
    ```

## 優特接入方法

### 引數填寫

提供商型別：優特支援的型別  
API 金鑰：於 優特獲取  
API 地址：優特站點地址

請使用您自己部署的 優特，或確認服務方具備合法上游授權和合規義務的 優特服務。不要將來源不明的 API 地址或金鑰接入生產環境。
