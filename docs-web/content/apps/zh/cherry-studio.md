# Cherry Studio

> **聊天设置选项**
>
> 在 优特斯
>   控制台的系统设置->聊天设置中，可添加如下快捷选项，便于在令牌管理页一键填充到
>   Cherry Studio：

    ```json
    { "Cherry Studio": "cherrystudio://providers/api-keys?v=1&data={cherryConfig}" }
    ```

## 优特斯接入方法

### 参数填写

提供商类型：优特斯支持的类型  
API 密钥：于 优特斯获取  
API 地址：优特斯站点地址

请使用您自己部署的 优特斯，或确认服务方具备合法上游授权和合规义务的 优特斯服务。不要将来源不明的 API 地址或密钥接入生产环境。
