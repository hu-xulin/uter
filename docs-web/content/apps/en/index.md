## Integration Guide

Most applications only require configuring the following information to connect to URouters:

1.  **API Address**: Your URouters service address
2.  **API Key**: The Token generated in the URouters console
3.  **Model Name**: Select the model to use

For specific configuration steps, please refer to the detailed documentation of each application.
