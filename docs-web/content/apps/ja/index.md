## 連携ガイド

ほとんどのアプリケーションは、Uter に接続するために以下の情報を設定するだけです：

1.  **API アドレス**: お使いの Uter サービスのアドレス
2.  **API Key**: Uter コンソールで生成したトークン
3.  **モデル名**: 使用するモデルを選択

具体的な設定手順については、各アプリケーションの詳細ドキュメントを参照してください。
