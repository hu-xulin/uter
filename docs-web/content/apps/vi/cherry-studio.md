# Cherry Studio - Ứng dụng khách AI máy tính để bàn

> **Tùy chọn cài đặt trò chuyện**
>
> Trong bảng điều khiển Uter,
>   tại System Settings -> Chat Settings, bạn có thể thêm các tùy chọn nhanh sau để điền một cú nhấp vào
>   Cherry Studio trên trang quản lý token:

    ```json
    { "Cherry Studio": "cherrystudio://providers/api-keys?v=1&data={cherryConfig}" }
    ```

> 🍒 Cherry Studio là một ứng dụng khách AI máy tính để bàn mạnh mẽ dành cho người dùng chuyên nghiệp, tích hợp 30+
>   trợ lý thông minh chuyên ngành để đáp ứng nhu cầu của nhiều kịch bản công việc và cải thiện đáng kể hiệu suất làm việc.

- Trang chủ: [https://cherry-ai.com](https://cherry-ai.com/)
- Liên kết tải xuống: [https://cherry-ai.com/download](https://cherry-ai.com/download)
- Tài liệu chính thức: [https://docs.cherry-ai.com](https://docs.cherry-ai.com)

## Phương thức tích hợp Uter

### Cấu hình tham số

Provider Type: Các loại được Uter hỗ trợ
API Key: Lấy từ Uter
API Address: Địa chỉ trang Uter

Vui lòng sử dụng Uter tự triển khai của bạn, hoặc đảm bảo rằng nhà cung cấp dịch vụ có dịch vụ Uter với ủy quyền upstream hợp pháp và các nghĩa vụ tuân thủ. Không tích hợp địa chỉ API hoặc khóa từ nguồn không xác định vào môi trường sản xuất.
