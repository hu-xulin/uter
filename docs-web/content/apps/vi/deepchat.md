# DeepChat - Ứng dụng khách tác nhân AI đầy đủ tính năng thân thiện thương mại

> **Tùy chọn cài đặt trò chuyện**
>
> Trong bảng điều khiển Uter, đi tới System Settings -> Chat Settings và thêm
>   tùy chọn lối tắt sau. Nó cho phép người dùng điền DeepChat từ trang quản lý
>   token chỉ với một cú nhấp:

    ```json
    { "DeepChat": "deepchat://provider/install?v=1&data={deepchatConfig}" }
    ```

> DeepChat là một ứng dụng khách tác nhân AI mã nguồn mở, đa nền tảng, thân thiện thương mại và
>   đầy đủ tính năng. Nó hỗ trợ mô hình đám mây và cục bộ, gọi công cụ MCP, Skills,
>   ACP, tích hợp Agent và quy trình điều khiển từ xa, phù hợp cho người dùng cần quản lý
>   Provider thống nhất và các Agent AI nâng cao.

## Phương thức tích hợp Uter

### Phương pháp 1: Nhập một cú nhấp

1. Trong thanh bên bảng điều khiển Uter, mở **Token Management** và tìm token bạn muốn sử dụng

2. Chọn **DeepChat** từ các thao tác token

3. Để trình duyệt khởi chạy DeepChat và xác nhận mở ứng dụng
   ![Mở DeepChat](/apps-assets/deepchat/3-open-deepchat.webp)

4. Xác nhận cấu hình trong bản xem trước nhập Provider của DeepChat
   ![Xác nhận cấu hình DeepChat](/apps-assets/deepchat/4-deepchat-ok.webp)

5. Mở danh sách mô hình và chọn một mô hình Uter để bắt đầu sử dụng
   ![Mở danh sách mô hình](/apps-assets/deepchat/5-open-models.webp)

### Phương pháp 2: Nhập thủ công

1. Sao chép API Key và địa chỉ trang từ bảng điều khiển Uter
   ![Hướng dẫn cấu hình thủ công Uter](/apps-assets/deepchat/7-new-api-manual-guidance.webp)

2. Trong cài đặt DeepChat, thêm hoặc chỉnh sửa Provider Uter, sau đó điền địa chỉ API và API Key
   ![Hướng dẫn cấu hình thủ công DeepChat](/apps-assets/deepchat/6-deepchat-manual-guidance.webp)

3. Mở danh sách mô hình và chọn một mô hình Uter để bắt đầu sử dụng
   ![Mở danh sách mô hình](/apps-assets/deepchat/5-open-models.webp)
