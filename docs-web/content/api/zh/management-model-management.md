# 模型管理

## 获取所有模型元数据

👨‍💼 需要管理员权限（Admin）

`GET` `/api/models/`

### 响应

| 状态码 | 说明 |
|---|---|
| `200` | 成功 |

👨‍💼 需要管理员权限（Admin）

### 请求参数

| 参数名 | 位置 | 类型 | 必填 | 说明 |
|---|---|---|---|---|
| `id` | path | integer | 是 | — |

|---|---|
| `200` | 成功 |
