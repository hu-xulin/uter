# 供应商

## 获取所有供应商

👨‍💼 需要管理员权限（Admin）

`GET` `/api/vendors/`

### 响应

| 状态码 | 说明 |
|---|---|
| `200` | 成功 |

| 参数名 | 位置 | 类型 | 必填 | 说明 |

| `id` | path | integer | 是 | — |
