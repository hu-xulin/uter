# 日志

## 删除历史日志

👨‍💼 需要管理员权限（Admin）

`DELETE` `/api/log/`

### 响应

| 状态码 | 说明 |
|---|---|
| `200` | 成功 |

## 获取所有日志

👨‍💼 需要管理员权限（Admin）

`GET` `/api/log/`

### 请求参数

| 参数名 | 位置 | 类型 | 必填 | 说明 |
|---|---|---|---|---|
| `p` | query | integer | 否 | — |
| `page_size` | query | integer | 否 | — |

### 响应

| 状态码 | 说明 |
|---|---|
| `200` | 成功 |
