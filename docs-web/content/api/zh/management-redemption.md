# 兑换码

## 获取所有兑换码

👨‍💼 需要管理员权限（Admin）

`GET` `/api/redemption/`

### 请求参数

| 参数名 | 位置 | 类型 | 必填 | 说明 |
|---|---|---|---|---|
| `p` | query | integer | 否 | — |
| `page_size` | query | integer | 否 | — |

### 响应

| 状态码 | 说明 |
|---|---|
| `200` | 成功 |
