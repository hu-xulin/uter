# logs

## 過去のログの削除

👨‍💼 管理者権限が必要（Admin）

`DELETE` `/api/log/`

### レスポンス

| ステータスコード | 説明 |
|---|---|
| `200` | 成功 |

## すべてのログの取得

👨‍💼 管理者権限が必要（Admin）

`GET` `/api/log/`

### リクエストパラメータ

| パラメータ名 | 位置 | 型 | 必須 | 説明 |
|---|---|---|---|---|
| `p` | query | integer | いいえ | — |
| `page_size` | query | integer | いいえ | — |

| ステータスコード | 説明 |
|---|---|
| `200` | 成功 |
