# Format Gemini natif

Renvoie la liste des modèles disponibles au format Gemini API.

`GET` `/v1beta/models`

### Réponse

| Code d'état | Description |
|---|---|
| `200` | Liste des modèles récupérée avec succès |

#### Champs de la réponse `200`

| Champ | Type | Description |
|---|---|---|
| `models` | array&lt;object&gt; | — |
