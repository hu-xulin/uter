# statistics

## Récupérer toutes les données de quota

👨‍💼 Nécessite des privilèges d'administrateur (Admin)

`GET` `/api/data/`

### Réponse

| Code d'état | Description |
|---|---|
| `200` | Succès |

## Récupérer les données de quota personnelles

🔐 Nécessite une connexion (permission User)

`GET` `/api/data/self`

### Réponse

| Code d'état | Description |
|---|---|
| `200` | Succès |
