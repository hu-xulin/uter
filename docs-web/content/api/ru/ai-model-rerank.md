# Переранжирование документов

## Переранжирование документов

Выполняет переранжирование списка документов по релевантности относительно запроса.

`POST` `/v1/rerank`

### Тело запроса (`application/json`)

| Поле | Тип | Обязательно | Описание |
|---|---|---|---|
| `model` | string | да | — |
| `query` | string | да | Текст запроса |
| `documents` | array&lt;string&gt; | да | Список документов для переранжирования |
| `top_n` | integer | нет | Вернуть первые N результатов |
| `return_documents` | boolean | нет | — |

### Ответ

| Код статуса | Описание |
|---|---|
| `200` | Переранжирование выполнено успешно |

#### Поля ответа `200`

| Поле | Тип | Описание |
|---|---|---|
| `id` | string | — |
| `results` | array&lt;object&gt; | — |
| `meta` | object | — |
