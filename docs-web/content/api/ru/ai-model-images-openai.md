# openai

## Редактирование изображения

Создаёт отредактированное или расширенное изображение на основе исходного изображения и подсказки.

`POST` `/v1/images/edits/`

### Тело запроса (`multipart/form-data`)

| Поле | Тип | Обязательно | Описание |
|---|---|---|---|
| `image` | string（binary） | да | Изображение для редактирования. Должен быть корректным PNG-файлом размером менее 4 МБ и квадратным. Если маска не указана, изображение должно иметь прозрачность, которая будет использована как маска. |
| `mask` | string（binary） | нет | Дополнительное изображение, полностью прозрачные области которого (например, с нулевым значением alpha) указывают, где нужно редактировать `image`. Должен быть корректным PNG-файлом размером менее 4 МБ и совпадать по размеру с исходным `image`. |
| `prompt` | string | да | Текстовое описание желаемого изображения. Максимальная длина — 1000 символов. |
| `n` | string | нет | Количество генерируемых изображений. Должно быть от 1 до 10. |
| `size` | string | нет | Размер генерируемого изображения. Должен быть одним из: `256x256`, `512x512` или `1024x1024`. |
| `response_format` | string | нет | Формат возврата сгенерированного изображения. Должен быть `url` или `b64_json`. |
| `user` | string | нет | Уникальный идентификатор, представляющий вашего конечного пользователя; помогает OpenAI отслеживать и выявлять злоупотребления. [Подробнее](https://platform.openai.com/docs/guides/safety-best-practices/end-user-ids). |
| `model` | string | нет | — |

### Ответ

| Код статуса | Описание |
|---|---|
| `200` | Ответ |

## Генерация изображений

Создаёт изображение на основе заданной подсказки. [Подробнее](https://platform.openai.com/docs/guides/images).

`POST` `/v1/images/generations/`

### Тело запроса (`application/json`)

| Поле | Тип | Обязательно | Описание |
|---|---|---|---|
| `model` | string | нет | Модель для генерации изображений. Одна из: `dall-e-2`, `dall-e-3` или `gpt-image-1`. По умолчанию `dall-e-2`, если не используются параметры, специфичные для `gpt-image-1`. |
| `prompt` | string | да | Текстовое описание желаемого изображения. Максимальная длина: 32000 символов для `gpt-image-1`, 1000 символов для `dall-e-2`, 4000 символов для `dall-e-3`. |
| `n` | integer | нет | Количество генерируемых изображений. Должно быть от 1 до 10. Для `dall-e-3` поддерживается только `n=1`. |
| `size` | string | нет | Размер генерируемого изображения. Для `gpt-image-1` должен быть одним из: `1024x1024`, `1536x1024` (альбомный), `1024x1536` (портретный) или `авто` (по умолчанию); для `dall-e-2` — одним из `256x256`, `512x512` или `1024x1024`; для `dall-e-3` — одним из `1024x1024`, `1792x1024` или `1024x1792`. |
| `background` | string | нет | Позволяет задать прозрачность фона для генерируемого изображения. Этот параметр поддерживается только для `gpt-image-1`. Должен быть одним из: `прозрачный`, `непрозрачный` или `авто` (по умолчанию). При использовании `авто` модель сама определит оптимальный фон изображения. Если значение `прозрачный`, формат вывода должен поддерживать прозрачность, поэтому следует установить `png` (по умолчанию) или `webp`. |
| `moderation` | string | нет | Контролирует уровень модерации контента для изображений, генерируемых `gpt-image-1`. Должен быть `низкий` для менее строгой фильтрации или `авто` (по умолчанию). |
| `quality` | string | нет | Качество генерируемого изображения. |
| `stream` | string | нет | — |
| `style` | string | нет | — |
| `user` | string | нет | — |

### Ответ

| Код статуса | Описание |
|---|---|
| `200` | Ответ |

#### Поля ответа `200`

| Поле | Тип | Описание |
|---|---|---|
| `created` | integer | — |
| `data` | array&lt;object&gt; | — |
| `usage.total_tokens` | integer | — |
| `usage.input_tokens` | integer | — |
| `usage.output_tokens` | integer | — |
| `usage.input_tokens_details.text_tokens` | integer | — |
| `usage.input_tokens_details.image_tokens` | integer | — |
