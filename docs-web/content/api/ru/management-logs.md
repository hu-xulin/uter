# logs

## Удаление исторических логов

👨‍💼 Требуются права администратора (Admin)

`DELETE` `/api/log/`

### Ответ

| Код статуса | Описание |
|---|---|
| `200` | Успешно |

## Получение всех логов

👨‍💼 Требуются права администратора (Admin)

`GET` `/api/log/`

### Параметры запроса

| Параметр | Расположение | Тип | Обязательно | Описание |
|---|---|---|---|---|
| `p` | query | integer | нет | — |
| `page_size` | query | integer | нет | — |

### Ответ

| Код статуса | Описание |
|---|---|
| `200` | Успешно |
