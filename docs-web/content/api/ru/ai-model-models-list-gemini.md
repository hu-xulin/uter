# Нативный формат Gemini

Возвращает список доступных моделей в формате Gemini API.

`GET` `/v1beta/models`

### Ответ

| Код статуса | Описание |
|---|---|
| `200` | Список моделей успешно получен |

#### Поля ответа `200`

| Поле | Тип | Описание |
|---|---|---|
| `models` | array&lt;object&gt; | — |
