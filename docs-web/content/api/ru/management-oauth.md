# OAuth

## Вход через Discord OAuth

🔓 Без авторизации (OAuth callback)

`GET` `/api/oauth/discord`

### Параметры запроса

| Имя параметра | Расположение | Тип | Обязательный | Описание |
|---|---|---|---|---|
| `code` | query | string | Нет | — |

### Ответ

| Код состояния | Описание |
|---|---|
| `200` | Успешно |
