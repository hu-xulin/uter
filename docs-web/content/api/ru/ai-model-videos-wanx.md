# Формат Wanx

Генерация видео Wan 2.7: обращение к полному семейству моделей Wan 2.7 через асинхронный API задач; поддерживаются генерация по тексту, по изображению, по эталонам и редактирование видео, с выходом 1080P, видео до 15 секунд, многосценичное повествование и нативная синхронизация аудио.

## Поддерживаемые модели

Все четыре модели используют один конечный путь `/v1/video/generations` и различаются только полем `model`; форма ответа идентична.

| Модель | Возможность | Обязательный медиаввод | Описание |
|---|---|---|---|
| `wan2.7-t2v` | Генерация по тексту | — | Генерация видео по тексту; поддерживает многосценичное повествование и синхронизацию аудио |
| `wan2.7-i2v` | Изображение в видео | 1 кадр (первый) | Анимация от первого кадра в соответствии с подсказкой |
| `wan2.7-r2v` | По эталонам | 1–9 эталонных изображений | Мультиизображение с сохранением согласованности субъекта; ссылки на изображения как `[Image N]` |
| `wan2.7-videoedit` | Редактирование видео | 1 видео + 0–3 эталонных изображения | Перенос стиля, замена элементов и локальные правки по текстовым инструкциям |

## Создание видео

`POST` `/v1/video/generations`

### Заголовки запроса

| Заголовок | Обязательно | Описание |
|---|---|---|
| `Authorization` | Да | `Bearer sk-your-api-key` |
| `Content-Type` | Да | `application/json` |

### Тело запроса (`application/json`)

| Поле | Тип | Обязательно | Описание |
|---|---|---|---|
| `model` | string | Да | Название модели Wan 2.7, см. таблицу выше |
| `prompt` | string | Да | Текстовая подсказка, до 5000 символов, поддерживаются китайский и английский |
| `resolution` | string | Нет | Уровень разрешения: `720P` / `1080P`, по умолчанию `720P`. **Рекомендуется**; совпадает с официальным именем поля Alibaba Cloud |
| `size` | string | Нет | Устаревшее имя поля. При указании обоих приоритет у `resolution`; если передан только `size`, его значение используется как разрешение. Новым интеграциям следует использовать `resolution` |
| `duration` | int | Нет | Длительность в секундах: `2`–`15` для t2v/i2v, по умолчанию `5`; `2`–`10` для r2v с эталонным видео; игнорируется для `videoedit` (следует входному видео, макс. 15с) |
| `input_reference` | string | Нет | Только i2v: публичный URL первого кадра изображения |
| `images` | array | Нет | Только videoedit: массив URL медиа; 1-й элемент — редактируемое видео (MP4/MOV), остальные — необязательные эталонные изображения (макс. 3) |
| `metadata` | object | Нет | Контейнер параметров, специфичных для Wan 2.7, см. ниже |

> Поле `images` находится в переходном периоде релиза: до релиза передавайте медиа через массив `metadata.input.media`; после него система выводит типы медиа по расширениям URL, и `images` можно использовать напрямую.

### Ответ

| Статус | Описание |
|---|---|
| `200` | Задача видео успешно создана |
| `400` | Недопустимые параметры запроса |

#### Поля ответа `200`

| Поле | Тип | Описание |
|---|---|---|
| `id` / `task_id` | string | Публичный ID задачи (префикс `task_`) для последующих запросов |
| `object` | string | Тип объекта (`video`) |
| `model` | string | Использованная модель |
| `status` | string | Состояние задачи (сразу после отправки — `queued`) |
| `progress` | integer | Прогресс в процентах |
| `created_at` | integer | Временная метка создания |

> `id` / `task_id` генерируется Uter и не является upstream-идентификатором задачи DashScope. Всегда используйте значение, возвращаемое здесь.

## Получение состояния задачи видео

`GET` `/v1/video/generations/{task_id}`

Ответ использует единый конверт Uter `{code, message, data}`.

### Параметры запроса

| Имя | Расположение | Тип | Обязательно | Описание |
|---|---|---|---|---|
| `task_id` | path | string | Да | ID задачи видео |

### Ответ

| Статус | Описание |
|---|---|
| `200` | Состояние задачи успешно получено |
| `404` | Задача не найдена |

#### Поля ответа `200` (`data`)

| Поле | Тип | Описание |
|---|---|---|
| `data.task_id` | string | Публичный ID задачи |
| `data.status` | string | Состояние задачи: `NOT_START` / `QUEUED` / `IN_PROGRESS` / `SUCCESS` / `FAILURE` |
| `data.result_url` | string | URL результата видео (непустой только при `SUCCESS`; подписанная ссылка upstream OSS, действительна 24 часа) |
| `data.fail_reason` | string | Причина сбоя (непустая только при `FAILURE`) |
| `data.quota` | int | Исходная квота, списанная за эту задачу |
| `data.progress` | string | Строка прогресса, напр. `"40%"` / `"100%"` |
| `data.properties.upstream_model_name` | string | Название модели, фактически отправленной upstream |
| `data.data` | object | Исходный ответ upstream DashScope (`output.video_url`, `usage`, `request_id`) |

#### Перечисление статусов

| Статус | Статус upstream | Описание |
|---|---|---|
| `NOT_START` | `PENDING` | Создано, ещё не обрабатывается |
| `QUEUED` | `PENDING` | В очереди upstream |
| `IN_PROGRESS` | `RUNNING` | Генерация |
| `SUCCESS` | `SUCCEEDED` | Завершено; `result_url` содержит видео |
| `FAILURE` | `FAILED` / `CANCELED` / `UNKNOWN` | Сбой; `fail_reason` объясняет причину |

## Специфичные параметры (`metadata`)

Передавайте следующее через объект `metadata` тела запроса; Uter перенаправляет их upstream DashScope.

### Общие управляющие параметры

| Поле | Тип | Применяется к | Описание | По умолчанию |
|---|---|---|---|---|
| `ratio` | string | t2v / r2v | Соотношение сторон: `16:9` / `9:16` / `1:1` / `4:3` / `3:4` | `16:9` |
| `seed` | int | Все | Случайное зерно, `0`–`2147483647`; генерируется автоматически при пропуске | — |
| `negative_prompt` | string | Все | Негативная подсказка, до 500 символов | — |

> i2v не поддерживает `ratio`; соотношение сторон следует за первым кадром входного изображения.

### Мультимедийный ввод (`metadata.input.media`)

Для r2v и videoedit передавайте медиа через массив `metadata.input.media`:

| `type` | Назначение | Лимит количества |
|---|---|---|
| `reference_image` | Эталонное изображение | r2v: 1–9; videoedit: 0–3 |
| `video` | Редактируемое видео (только videoedit) | Ровно 1 |
| `first_frame` | Изображение первого кадра (только i2v; также можно использовать верхуровневый `input_reference`) | Ровно 1 |

Для r2v ссылайтесь на эталонные изображения по порядку в массиве в подсказке через `[Image 1]`, `[Image 2]`.

### Ограничения медиа

| Тип | Формат | Разрешение | Размер | Другие ограничения |
|---|---|---|---|---|
| Изображение (первый кадр i2v) | JPEG / JPG / PNG / WEBP | 240–8000 px | ≤ 10 МБ | Соотношение сторон 1:8 – 8:1 |
| Изображение (эталон r2v) | JPEG / JPG / PNG / WEBP | Короткая сторона ≥ 300 px | ≤ 10 МБ | Используйте чёткие изображения |
| Изображение (эталон videoedit) | JPEG / JPG / PNG / BMP / WEBP | 240–8000 px | ≤ 20 МБ | Соотношение сторон 1:8 – 8:1 |
| Видео (вход videoedit) | MP4 / MOV (H.264) | 240–4096 px | ≤ 100 МБ | 2–10 с, соотношение сторон 1:8 – 8:1 |

## Совместимая с OpenAI конечная точка

Помимо `/v1/video/generations`, доступна конечная точка в стиле OpenAI `/v1/videos`; они полностью эквивалентны.

- Отправка: `POST` `/v1/videos` (идентичные поля тела)
- Запрос: `GET` `/v1/videos/{task_id}` (возвращает плоский формат OpenAI)

| Статус OpenAI | Единый статус |
|---|---|
| `queued` | `NOT_START` / `QUEUED` |
| `in_progress` | `IN_PROGRESS` |
| `completed` | `SUCCESS` |
| `failed` | `FAILURE` |

## Тарификация

Wan 2.7 тарифицируется по формуле **секунды × коэффициент разрешения**:

| Разрешение | Цена | Пример для 5 секунд |
|---|---|---|
| `720P` | $0.10 / секунду | $0.50 |
| `1080P` | $0.15 / секунду | $0.75 |

```
quota = modelPrice × QuotaPerUnit × groupRatio × seconds × resolutionRatio

QuotaPerUnit    = 500,000
modelPrice      = 0.10 (все модели wan2.7)
groupRatio      = 1.0 (производственная группа по умолчанию)
resolutionRatio = 720P → 1.0, 1080P → 1.5
```

При `FAILURE` Uter автоматически возвращает средства.

## Полный пример

```bash
# Step 1: submit the task
curl -X POST https://uter.ai/v1/video/generations \
  -H "Authorization: Bearer sk-your-api-key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "wan2.7-t2v",
    "prompt": "A kitten running under the moonlight, fur drifting in the wind, cinematic slow motion",
    "resolution": "720P",
    "duration": 5,
    "metadata": { "ratio": "16:9", "seed": 42 }
  }'

# Step 2: poll (every 10~15 seconds)
curl https://uter.ai/v1/video/generations/task_xxx \
  -H "Authorization: Bearer sk-your-api-key"

# Step 3: once data.status == "SUCCESS", download from data.result_url
```

Для videoedit передавайте медиа через массив `images`: 1-й MP4/MOV — редактируемое видео, остальные PNG/JPG/WEBP — эталонные изображения; `duration` не требуется (следует входному видео).

## Коды состояния и ошибки

| Случай | Описание |
|---|---|
| `400` | Ошибка параметра (отсутствует `prompt`, неизвестная модель, пустой `images` для videoedit, …); отклоняется до отправки, списание не производится |
| `401` / `403` | Недействительный API-ключ / нет доступа к этой модели |
| `402` | Недостаточный баланс (`insufficient user quota`); пополните в консоли Uter |
| Задача `FAILURE` | Генерация upstream не удалась, см. `fail_reason`; Uter автоматически возвращает средства |
