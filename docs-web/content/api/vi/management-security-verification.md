# Xác minh bảo mật (security-verification)

## Xác minh bảo mật chung (General Security Verification)

🔐 Yêu cầu đăng nhập (quyền User)

`POST` `/api/verify`

### Phản hồi

| Mã trạng thái | Mô tả |
|---|---|
| `200` | Thành công |

## Lấy trạng thái xác minh (Get Verification Status)

🔐 Yêu cầu đăng nhập (quyền User)

`GET` `/api/verify/status`

### Phản hồi

| Mã trạng thái | Mô tả |
|---|---|
| `200` | Thành công |
