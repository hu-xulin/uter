# Tài liệu tham khảo API

## Tổng quan

Uter cung cấp một bộ giao diện API RESTful hoàn chỉnh, được phân loại thành **AI Model APIs** (API Mô hình AI) và **Management APIs** (API Quản lý). Bạn có thể sử dụng các giao diện này để gọi các năng lực AI và thực hiện các chức năng quản lý hệ thống.

> **Gỡ lỗi trực tuyến**
>
> Bạn có thể truy cập Apifox Playground để kiểm thử và gỡ lỗi các giao diện API trực tuyến, hoặc duyệt tài liệu API bên dưới.

## AI Model APIs

AI Model APIs cung cấp quyền truy cập vào nhiều năng lực AI khác nhau và tương thích với định dạng API của OpenAI.

## Management APIs

Management APIs được sử dụng cho các thao tác phần mềm, chẳng hạn như cấu hình hệ thống, quản lý người dùng và quản lý nghiệp vụ.
