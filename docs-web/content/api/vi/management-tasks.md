# Tác vụ (tasks)

## Lấy tất cả tác vụ Midjourney (Get All Midjourney Tasks)

👨‍💼 Yêu cầu quyền quản trị viên (Admin)

`GET` `/api/mj/`

### Phản hồi

| Mã trạng thái | Mô tả |
|---|---|
| `200` | Thành công |
