Unified Design Spec · 合并设计规范

由《UTER Design System》与《上游 new-api 设计规范》合并而成，是合并体系的单一权威文件。 差异点按裁决总表定案：品牌 / 圆角 / 分层 / 主题维度取上游 new-api，焦点环 / 密度 / 表格 / 侧栏 / 控件高度取 UTER。

品牌色阶 #6565E8 · 六档派生 · 白字 4.59:1 ✅ AA 圆角基准 1rem 分层 ring-1 描边 + 悬停投影 焦点环 2px 满色 密度不动字号 主题维度 ×5（含字体轴） 侧边栏 220px 控件高度 --ds-* Token 化 十档字号 v1.2

  • 页面层级四层不多不少：28 / 22 / 18 / 15；text-base(16px) 不是标题，只给行标题 16/500、设置字段档 16/600、指标数值 16/600+tabular-nums。
  • 行高属于字号：text-sm 即得 14/22；禁止 leading-* 字面值。字重四档 400/500/600/700；字距恒为 0。
  • 最小字号 12px 强制；12px 只给真 caption（单行 ≤20 字、不承载数值、不是阅读主体）。
  • 字体轴 system（默认 sans-serif）/ sans（Public Sans）/ serif（Lora + 思源宋体系）；Markdown prose 阶梯 24/18/16/14。

分层：ring-1 描边 + 悬停投影

Card 常态
无投影，ring-1 ring-foreground/10 描边 + 表面色差分层。
Card 悬停（≥641px）
唯一成文投影：0 4px 12px rgb(0 0 0 / 0.06)，深色 0.3，配 translateY(-1px) · 150ms。

浮层（下拉 / 弹窗 / 抽屉）允许 Tailwind 内置 shadow-sm~xl；投影是例外表达，不是层级体系。

焦点环：2px 满色（UTER 标准）

用 Tab 键聚焦上方元素 —— 全站唯一焦点指示器：focus-visible:ring-2 ring-ring，2px 满色、贴边（offset 0）。ring-3/4 任何位置都违规；禁止 outline: none 无替代。
