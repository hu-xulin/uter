New API Design Spec · 上游 new-api 设计规范（合并版）

提取上游 new-api（QuantumNous/new-api，基线 commit 45746ee，2026-11-02）的设计标准，按《UTER Design System》章节格式整理。

合并裁决规则：品牌主色 = #6565E8（唯一改写项）；字号 / 行高 / 字重 = UTER 十档 v1.2；其余全部 = 上游 new-api；上游未定义项回退 UTER（正文标注「回退」）。

品牌主色 #6565E8 · AA 达标 圆角基准 1rem 焦点环 ring-3 / 50% 主题预设 ×9 字体轴 system / sans / serif

2. 视觉基调

  • OpenAI 风格中性画布 + 品牌点缀：近黑前景、细描边、以描边分层而不是投影、大圆角。
  • 圆角基准 1rem（16px），Badge 全胶囊、Card / Dialog 22.4px。
  • 深色是「炭灰画布」（background oklch(0.235 0 0)），不是纯黑蓝。
  • 半透明修饰符（X/NN）是常规表达（hover / glass / 边框）。
  • 原生控件跟随主题：.dark 声明 color-scheme: dark，Dark Reader 据此识别。

3.2 品牌主色与派生

上游没有独立 hover / active 色阶 Token，状态变化用三类写法：

  1. 透明度修饰符：hover:bg-primary/90、bg-primary/80、ring-ring/50；
  2. color-mix 浅底：--accent / --sidebar-accent = primary 12%（深色 20%）混入 background；
  3. 描边跟随：focus-visible:border-ring。

回退 需要 hover / active / subtle / border 派生档且透明度写法观感不符时，参照 UTER §11.2 为 #6565E8 派生同色相加深 12% / 24% 的档位并登记到规范，不要散写近似色值。

  • 组件不得写品牌色字面值，一律 bg-primary / text-primary / border-ring；
  • 品牌色改值只改 theme.css 的 :root 与 .dark 两处；
  • --ring 是上游独立的蓝色焦点环取值，不随品牌色自动变化——要跟品牌须显式改两处 --ring。

3.3 文字层级

上游未定义 --fg-* 七档，文字层级由既有 Token 表达：

层级Token典型用法

回退 三级弱信息 / 禁用 / 链接等更细层级，采用 UTER --fg-tertiary / --fg-disabled / --fg-link 语义补声明；文字层级不得用 opacity 或 text-foreground/NN 凑（上游的 X/NN 仅限 hover / glass 等状态表达）。

3.4 图表色与仪表盘强调色

  • --chart-1…5 是分类色（深色统一提亮 L≈0.76），区分类别不表达成败；状态语义走四个状态色。
  • --overview-accent-1/2/3（同 chart-1/2/3）用于仪表盘强调。
  • 回退 UTER §11.4 三条分类色硬规则：不拿 chart-N 表达成败、只追求可辨不追求语义、边框表达层级。

4. 字号与排版

字号整体采用 UTER 十档 v1.2。上游的 Tailwind 默认阶梯 + 密度档缩放 + 组件散写 text-[0.8rem] 不再使用；同名档位（text-sm=14、text-xs=12、text-base=16）恰好同值无需改类名，任意值必须替换为最近档位。

4.2 行高、字重与字距

  • 行高属于字号：写 text-sm 即得 14/22；上游改法 禁止 leading-snug / leading-[1.15] 字面值，换档位或 leading-[var(--…)]。
  • 字重四档：400 正文 / 500 标签导航 / 600 标题 / 700 保留档（普通管理界面不用）。
  • 字距恒为 0：上游改法 移除组件散写的 tracking-*；serif 轴的 -0.012em 标题微调是唯一保留项，随字体轴走。
  • 数字排版：金额 / Token / 表格数字一律 tabular-nums（上游已全局应用于表格与 .tabular-nums，保留）。

5. 间距与布局

  • 间距阶梯 = Tailwind 默认 4px 单位，未自定义 --spacing；直接 gap-2 / p-4 / px-2.5。
  • 密度档同时缩放间距与字号（与 UTER 相反，按裁决采用上游）：data-theme-scale 三档——sm: 0.225rem（字号整体缩小）、lg: 0.28rem、xl: 0.3rem（放大）。
  • 控件高度无 Token：高度直接写在组件类里（Button h-8、Input h-8、表头 h-10、表行 h-15）。
  • 头部高度 --app-header-height: 3rem；容器 padding-inline 2rem。
  • 内容宽度：max-w-container = 1280px、max-w-container-lg = 1536px；centered 模式 ≥1280px 钳制 --max-content-width 并居中。
  • 侧边栏：13rem（208px），移动端抽屉 17rem，图标态 2.75rem。
  • 弹窗：默认 sm:max-w-sm、max-w-[calc(100%-2rem)]；移动端用 --dialog-available-height（100dvh − 安全区）定位。

7. 描边与投影

  • 分层靠描边 + 表面色差，不靠投影：Card / Dialog 常态无投影，用 ring-1 ring-foreground/10。
  • 自定义 --shadow-* 未定义，用 Tailwind 内置 shadow-sm/md/lg/xl（不设 UTER 六档约束）。
  • 卡片悬停投影（唯一成文值，仅 ≥641px）：浅色 0 4px 12px rgb(0 0 0/0.06)，深色 0.3，配 translateY(−1px)，150ms。
  • sidebar 浮层 shadow-[0_0_0_1px_var(--sidebar-border)]；玻璃拟态走 glass-1…5 工具类。
  • ui 内 shadow 统计：none ×9、md ×9、sm ×3、lg ×3、xl ×1——投影是例外表达，不是层级体系。

8. 动效

  • 默认过渡：Tailwind 默认 150ms / ease（未重定义）。
  • 典型时长：Dialog 100ms；卡片 hover 150ms；表格行 120ms；sidebar 200ms linear；折叠 300ms ease-out；营销入场 0.6s cubic-bezier(0.16,1,0.3,1)；流光边框 3.2s。
  • 按压反馈：active:scale(0.98) / active:translate-y-px。
  • keyframes：skeleton-shimmer 1.8s、slideDown/Up 300ms、appear/appear-zoom 0.6s、scroll-up 20s、stream-fade-in 250ms、landing 系列 0.6s、tableRowEnter 0.2s（行级联 25–250ms）、terminal-demo 系列、flow-border 3.2s。
  • prefers-reduced-motion 下几乎所有动画关闭——新增动画必须配 reduce 媒体查询。
  • 上游未定义 --ds-motion-* Token 体系，新动画跟随既有清单的节奏档位。

10. 图标

  • 库：lucide-react 与 @hugeicons/react 混用（ui 基础件多用 Hugeicons，业务层大量 lucide）；strokeWidth 统一 2。
  • 尺寸约束：无全局 size Token，靠父级 [&_svg:not([class*='size-'])]:size-4 约束；Badge svg 强制 size-3；sidebar 菜单 size-4。
  • 颜色跟随父级文字色（currentColor）。
  • 回退 UTER 五档（16/18/24/32/48）作为新增图标选档依据：新图标尺寸优先落在 12/14/16/18/24 的既有使用值上，不发明新值。

11. 断点与响应式

  • 断点不自定义：Tailwind 默认 sm 640 / md 768 / lg 1024 / xl 1280。
  • 侧边栏 md:（≥768px）常驻，以下 Sheet 抽屉（17rem）。
  • centered 内容钳制 ≥1280px 生效。
  • 输入控件：移动 text-base（16px）→ ≥md text-sm；另有 <767px 的 16px !important 双保险。
  • 卡片 hover 投影仅 ≥641px 启用。
  • 回退 桌面与移动共用一套阶梯，小屏只允许放大不允许缩小。

12. 焦点环、触控目标与可访问性

  • 焦点环（上游标准）：focus-visible:ring-3 ring-ring/50 + focus-visible:border-ring——3px 半透明环。试试：（全局兜底 * { outline-color: ring/50 }；sidebar 内 ring-2 无透明；aria-invalid 时 ring-destructive/20）。
  • 回退 触控目标（上游未定义）：最小命中区 24×24（WCAG 2.2 AA）；视觉 <24px 时加居中扩大命中层，不用 min-w/min-h 撑盒子。
  • 对比度：普通文本 4.5:1、大文本 3:1、非文本 3:1；品牌色替换后的必测组合见 §1，每次调色重算。
  • 深色独立验证：.dark 有全套独立 Token，对比度结论不得从浅色推断。
