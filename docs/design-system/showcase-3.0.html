区域 7状态色 §2.7

每种状态五 Token 成组（base / foreground / soft / soft-foreground / border）；色值沿用项目已核实值。

状态组合对比度（实心与 Soft，AA 4.5:1）

结果为实时计算、如实显示：Light 下 success 实心（3.15:1）与 info 实心（3.85:1）未达 AA —— 按 §2.7 / §19.4 须在 Token 定版时处理（加深底色或换前景色），不得据此下调阈值。

✔Success · 操作成功余额到账、任务完成 —— 图标 + 文字，不只靠颜色（§2.7 要求 1-2）。

✕Destructive · 错误 / 危险删除及不可逆操作。
iInfo · 中性通知帮助信息、一般说明。

区域 14五档 Elevation Shadow + Brand Glow §8

五个 Elevation Token + 一个独立品牌 Glow Token（不是六档普通阴影）。仅用于浮起关系场景；普通卡片用边框。

Dark 阴影为候选值（§8.2 要求独立定义 + 实测验收），切换深色查看，定版前不得标记为已验收。禁止给所有 Card 自动加 Shadow；禁止大范围 Glow 代替品牌色。
